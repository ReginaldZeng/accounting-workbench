# 对接说明 · BP 工作台「只读标准成本台账」（核算侧 V2.442 已备口，BP 侧照此做页面）

> 2026-09-05 核算工作台线 → BP 工作台线（01 项目）。配套《对接需求_BP消费接口_20260905》与《对接确认_核算侧回复》§1–§8。
> 业务方定的原则：**入口在 BP，动作在核算。** BP 页面只放链接和数字，审核、对比、下载都在核算工作台完成，两边不重复做一套审核流。

## 0. 这页是什么、不是什么

| 是 | 不是 |
|---|---|
| 一张**只读镜像**：核算侧「已审核·对外」的标准成本（含税五分项 元/kg + 单位净重）| 不是第二本台账，不能改数、不能审核 |
| 每行三件事：**关联核算表**（深链到核算详情）、**对比**（深链到版本对比）、**下载核算表**（重排版 xlsx / 网页预览 / 源附件）| 不在 BP 里渲染核算表明细（逐料、勾稽、留痕都在核算页） |
| 顶部一条：**「有 N 条待你终审 → 去核算终审」**（财务BP 在核算工作台做终审）| 不在 BP 里做终审弹窗 |

## 1. 数据来源（都已上线）

| 接口 | 用途 | 鉴权 |
|---|---|---|
| `GET /api/bomcost/final` | 台账行（已审核对外版），每行含 `links{detailUrl,compareUrl,previewUrl,downloadUrl,originalUrl}`、`supersedes[]`；顶层 `pendingFinalCount` / `warnings[]` | `X-Internal-Token` + 回环，或门户登录 |
| `GET /api/bomcost/pending-final` | 待终审明细：`count` + `rows[{entryId,cpCode,productName,erpCode,channel,fullIncl,firstReviewedBy/At,replaces[],finalReviewUrl}]` + `listUrl` | 同上 |
| `GET /api/bom/export/pretty?entry_id=&preview=0/1` | 重排版 xlsx（活公式）/ 网页预览（值） | 门户用户须「导出」权限；**内部令牌只准拿已审核版**（初审版 403） |
| `GET /api/bom/export/original?entry_id=` | 源附件原样（无留档 404，前端退到重排版） | 同上 |

## 2. 链接怎么拼

`links.*` 与 `finalReviewUrl` 都是**相对核算门户根的路径**，BP 前端拼上门户域名即可（同机 nginx：核算在 `/`，BP 在 `/bp/`）。

- 页面类（`/#/bomstd?entry=17`、`…&compare=1`、`…&final=1`）：**新标签页打开**。核算 SPA 登录后按 hash 直落「标准成本台账」并直开详情 / 对比 / 终审弹窗；用户没登录会先到登录页，登录后继续。`&final=1` 而用户无终审权限 → 退到详情。
- 文件类（`/api/bom/export/...`）两种用法都行：
  - **用户浏览器直开**（走门户登录 cookie，须有「导出」权限）——最简单，推荐；
  - **BP 后台代拉**（带 `X-Internal-Token`，回环 `127.0.0.1:8000`）再回给用户——用户不需要核算侧导出权限时用。注意内部令牌只放行已审核版。

## 3. 页面建议（BP 侧自己定样式）

```
[ 标准成本台账（只读 · 来自核算工作台 · 最近同步 2026-09-05 21:10）]   [ 同步 ]
⚑ 有 2 条待你终审 → 去核算终审                                    ← pendingFinalCount>0 才显示；点 finalReviewUrl 或 listUrl
──────────────────────────────────────────────────────────────────────
物料编码  CP码  产品  规格  净重kg  原料  包材  加工费  装卸费  管理费  全成本  审核日期  渠道  引用次数  操作
300600092 CP05… 原味糯米丸子 1kg/袋 1.0  6.52  0.71  1.60   0.00   0.50   9.34   09-05    通品   3个方案   核算表 › | 对比 › | 下载 ▾
```

- **引用次数**＝BP 自己的 `pricingMaterial` 反查（哪些定价方案引用了这行），核算侧不知道、也不该知道。
- 「下载 ▾」三项：重排版 xlsx（`downloadUrl`）/ 网页预览（`previewUrl`，新标签页）/ 源附件（`originalUrl`，404 时灰掉）。
- 行内若 `supersedes` 非空，标「替代 CP0001」，并把引用 CP0001 的方案打「成本已更新」（见回复文档 §6）。
- `netWeightKg` 为 null 的行标「未填净重」，BP 别按袋换算。
- `erpCode` 为空的行**照常显示**（未中试的新品本来没编码，见回复文档 §7），只是不能按编码关联，用 `productKey` 关联。

## 4. 同步口径（重申）

- 增量：`since=上次 asOf`（按**终审时间**）；全量：不传 since。
- 身份键：`productKey`（建议，§7）；`erpCode` 为属性，有则挂。
- 同一 `erpCode` 接口保证只返一行；`warnings` 只记日志。
- 数值含税、元/kg；`transIncl` 恒 0；台账来源物料不叠 5% 管理费系数。

## 5. 权限

- BP 用户要在核算工作台看核算表：核算侧账号管理给 `enter:bomstd`（标准台账准入）+ 需要下载再给 `bom:export`；要终审给 `bom:final_review`。
- 内部令牌：两边 `.env` 同值 `BOMCOST_INTERNAL_TOKEN`（凭据不进代码不进文档）。
