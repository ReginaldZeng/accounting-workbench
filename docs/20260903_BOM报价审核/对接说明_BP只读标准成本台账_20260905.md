# 对接说明 · BP 工作台「只读标准成本台账」（核算侧 V2.442 已备口，BP 侧照此做页面）

> 2026-09-05 核算工作台线 → BP 工作台线（01 项目）。配套《对接需求_BP消费接口_20260905》与《对接确认_核算侧回复》§1–§8。
> 业务方定的原则：**入口在 BP，动作在核算。** BP 页面只放链接和数字，审核、对比、下载都在核算工作台完成，两边不重复做一套审核流。

## 0. 这页是什么、不是什么

| 是 | 不是 |
|---|---|
| 一张**只读镜像**：核算侧「已审核·对外」的标准成本（含税五分项 元/kg + 单位净重）| 不是第二本台账，不能改数、不能审核 |
| 每行三件事：**关联核算表**（深链到核算详情）、**对比**（深链到版本对比）、**下载核算表**（重排版 xlsx / 网页预览 / 源附件）| 不在 BP 里渲染核算表明细（逐料、勾稽、留痕都在核算页） |
| 顶部一条：**「有 N 条待你终审 → 去核算终审」**（财务BP 在核算工作台做终审）| 不在 BP 里做终审弹窗 |

> ⚠ **2026-09-06 口径更新（V2.451）**：业务方定「BP 侧想看核算表的就在 BP 侧看，除非主管理员」「下载的核算表要分版本」。
> 因此**「关联核算表」不再深链到核算工作台**（那是主管理员专用），而是 BP 页面用 `GET /api/bomcost/sheet` 自己渲染**脱敏版**核算表；
> 下载走 `GET /api/bomcost/export`（脱敏版 xlsx / 预览）。原版附件不给 BP。下文 §1/§2 已按此改，§3 页面示意里「核算表 ›」＝打开 BP 自己的脱敏核算表页。

## 1. 数据来源（都已上线）

| 接口 | 用途 | 鉴权 |
|---|---|---|
| `GET /api/bomcost/final` | 台账行（已审核对外版），每行含 `links{sheetUrl,previewUrl,downloadUrl,adminDetailUrl,adminCompareUrl}`、`supersedes[]`、`variantGroup/variants[]`；顶层 `pendingFinalCount` / `warnings[]` | `X-Internal-Token` + 回环，或门户登录 |
| `GET /api/bomcost/sheet?entryId=` | **脱敏版核算表 JSON**（BP 自己渲染）：头部、五分项、物料行（型号/规格/供应商已置空）、勾稽、`hiddenColumns` | 同上；只准已审核版 |
| `GET /api/bomcost/export?entryId=&preview=0/1` | **脱敏版**重排版 xlsx（活公式）/ 网页预览 | 同上；只准已审核版 |
| `GET /api/bomcost/pending-final` | 待终审明细：`count` + `rows[{…,finalReviewUrl}]` + `listUrl` | 同上 |

⛔ `GET /api/bom/export/*`（全量重排版 / 原版附件）**对内部令牌 403**——全量只给核算工作台内部账号；BP 不拿原版附件。

## 2. 链接怎么用

`links.*` 与 `finalReviewUrl` 都是**相对核算门户根的路径**（同机 nginx：核算在 `/`，BP 在 `/bp/`）。

- **`sheetUrl` / `previewUrl` / `downloadUrl`（脱敏版）**：BP 后台带 `X-Internal-Token` 回环拉（`127.0.0.1:8000`），`sheetUrl` 拿 JSON 自己渲染核算表页；`previewUrl` 拿 HTML 可 iframe；`downloadUrl` 拿 xlsx 回给用户。**不要让用户浏览器直开这三条**（用户没有核算侧会话）。
- **`adminDetailUrl` / `adminCompareUrl`（核算工作台深链，全量）**：**只对主管理员显示**（Owner / 总监），新标签页打开，核算 SPA 登录后直落详情 / 对比。普通 BP 用户不放这两个按钮。
- **`finalReviewUrl`**：财务BP 终审入口，新标签页跳核算工作台（需 `bom:final_review`）。

## 3. 页面建议（BP 侧自己定样式）

```
[ 标准成本台账（只读 · 来自核算工作台 · 最近同步 2026-09-05 21:10）]   [ 同步 ]
⚑ 有 2 条待你终审 → 去核算终审                                    ← pendingFinalCount>0 才显示；点 finalReviewUrl 或 listUrl
──────────────────────────────────────────────────────────────────────
物料编码  CP码  产品  规格  净重kg  原料  包材  加工费  装卸费  管理费  全成本  审核日期  渠道  引用次数  操作
300600092 CP05… 原味糯米丸子 1kg/袋 1.0  6.52  0.71  1.60   0.00   0.50   9.34   09-05    通品   3个方案   核算表 › | 对比 › | 下载 ▾
```

- **引用次数**＝BP 自己的 `pricingMaterial` 反查（哪些定价方案引用了这行），核算侧不知道、也不该知道。
- 「核算表 ›」＝打开 BP 自己的脱敏版核算表页（`sheetUrl` 渲染，`hiddenColumns` 里的列不显示表头）；「下载 ▾」两项：脱敏版 xlsx（`downloadUrl`）/ 网页预览（`previewUrl`）。主管理员多一个「去核算看全量 ›」（`adminDetailUrl`）。
- 行内若 `supersedes` 非空，标「替代 CP0001」，并把引用 CP0001 的方案打「成本已更新」（见回复文档 §6）。
- `netWeightKg` 只是**规格解析参考值**（V2.445 起核算侧不确认、不设闸）：BP 物料表自己维护「最小销售单元 + 单位净重」，可用它预填、由 BP 改定；为 null 的行 BP 手填后再按袋换算。
- `erpCode` 为空的行**照常显示**（未中试的新品本来没编码，见回复文档 §7），只是不能按编码关联，用 `productKey` 关联。

## 4. 同步口径（重申）

- 增量：`since=上次 asOf`（按**终审时间**）；全量：不传 since。
- 身份键：`productKey`（建议，§7）；`erpCode` 为属性，有则挂。
- 同一 `erpCode` 接口保证只返一行；`warnings` 只记日志。
- 数值含税、元/kg；`transIncl` 恒 0；台账来源物料不叠 5% 管理费系数。

## 5. 权限

- BP 用户要在核算工作台看核算表：核算侧账号管理给 `enter:bomstd`（标准台账准入）+ 需要下载再给 `bom:export`；要终审给 `bom:final_review`。
- 内部令牌：两边 `.env` 同值 `BOMCOST_INTERNAL_TOKEN`（凭据不进代码不进文档）。
