## 1. 接口 `GET /api/bomcost/final`（新增，按贵方契约；原 `/api/bom/final` 保留不动）

- **选择口径**：定稿指针 + 状态＝已审核；同一 `productKey` 一版（指针即最新定稿）。
- **参数**：`channel`（接受 `电商/通品/TOB/TOC`，也接受代码 `ecom/common/tob/toc`）、`since`、`erpCodes`（逗号分隔）。
- **响应**：按文档字段；另加 `netWeightSrc`（`manual`＝成本会计确认 / `auto`＝按规格预填待确认 / `""`＝未填）、`firstReviewedBy/At`（初审）、`quotable/quoteReason`（成本会计是否建议对外报价及原因——BP 定价前请看）。
- **数值**含税、元/kg，与列表页同口径（同一 `compose` 函数）。

### 与文档不同的口径（请 BP 侧对齐）

| # | 点 | 核算侧做法 | 为什么 |
|---|---|---|---|
| a | **`finalizedAt/By` 与 `since` 按什么时间** | `finalizedAt/By` ＝ **终审**（成为 `final` 对外的时刻）；`since` 按它增量。初审时间另给 `firstReviewedAt/By`。 | 文档写按初审 `finalized_at` 增量：若一版初审早、终审晚，BP 按初审时间拉会**漏掉**它。对外时刻是终审，增量必须按终审。 |
| b | **时间格式** | 核算侧时间戳**到分**：`YYYY-MM-DD HH:MM`（如 `2026-09-05 20:51`），不是到秒。 | `since` 请**原样传接口回的 `asOf` / `finalizedAt`**（字符串比较），别自己拼到秒的串。 |
| c | **`transIncl`（运输）恒 `0.00`** | 台账「装卸费」＝源表**运输+装卸合并**入账，不单拆运输；`loadIncl` 已含运输。 | BP §4「加工费+装卸费→加工费」会把运输一并带进加工费；「运输费并入产品成本」那条对核算来源实际为 0，**不会双算**，但请勿再另加运费。 |
| d | **`netWeightKg` 可能为 `null`** | 定稿闸上线前已定稿的老行，规格解析不出的返 `null`。 | BP 同 `erpCode:""` 处理：跳过并告警；成本会计在核算侧补填后下次拉到。新定稿的行一律 >0（闸拦）。 |

## 2. 单位净重 `net_weight_kg`

- 列已加（FLOAT），迁移自动跑，服务器无需手工建列。
- 入账**不写库**，改为按 `pack_spec` **实时预填**（`(\d+(\.\d+)?)\s*(kg|g)\s*/\s*(袋|盒|瓶|包|罐)`，g 换 kg，如 `1kg/袋，10袋/箱`→1.0、`500g/盒`→0.5、`10袋/箱`→解析不出留空**不猜**），前端标「按规格预填·待确认」；成本会计在核算表右栏「单位净重(kg)」填/确认 → 存库 + `bom_quote_audit` 留痕（原值→新值）。
- **定稿闸**：空或 ≤0 **不准初审定稿**（两条定稿路径都拦，与勾稽同级），提示「单位净重(kg)未填或≤0——右栏「单位净重」填好并确认再定稿」。
- ⚠ **上线后对成本会计的实际影响**：规格能解析的单子右栏自动带值、点「确认」即可；解析不出的**必须手填才能定稿**。

## 3. 鉴权（服务间调用，不走用户 cookie）

- 放行二选一：① 请求头 `X-Internal-Token` ＝ `BOMCOST_INTERNAL_TOKEN` **且** 来源回环地址（127.0.0.1 / ::1）；② 门户登录用户。否则 **401**。
- 令牌读取：进程环境变量优先（**与 `DB_URL` 同机制**——服务器怎么给 DB_URL 就怎么给它），没有则读 `backend/.env` 的 `BOMCOST_INTERNAL_TOKEN=…`。**凭据只写两边服务器的 .env/环境变量，不进代码、不进本文档。**
- 核算 8000 / BP 8010 同机回环，无跨域。BP 调用示例：`GET http://127.0.0.1:8000/api/bomcost/final?since=2026-09-05 09:58`，头 `X-Internal-Token: <值>`。
