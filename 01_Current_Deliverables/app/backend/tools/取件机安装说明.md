# 报表取件机 · 安装说明

## 这是干什么的

财务核算工作台跑在**腾讯云**上，报表也导在那台服务器上。但公司的 NAS（`10.10.8.251`）在**办公室内网**，
云服务器够不着它——中间隔着防火墙。

让云服务器进内网需要拉 VPN、在防火墙上开入口，运维要审批，而且等于在公司网络上开了个洞。

**所以反过来做**：在公司内网找一台常开的电脑，让它**主动出去把文件取回来**，放进共享盘。
连接方向由内到外，出方向本来就通——**办公室网络一个入口都不用开**。

```
   办公室内网                          公网
 ┌──────────────┐              ┌─────────────┐
 │  这台电脑     │  ──主动出去取──▶  │  工作台服务器 │
 │      │       │              └─────────────┘
 │      ▼       │
 │  NAS 共享盘   │   同事照常从共享盘拿文件，不知道背后是谁放的
 └──────────────┘
```

---

## 选哪台电脑

- **常年开机**的（关机期间不会同步，但开机后下一轮自动补上，不会丢文件）
- 能打开共享盘 `\\10.10.8.251\starfield部门文件夹\...`

**不用装任何软件。** 取件脚本有两个版本，功能完全相同、读同一个配置文件：

| 版本 | 需要什么 | 什么时候用 |
|---|---|---|
| `pull_reports.ps1` | **什么都不用装**（PowerShell 是 Windows 自带的） | **默认用这个** |
| `pull_reports.py` | 要装 Python 3.8+ | 那台电脑本来就有 Python，且你更习惯 Python |

默认走 PowerShell 版，所以**这台电脑不需要装 Python**。

## 三步装好

### 第 1 步：放文件

在那台电脑上建个目录，比如 `D:\报表取件\`，把这三个文件放进去：

- `pull_reports.ps1`（脚本本体，PowerShell 版——默认用这个）
- `pull_hidden.vbs`（无窗口启动器，被计划任务调用；**必须和 .ps1 放同一个目录**）
- `pull_reports.py`（同功能的 Python 版，备选）
- `pull_reports.ini.example`
- `注册定时任务.bat`
- `install_task.ps1`（bat 的内容都在这里）

### 第 2 步：改配置

把 `pull_reports.ini.example` **复制**一份改名为 `pull_reports.ini`，填三项：

```ini
[pull]
server     = http://111.229.72.116          ← 平时打开工作台的网址
pull_token = <管理员给的取件码>               ← 纯英文数字，别放中文
dest_dir   = \\10.10.8.251\starfield部门文件夹\永续风控中心\旧文件\财务部\财务BP\测试
```

> **`dest_dir` 一定要用 `\\10.10.8.251\...` 这种写法，不要写 `Y:\...`。**
> 盘符是"当前登录用户"的映射，定时任务在后台跑时可能根本看不到 Y 盘，会报"目标目录不存在"。

先手工跑一次验证：

```
powershell -ExecutionPolicy Bypass -File "D:\报表取件\pull_reports.ps1"
```

> **这一整条直接粘进去跑，别先 `cd`。** 无论你开的是「命令提示符」还是「Windows PowerShell」都能用。
> ⚠ 别用 `cd /d D:\报表取件` 再跑——`cd /d` 是 **cmd 的语法**，在 PowerShell 里 `cd` 是 `Set-Location` 的
> 别名、不认 `/d`，会报「找不到接受实际参数 "D:\报表取件" 的位置形式参数」，然后因为没切成目录，
> 第二行又报「`-File` 的实际参数 "pull_reports.ps1" 不存在」。

（装了 Python 也可以用 `python "D:\报表取件\pull_reports.py"`，效果一样。）

看到 `下载 8 个、跳过 0 个、失败 0 个` 就成了。再跑一次应该是 `跳过 8 个`（已有的不重复下载）。

### 第 3 步：注册定时任务

**右键 → 以管理员身份运行** `注册定时任务.bat`。它会建一个每分钟跑一次的任务。

装好后可以在「任务计划程序」里看到「财务报表取件机」。

> **装好后桌面上应该什么都看不见**——任务是无窗口跑的。
> 要确认它在干活，看日志文件或工作台页面上的同步时间（见下面那节），不要指望看到窗口。

---

## ⚠ 如果你现在桌面上堆着一叠空白窗口

那是 **V2.241 的毛病，V2.242 已经修了**。当时任务直接起 `powershell.exe`，因为必须跑在
登录用户的会话里（共享盘只在这个会话里存在），所以每分钟在桌面弹一个控制台窗口。
而 Windows 控制台默认开着「快速编辑」——**往窗口里误点一下就会选中文本，进程当场冻住**，
要按 Esc 才继续。于是冻住的窗口一分钟叠一个，同步也跟着悄悄停了。

**怎么修**：把新包解压覆盖到原目录，再**以管理员身份运行一次** `注册定时任务.bat`。
它会先把卡住的旧窗口全部关掉（只关命令行里带 `pull_reports.ps1` 的，不碰别的），
再按新方式重新注册。之后不会再弹任何窗口。

新任务还加了两条护栏：上一轮没跑完就不启动下一轮（不会越叠越多）；单轮超过 5 分钟
由系统强杀、下一分钟重来（共享盘掉线时 SMB 能吊很久）。

---

## ⚠ 关于运行账号（最容易踩的坑）

定时任务默认可能用 `SYSTEM` 账号跑，而 **`SYSTEM` 账号对公司 NAS 没有任何凭据**，
会报"目标目录不存在"或"拒绝访问"——**手工跑好好的，定时任务就是不行**，很容易查半天。

`注册定时任务.bat` 已经设成用**当前登录的这个 Windows 账号**跑。所以：

- 这台电脑要**保持这个账号登录**（可以锁屏，但别注销、别切换用户）
- 如果换了账号或改了密码，重新跑一次那个 bat

## 怎么知道它在正常干活

**看工作台页面**：进「报表板块 › 财务报表 › 报表导出」，第一页上有一行：

> 共享盘同步：立即同步 ↻　**2026-08-07 16:30:12** · 取件机 FIN-PC-01 · 本轮下载 0 个、已有 8 个

那个时间**每分钟都会刷新**。要是停在很久以前不动了，说明这台电脑关机了、或者任务没跑起来。

**看本地日志**：`D:\报表取件\pull_reports.log`（只记有变化的轮次，日志封顶 2000 行不会撑爆盘）。

## 常见问题

| 现象 | 原因 |
|---|---|
| `连不上服务器` | 这台电脑上不了外网，或工作台地址填错 |
| `服务器拒绝（HTTP 403）` | 取件码不对，或服务器 conf.ini 没配 `pull_token` |
| **令牌明明填对了还是 403** | 取件码里放了**中文或空格**。它走 HTTP 请求头传，头里放不了非 ASCII——只能用英文字母数字和 `-_` |
| `目标目录不存在` | 共享盘没连上；或用了 `Y:\` 盘符（改成 `\\10.10.8.251\...`）；或定时任务用了 SYSTEM 账号跑 |
| 手工跑正常、定时任务不行 | 基本都是运行账号问题，见上面那节 |
| 一堆看不懂的 PowerShell 语法错、中文全是乱码 | `pull_reports.ps1` 被存成了「UTF-8 无 BOM」。Windows PowerShell 5.1 没 BOM 会按 GBK 读，中文全乱、引号配对崩掉。**别用记事本另存这个文件**；真改了就用 VS Code 存成 "UTF-8 with BOM" |
| 页面上同步时间不更新 | 这台电脑关机/休眠了，或任务被停了 |
| **桌面上堆了一叠空白窗口** | 装的是 V2.241。见上面那节，升到 V2.242 重新注册一次即可 |
| 装好后桌面上什么都没有 | **这是正常的**，任务本来就无窗口跑。看日志或页面上的同步时间 |
