# 物流费用管理 · 四期路线图 v1.0

> **性质**：物流计提（已上线 V2.29+）与物流对账（内核已落地 V2.44）两个工具的统一排期，按"计提 → 对账 → 付款"业务链推进。
> **状态**：✅ 业务方确认 · 2026-07-09。
> **依据**：物流对账需求确认书 v1.2（Approved Baseline，口径不变）；V2.44 内核跑分（山姆回填 102/102、匹配 75%、差异全捕获）。

## 一期 · 优化计提表、汇总表格式

**目标**：把物流计提表、汇总表改成好填、好看、月月可复用的版式，**口径与对账对齐**。

| 要点 | 内容 |
|---|---|
| 口径对齐 | 维度统一为 承运商 × 费用归属 × 主体 × 账期，与对账差异清单可直接对表 |
| 预留列 | **计提数 / 对账定稿数 / 差异**三列，为三期"定稿回冲/补提"闭环打地基 |
| 输入 | 业务方提供现行计提表/汇总表样表 + 痛点清单（哪里难填、哪里月月手工调） |
| 归属 | 物流计提工具迭代（B 期序列） |

## 二期 · 已回填单据号账单的金蝶比对

**目标**：物流部门已手工回填金蝶单据号的账单（如极鲜达山姆 sheet 的 XSCKD 列），工具**拿单据号直查金蝶**，逐行比对数量、重量、金额——不做自动匹配，先把"比对"这半边跑熟建信任。

| 要点 | 内容 |
|---|---|
| 链路 | 导入账单（含回填单号列）→ 按单号取金蝶出库单（只读）→ 核价核量 → 差异清单 |
| 复用 | V2.44 内核的解析/核价/折算/归因/导出全部复用；**匹配引擎（五信号）本期不启用** |
| 新增 | 单号查无/单号重复/单号与行明显不符（客户对不上）三种校验提示 |
| 边界 | 未回填单号的行如实标「待人工」，不猜 |
| DoD | 极鲜达 6 月山姆 sheet 逐行比对结果与 V2.44 跑分一致；单号查无行正确单列 |

## 三期 · 原始账单核对上线

**目标**：不依赖人工回填，对原始账单全流程自动核对，替代物流部门手工回填工序。

| 要点 | 内容 |
|---|---|
| 内容 | 五步工作流屏（账单导入→金蝶取数→匹配确认→差异稽核→清单出具）+ 价格卡/别名表/多候选点选界面 + **匹配引擎（五信号+对账组）启用** + 常用 5 家承运商模板与合同铺开 |
| 结算定稿 | 差异人工判断完 → 每承运商每账期**定稿金额锁定留痕**（四期付款的数据源头） |
| 产出 | 《差异清单》《单号回填版账单》界面化导出；计提表"对账定稿数/差异"列回填（接一期格式） |
| DoD | 按需求确认书 v1.2 §11（山姆 102/102、自动匹配 ≥70%、差异全捕获、三道勾稽） |

## 四期 · 钉钉付款申请

**目标**：定稿金额一键生成钉钉付款审批申请，付款申请自带证据链。

| 要点 | 内容 |
|---|---|
| 触发原则 | **人工触发**——人点了才发起，工具绝不自动发；发起记录本地留痕（谁/何时/金额/对应定稿） |
| 证据链 | 审批单携带定稿金额 + 差异清单 + 单号回填账单附件 |
| 卡点 | **发票金额 = 定稿金额一致才允许发起**，不一致拦下提示 |
| 前置协调 | 钉钉审批模板归属（沿用现有付款模板 or 新建"物流费结算"模板）需与钉钉管理员确认；企业应用 appKey/appSecret 申请 |
| 依赖 | 三期"结算定稿"状态 |
