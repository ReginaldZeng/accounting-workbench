# 月度流水包 · 交付标准（发出纳）

> 依据《银行对账工具·需求确认书 v1.4》§2，随 v1.4 签署生效。每月结账前，把当月全部银行/支付流水按下面的标准打包交给核算组（或自行上传）。

## 一、打包（2 条）

1. **整个流水文件夹打成一个压缩包**。**首选 ZIP**；RAR 也能直传（系统已实测支持）。
2. **可以加密**。加密了就**必须把密码一并送到**（钉钉单独发给上传的人，别丢群里）——上传时填在页面「压缩包密码」框，系统不保存密码、不进日志。只给包不给密码，系统会停下来要密码。

## 二、包里要有什么（4 必含 + 随意项）

| 必含 | 文件长相 | 说明 |
|---|---|---|
| ① 财资平台明细（宁波+招商） | xlsx | **一次全量导出**：全部账户、整个自然月。⚠ 注意导出行数上限——如果平台提示截断，扩大范围重导一次**全的**，删掉不全的那份再打包（多份也能兜住，但别当常态） |
| ② 中行流水 | HISQRY-**当月起止日**-….csv | 按整月区间导出 |
| ③ 支付宝账务组合查询 | 2088…-账务组合查询.xls.zip | 各账号都要 |
| ④ 抖音流水 | DL….csv | 有则必含 |

回单、余额/收支证明、资产证明、理财持仓、网银截图——**可以随包带**，系统会自动跳过登记，不算错。

- **文件名尽量保留系统导出的原名**（改名系统多数认得出，但别把非流水文件改成流水样式的名字）。
- 微信流水：近两月包里均未出现——渠道是否仍在用，以确认书 Q1 的答复为准。

## 三、上传后（给上传的人）

1. 系统解析完会列清单：哪些并入了、哪些跳过了，逐个文件有交代。
2. 如果包里有**多份财资导出**，会弹「重复判定确认」窗——**逐条核对后点确认**（确认人和时间会留痕入审计）。如果窗里出现红色「⚠ 疑漏」，先别确认，按提示核对，属导出不全的退回重导。
3. 上传错了直接重传，新包覆盖本期、有留痕。

## 四、一句话版

> **一个包（ZIP 优先）＋ 密码随包到 ＋ 财资一次导全 ＋ 四类流水齐 ＝ 合格交付。**
