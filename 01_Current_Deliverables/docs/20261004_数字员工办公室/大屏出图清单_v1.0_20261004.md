## 先说怎么分工

| 谁 | 做什么 |
|---|---|
| 生图工具 | 只管**画**：一张办公室底图 + 每个小人的动作图集 |
| 代码（Claude） | 所有**会变的东西**：状态灯、名字牌、数字、气泡、Zzz、谁坐哪、谁在走路 |

所以图里**一个字都不要有**（中文会被画成乱码），也不要画状态灯、气泡、问号、Zzz——这些都由代码叠上去。

---

## 四条硬规矩（每一张图都要守）

1. **不照任何真人画。** 人物是虚构的岗位形象，不参考照片，不像任何一位同事。
2. **图里没有字、没有商标。** 门牌、招牌、屏幕、文件上都留空白或画成抽象线条。
3. **视角、光源、比例全程一致。** 所有图都是同一个斜上方俯视角度、光从左上来、同一套色板；小人在每张图集里一样大。
4. **人物图必须能抠出来。** 能出透明底就出透明底；出不了就用**纯绿色背景 `#00FF00`**（不要画棋盘格假透明），人物身上不要用这个绿。

## 第 0 步：先定画风（出 2 张给业务方挑，挑完再往下画）

**这一步不挑定，后面不要画。**

画同一间办公室的两种画风，各一张，1920×1080：

- **候选 A · 精细像素风**：高清像素画，像素块清楚、轮廓有阶梯感、色板有限，温暖、有生活气。
- **候选 B · 干净的半写实插画风**：平滑的手绘插画，柔和阴影，不是像素、不是照片、不是 3D 渲染。

两张都按下面「办公室长什么样」来画，都带上 6～8 个小人坐在工位上（这一张可以带人，只为看整体感觉）。

> 给生图工具的话：
> 画一间现代写字楼里的财务部办公室，斜上方俯视（镜头在前上方往下看，后墙在画面上方，地面朝向观众，正交无透视变形）。暖白墙面、灰蓝地毯、浅木色桌面，光从左上方照进来，干净明亮。三排工位，每排四张桌子，员工都面朝观众坐着办公。左墙一排灰色文件柜，后墙有带百叶的窗。左上角一间小机房，右上角茶水间，左下角休息区有沙发，右下角一个交接柜台。画面中不要出现任何文字和商标。人物是虚构的 Q 版上班族，约三头身，不参考任何真人。
> 画风：【A 精细像素风 / B 半写实插画风】。

**业务方挑定后**，把那张存成 `00-style-approved.png`，后面每一步都把它当画风参考图喂给工具。

## 第 1 步：办公室底图（1 张，没有人、没有椅子）

- 文件：`office-bg.png`，**3840×2160**（出不了这么大就 1920×1080，但要清晰）
- 不透明，整张铺满

### 办公室长什么样

```
┌──────────────────────── 后墙（带百叶的窗）────────────────────────┐
│  取件间              │                               │  茶水间     │
│  （一张长桌上        │                               │ （吧台、咖啡 │
│   三台台式电脑）     │                               │  机、饮水机）│
├──────────────────────┘                               └─────────────┤
│ 文                                                                 │
│ 件   第一排工位：  □   □   □   □                                   │
│ 柜                                                                 │
│ 一   第二排工位：  □   □   □   □                    打印机         │
│ 排                                                                 │
│      第三排工位：  □   □   □   □                                   │
│                                                                    │
│  休息区                                              交接台        │
│ （沙发、茶几、绿植）        门 / 前台（空白招牌）   （一个柜台，    │
│                                                      上面有文件筐） │
└────────────────────────────────────────────────────────────────────┘
```

### 画的时候必须满足

1. **12 张工位桌，3 排 × 4 列，排得整整齐齐**（横平竖直、间距相等）。现在用 9 张，另外 3 张留着以后加工位。
2. **所有人都面朝观众坐**：人坐在桌子的**后面**（画面上方那一侧），所以每张桌子后面要**留出一块空地**放椅子和人，那块地上不要画任何东西。
3. **底图里不要画椅子，也不要画人**（椅子和人是单独的图，由代码放上去）。
4. **每张桌上一台显示器**，放在桌子偏左或偏右的位置（不要挡在正中间，否则会挡住人脸）。显示器背面朝观众，**屏幕关着、不发光**。每张桌子的显示器放在同一侧。
5. 桌上可以有键盘、鼠标、文件、计算器、水杯、小盆栽——每张桌子略有不同，但**桌面中间靠后的位置留空**（人的手要搭在那里）。
6. 相邻工位之间可以有矮隔板，但**不能高过桌面太多**，不能挡住后一排的人。
7. **排与排之间的过道要够宽**——至少能站下一个小人还不碰到前后桌子（小人要在过道里走）。
8. **取件间**：三台电脑要分得开、数得清（每台对应一台真的取件机，代码会在上面点灯）。
9. **交接台**：柜台上放一个空的文件筐（「等人接手」的文件由代码往上摞）。
10. **茶水间**：吧台前面留出能站两个人的空地。**休息区**：沙发正面朝观众，能坐两个人。
11. 前台的招牌、后墙的门牌都**画成空白牌子**，字由代码写。
12. 工位区的地面用**同一种颜色的地毯**，不要分区着色（分区由代码叠一层淡色）。

> 给生图工具的话：
> 以 00-style-approved.png 为画风参考，画同一间办公室的**空场景底图**：没有任何人物，没有任何椅子，没有任何文字。保持相同的视角、光源、色板。3 排 × 4 列共 12 张工位桌，横平竖直、间距相等；每张桌子后方（画面上方一侧）留出一块空地面；每张桌上一台背面朝观众、屏幕关闭的显示器，放在桌子同一侧不居中；排间过道宽敞。左上取件间一张长桌上三台分开摆放的台式电脑；右上茶水间有吧台、咖啡机、饮水机，吧台前留空地；左墙一排文件柜；右侧一台打印机；左下休息区有一张正面朝观众的双人沙发、茶几和绿植；右下交接柜台上放一个空文件筐；下方中间是门和前台，招牌是空白牌子。

**可选的第二张**：`office-fg.png`，同尺寸、透明底，只画「应该挡在小人前面」的东西（前台柜台、画面最下方的绿植）。没有也行，代码会让小人不走到那些东西后面去。

## 第 3 步：每个人的「坐姿图集」（9 张，这一批画完就够上线）

- 文件：`char-01-seated.png` … `char-09-seated.png`
- 每张 **4 列 × 2 行 = 8 格**，每格 **256×256**，整张 1024×512，绿幕或透明底
- 喂给工具两张参考图：`00-style-approved.png`（画风）和 `cast-approved.png`（这个人长什么样）

### 每一格怎么画

**统一要求**：人**面朝观众**坐在办公椅上，**只画腰以上**（腰以下会被桌子挡住，不用画）；椅背从肩膀后面露出来，**椅子画在同一张图里**；人在格子里**水平居中、底边贴着格子下沿**（腰部那条线是平的）；8 格里人一样大、位置一样。

| 格子 | 画什么 | 代码用在哪 |
|---|---|---|
| 第 1 行第 1 格 | 双手在键盘上打字，手位 A | 正在干活 |
| 第 1 行第 2 格 | 同上，手位 B（两格轮流放就是打字动画） | 正在干活 |
| 第 1 行第 3 格 | 手放在桌上，看着前方，放松 | 在岗、现在没活 |
| 第 1 行第 4 格 | 一只手端着杯子喝水 | 在岗、现在没活 |
| 第 2 行第 1 格 | 一只手挠头，表情困惑 | 上一轮出错了 |
| 第 2 行第 2 格 | 同上，手的位置稍变（两格轮流放） | 上一轮出错了 |
| 第 2 行第 3 格 | 趴在桌上睡着了，头枕着手臂 | 停了 |
| 第 2 行第 4 格 | 同上，身体稍微起伏（两格轮流放是呼吸） | 停了 |

不要画问号、叹号、Zzz、汗滴这类符号——代码会加。

另外单独一张 **`chair-empty.png`**（256×256）：同样的取景，只有一把空椅子，没有人。用在「没上岗」的工位。

> 给生图工具的话（每个人一次）：
> 以 cast-approved.png 中【第 N 个人】为身份参考，人物、发型、服装、配色保持不变；以 00-style-approved.png 为画风参考。生成一张 4 列 × 2 行的图集，画布 1024×512，每格 256×256，纯绿色 #00FF00 背景。每格都是这个人面朝观众坐在黑色办公椅上、只画腰部以上、椅背从肩后露出、人物水平居中、底边贴格子下沿、8 格大小位置一致。从左到右、从上到下依次是：打字手位 A、打字手位 B、双手放桌上放松看前方、单手端杯喝水、单手挠头困惑、挠头手位稍变、趴在桌上睡觉、趴睡身体稍起伏。不要画任何文字和符号，不画桌子，不画显示器。

放到一个文件夹里（建议 `D:\0 Claude 数据\05 数字员工办公室\03_Source_Materials\大屏素材\`），文件名照上面的来：

```
00-style-approved.png      画风定稿
```

## 每张图自己先查一遍

- [ ] 图里没有任何文字、商标
- [ ] 视角、光源和画风定稿一致
- [ ] 人物和定稿是同一个人（发型、衣服、配色没变）
- [ ] 图集每格一样大，人在格子里的位置和大小一致，没有画出格
- [ ] 背景是真透明或纯绿 `#00FF00`，不是棋盘格
- [ ] 底图里没有人、没有椅子；12 张桌子横平竖直；每张桌子后面留了空地
- [ ] 没有画状态灯、气泡、问号、Zzz

## 图到了以后 Claude 做什么

1. 抠掉绿幕、裁成一格一格、压缩（原图太大，不直接进仓库）。
2. 在底图上标出每个工位的座位点、显示器位置、过道、茶水间和沙发的站位（做一个点一下就记坐标的小页面，标一次存下来）。
3. 把现在这版大屏的画面换成「底图 + 小人」，数据、状态判断、大屏链接都不动。
4. 状态灯、名字牌、数字、气泡、分区的淡色，全部由代码叠在图上。
5. 现在这版矢量画的大屏留着当备用：图没加载出来时自动退回它。
