## 1. 目标

银行流水 × 金蝶序时账**逐笔勾稽**,自动找出**漏账 / 做错 / 晚记**;每笔结论可追到凭证号;结果附三道勾稽自证可信。**只读金蝶,不做账,只出清单交人工。**

## 2. 范围

| 含 | 不含 |
|---|---|
| 流水归一化 · 账户台账 · 逐笔稽核 · 余额调节 · 资金看板 · 金蝶只读取数 · 理财对账 · 共享盘上行取件机 + 停机告警 | 写回/修改金蝶 · 自动做账 |

## 3. 对账状态模型（每笔银行流水恰归一类）

| 状态 | 定义 | 处理 |
|---|---|---|
| 疑似漏账 | 银行有、金蝶整窗口查无 | ★最优先,补账 |
| 做错·金额 | 配对上但金额不等（比到4位小数） | 核金额、补账 |
| 晚记（本月/跨期） | 金蝶入账日晚于银行日≥1天 | 关注跨期 |
| 金蝶单边·待查 | 金蝶有、银行无 | 疑金蝶做错,冲/改 |
| 疑记错户 | 同额同向、记到他户且对方户名命中他户凭证 | 核是否记错账户 |
| 内部往来·双腿 | 集团内部划转,标每腿做账状态;两边查无→双标未做账 | 核两腿是否做账 |
| 组合待确认 | 银行1笔=金蝶2~3张合计相等（如理财本金+收益） | 人工确认,不自动核销 |
| 账户缺金蝶数据 | 整户银行有流水、金蝶本期零动静 | 确认金蝶取数/补记 |
| 已匹配 | 金额(4位)+方向+当天+置信度达标 | 已核 |

> 铁律:**宁标"待人工确认",也不猜错**;低置信度强制复核。

## 4. 业务口径（R1–R13，已锁定）

| # | 口径 |
|---|---|
| R1 | 银行收=金蝶借,银行支=金蝶贷 |
| R2 | 金额比对到**4位小数**（金蝶4位属正常,不当"小数点错"） |
| R3 | 取数窗口:银行取目标月;金蝶序时账取"目标月+后续" |
| R4/R5 | 准时=金蝶日=银行日当天;晚≥1天分本月/跨期;配对可跨窗、准时线独立卡当天 |
| R6 | 未结账月金蝶期末=期初+序时账净 |
| R8/R9 | 只"银行账户"类进匹配桥;唯一命中→映射,短号/掩码/多义→单列不猜 |
| R10 | 金蝶单边→待查,不定性为错 |
| R11 | 每笔给高/中/低置信度,低强制复核 |
| R12 | 1:1为核心+组合候选交人工 |
| R13 | 银行余额取流水**最新一笔**（按完整交易时间,同日多笔取真末笔） |

## 5. 数据接入（双通道）

| 通道 | 说明 |
|---|---|
| **共享盘上行取件机**（主,推荐） | 出纳把流水按月存共享盘;常开内网电脑每小时扫→推服务器→自动解析定格。出纳零操作 |
| **手工上传**（应急） | 整月流水打一个压缩包上传;加密包填「压缩包密码」（不落盘） |

**共用铁律**:①自动推不覆盖人工上传;②保留人工确认闸(不自动确认);③传完才推。
**财资多份导出**:每份都解析、按账户整户择优并入、让位份逐笔查重;出现让位/重复/疑漏→**弹窗人工确认、留痕**。
**停机告警**:取件机超约2小时没回报→风控AI机器人发钉钉给指定人(前端配);页面同步红灯。

## 6. 余额调节表（对标《各银行余额》)

全四类科目逐户:**银行流水余额 · 汇率 · 综合本位币 · 金蝶系统余额 · 未达调节 · 调节后差额 · 备注**。
- 差额=**调节后残差**（未达账项调节后）:能解释的→0;仍≠0→标「本月差异 / 流水不平·核对流水」;
- 银行侧来源:银行存款取流水、电商渠道取渠道对账、其余待人工手填;
- 开户日期在**账户台账**维护、本表引用;支持导出 Excel 单月扁表。

## 7. 可信度报告（每次稽核自动产出,三道全过才算可信）

1. 笔数勾稽:每笔恰归一类、不重不漏;
2. 余额勾稽:期初+Σ收−Σ支=期末;
3. 数据齐:Σ收/支对自带汇总(4位),金蝶单边>0提示流水可能未导全。

## 8. 非功能

只读金蝶 · 密码不落盘不进日志 · 令牌鉴权 · 进页面读缓存秒开(仅"接入金蝶"实时取数) · 冷灰Linear风 · 1920×1080@125%/150%可用 · 已上财务服务器集中部署。
