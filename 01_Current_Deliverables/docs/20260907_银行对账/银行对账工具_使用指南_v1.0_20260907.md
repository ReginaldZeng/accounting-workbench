## 1. 开始之前

- **打开**：浏览器访问工作台地址，用你的账号登录（三个工作台共用一套账号）。
- **权限**：上传 / 接入流水需要「**上传资金流水**」权限；没有的话找管理员在账号管理里开。
- **选对期间**：右上角**会计期间**选择器决定你在对哪个月。**先选对月份再操作**——所有数据按期间定格，选错月会红字警告"可能选错月份"。
- **只读金蝶**：工具全程**不改金蝶**，只把金蝶数据读出来和银行流水比对。放心用，不会动账。

## 2. 四步主线总览

页面顶部的**步骤链路条**始终跟着你走，四步依次是：

| 步 | 名称 | 你在这一步干什么 |
|---|---|---|
| ① | **数据接入** | 让银行流水进来（自动或手工）+ 一键接金蝶取数 |
| ② | **逐笔稽核** | 看每笔银行流水的对账结论：漏账 / 做错 / 晚记 / 已匹配…… |
| ③ | **余额调节** | 三栏对平，确认期末余额对得上 |
| ④ | **结果出具** | 看《可信度报告》三道勾稽、导出差异清单 |

**优先核什么**：疑似漏账（银行出账了、金蝶没做账）永远排最前，先看它。

## 3. 第一步 · 数据接入

数据接入有**两条通道**，任选其一（推荐 A）。

### 3.A 共享盘自动接入（推荐 · 出纳零操作）

出纳把当月流水按月存进共享盘（如 `\\10.10.8.251\...\资金流水\2026年\{月}\`），**剩下的全自动**——一台常开内网电脑上的「取件机」每小时扫一次、把散件推给服务器，服务器自动解析、按期间定格入库。出纳**不用打包、不用加密、不用填密码、不用上传**。

**怎么看它在不在干活——「共享盘取件机」状态卡**：

| 看到 | 含义 |
|---|---|
| 🟢 **绿色呼吸灯 · 在跑** | 正常。卡上显示最近扫描时间、上轮推送几个文件、等待中的月份 |
| 🔴 **红色 · 停机** | 取件机超约 2 小时没回报——那台内网电脑可能关机了、或计划任务停了。**此时新流水不会自动进来**，请联系管理员，期间用手工上传（3.B）兜底 |

**「立即扫描共享盘」按钮**：出纳临时更新了共享盘、你不想等下一个整点，点它——取件机下一轮来问时会立刻扫（服务器进不了内网，这个按钮是"留个话"，不是马上扫）。

**🔔 停机钉钉告警（建议配一下）**：状态卡里点「🔔 停机钉钉告警 → 设置」，填要收告警的钉钉手机号（多个用逗号隔开）保存。以后取件机停了会**自动发钉钉**提醒这些人，不必盯着页面。收起后会显示打码号码（如 `136****3676`）方便你核对配了谁。

### 3.B 手工上传流水包（应急 / 补传）

取件机停机、或临时补传时用。步骤：

1. 出纳把当月整个流水文件夹打成**一个压缩包**（首选 `.zip`，`.rar` 也行）；
2. 在「① 上传资金流水」选择文件；加密包在右侧「压缩包密码」框填密码（**密码不落盘、不进日志、工具不保存**）；
3. 上传即解析、按当前所选期间定格入库。

**包里该有什么**（详见交付规范）：财资平台明细（宁波 + 招商）、中行 HISQRY（全月）、支付宝账务查询、抖音 csv。回单 / 余额证明 / 理财持仓 / 截图可以带，工具会自动跳过、折叠列示，不算错。

### 3.C 财资导了多份 / 重复确认弹窗（两条通道都会遇到）

出纳经常把财资平台**导出好几次**（一次比一次全，第 1 份可能被平台 200 行上限截断）。工具会：

- **每份都解析**，按**账户**整户取笔数最多的那份并入，让位的份逐笔查重证明是"子集"；
- 上传 / 推送后**弹窗**逐条列示：▶并入（绿）／ 重复（是子集、不重复并入）／ **⚠核对**（有笔只在这份里、疑似漏账）；
- 你必须逐条看过、点「**我已逐条核对，确认重复判定**」才算完——**谁确认、什么时候确认都留痕**。没确认前状态行一直琥珀提醒、每次进页面重新弹。

> ⚠ **看到「⚠核对 / 疑漏 > 0」怎么办**：说明有笔只出现在被让位的那份导出里，可能是两次导出范围不同漏了账。先人工核对；确属导出范围问题，退回出纳按规范重新做一次全量导出再传。**机器只做初核，判定责任在人。**

### 3.D 一键接金蝶取数

银行流水进来后，点「**一键接入金蝶**」，工具只读取金蝶四类数据（序时账取"目标月 + 后续窗口"，好抓跨月晚记）。**平时进页面是秒开的**（读缓存），只有点这个按钮才实时打金蝶。

## 4. 第二步 · 逐笔稽核（核心）

这是你花时间最多的地方。工具已经把每笔银行流水**恰好归成一类**，你按类去核。

### 4.1 七类状态怎么读

| 状态 | 什么意思 | 怎么处理 |
|---|---|---|
| 🔴 **疑似漏账** | 银行有这笔、金蝶整个窗口都查不到 | **最高优先**，先核。看是不是真漏做账，据补账建议补 |
| 🟠 **做错·金额** | 配上了但金额不等（比到 4 位小数，差额显示到 4 位） | 核金额差，生成补账建议 |
| 🟡 **晚记·本月** | 配上了，金蝶比银行晚 ≥1 天但没跨月 | 确认即可（影响小） |
| 🟠 **跨期晚记** | 金蝶跨了会计月才入账 | 关注：会扭曲期末 |
| 🔵 **金蝶单边·待查** | 金蝶有、银行没有 | 查银行流水是不是没导全 |
| ⚪ **账号对不上台账** | 账号在台账里唯一对不上（掩码 / 短号 / 一号多主体） | 单列交人工，或补台账 |
| ✅ **已匹配** | 金额（4 位）等、同向、同天、置信度够 | 已核，不用管 |

> **关于 4 位小数**：金蝶因设置有时产生 4 位小数（如 .7478）是**正常的**，工具不会把它当"小数点错"。只有真金额差才归「做错·金额」。

**置信度列**：每笔匹配标 高 / 中 / 低。**低置信度的强制复核**（候选多、或日期离得远、或对方 / 摘要对不上）。

### 4.2 三类特殊情形（工具只标候选、不自动核销）

| 情形 | 长什么样 | 你要做的 |
|---|---|---|
| **组合待确认** | 银行 1 笔 = 金蝶 2~3 张合计分毫不差（如理财赎回拆"本金 + 收益"） | 看随行列出的整组等式（含各凭证号），确认是不是同一笔的拆分 |
| **疑记错户·账在他户** | 同额同向、日差 ≤3 天、但记在别的户，且银行对方户名命中他户凭证摘要 | 工具指认"账已记在 ×户 记-XX"，两腿并一行；核是不是记错了户 |
| **内部往来·两腿列示 + 双漏** | 集团内部划转；两户一收一支同额、金蝶两边都查无 → 双标「未做账」 | 核这笔内部划转是不是两边都漏做了（实证抓出过 450 万未做账） |

### 4.3 筛选与搜索

- **按状态筛选**：只看"疑似漏账"、只看"做错"……
- **搜索**：关键字模糊（户名 / 摘要 / 制单人都能搜）、金额精确。
- **行内下钻**：点开某笔看它配对的金蝶凭证明细、钱账两栏对照。

## 5. 第三步 · 余额调节

三栏对平，确认**期初 + 本期发生 = 期末**对得上。未结账月的金蝶期末 = 期初 + 序时账（借 − 贷）实时重算，不依赖金蝶存储的滞后余额。银行余额取归一化流水里最新的「余额」；本期没有就显示「本月未更新」。

---

## 6. 第四步 · 结果出具

### 6.1 《可信度报告》三道勾稽（自动产出）

每次稽核工具自动跑三道自检，抬头就能看到状态：

1. **笔数勾稽**：每笔恰归一类、不重复，合计与来源一致；
2. **余额勾稽**：期初 + Σ收 − Σ支 = 期末；
3. **数据齐（总额）**：收 / 支合计对上各家自带汇总（比到 4 位小数）；金蝶单边 > 0 时提示"银行流水可能未导全"。

> **三道全过 = 本次结果可信**。有一道没过，工具标「待复核」并告诉你是哪道没过、为什么。

### 6.2 导出

把差异清单（漏账 / 做错 / 晚记）导出，落到可抽查的成品（每笔可回到凭证号），交人工核 / 补账。

## 7. 每月标准流程（速查）

```
选对会计期间
   ↓
① 确认银行流水已接入
   · 自动：看「共享盘取件机」是绿灯，本月数据已进来
   · 手工：上传当月压缩包（加密的填密码）
   ↓
   遇到财资多份 / 重复弹窗 → 逐条核对 → 点「确认重复判定」
   ↓
② 点「一键接入金蝶」取数
   ↓
③ 进「逐笔稽核」：先核【疑似漏账】，再核【做错·金额】，
   顺带看【组合待确认 / 疑记错户 / 内部往来】
   ↓
④ 进「余额调节」三栏对平
   ↓
⑤ 进「结果出具」：确认《可信度报告》三道全过 → 导出差异清单
```

## 8. 取件机部署与停机告警（系统管理员）

### 8.1 首次部署取件机

1. 选一台**常开的内网电脑**（能在资源管理器里看见共享盘）；
2. 把取件机脚本 + `bank_pull.ini` 放上去，`bank_pull.ini` 里的 `pull_token` 填**与服务器一致**的令牌；
3. 先手工试跑一次，确认能扫到共享盘、能推成功（页面状态卡出现回报）；
4. **右键「注册银行流水取件.bat」→ 以管理员身份运行**一次，看到绿色 `[OK]` 即完成。

### 8.2 计划任务说明

- 任务名「**银行流水取件机**」：每小时一次、**无窗口**、用**当前登录账号**运行（关键——共享盘只在该账号会话可见，SYSTEM 账号看不见）；
- 上一轮没跑完不启下一轮；单次超时 20 分钟（一次可能推整月几十个文件 + 十几 MB 财资回单）；
- 与报表取件机「财务报表取件机」任务**完全独立**，两个各跑各的、互不干扰；
- 装好后**桌面什么都看不到才是正常的**（无窗口运行）。

### 8.3 停机告警

- **判定**：服务器发现取件机超约 2 小时没回报 = 停机（每小时任务，取 130 分钟阈值避免正常间隔误报），页面红灯与钉钉告警同一阈值；
- **前提**：服务器 `conf.ini [dingtalk]` 已配钉钉应用；
- **收件人**：由使用方在「数据接入」页 🔔 停机钉钉告警里配（填手机号）；
- **发送**：只在"从在跑变停"发一条 ⚠️、恢复发一条 ✅，中间不重复刷屏；走风控 AI 机器人单聊。

## 9. 常见问题 FAQ

**Q：出纳这个月换了压缩格式 / 改了文件名，会不会漏？**
A：不会。工具靠**文件表头内容**认单据（不靠文件名），乱名散件也认得出；`.rar` 服务器能直接解（含 RAR5、加密）；实在缺工具会明确报错提示转 zip，不会静默漏。

**Q：状态卡红了怎么办？**
A：取件机停了。联系管理员查那台内网电脑是否关机 / 任务是否停；期间用手工上传兜底。配了 🔔 停机钉钉告警的话，你手机会先收到提醒。

**Q：自动接入会不会覆盖我手工传的、或跳过重复确认？**
A：都不会。**铁律**：本期已有你手工传的数据时，自动推**只暂存不覆盖**；自动推进来照样打「重复待确认」弹窗，**不自动确认**，等你点。

**Q：金蝶会被改吗？**
A：不会。全程**只读**。

**Q：为什么金蝶金额是 4 位小数，工具没报错？**
A：金蝶设置有时产生 4 位小数属正常，工具比对到 4 位、不当"小数点错"。只有真金额差才归「做错·金额」。

**Q：点了「立即扫描」怎么没马上更新？**
A：服务器进不了内网，这个按钮是给取件机"留个话"，取件机下一轮来问时才真扫。急的话让管理员在取件机上手动跑一次。

**Q：压缩包密码工具会存吗？**
A：不会。密码走请求头、不落盘、不进日志、用完即弃。

## 10. 名词表

| 词 | 意思 |
|---|---|
| **取件机** | 一台常开内网电脑上的小程序，每小时把共享盘的流水散件推给服务器。银行流水走"上行取件机"（内网 → 云端） |
| **定格入库** | 上传 / 推送即按所选期间存成快照，之后各页直接读快照、不重复解析；重传即覆盖本期快照 |
| **财资平台** | 出纳导银行流水的系统（宁波 + 招商多账户），常一次导多份 |
| **HISQRY** | 中行的流水导出（csv，全月区间） |
| **逐笔查重** | 多份财资导出时，让位的份逐笔比对、证明是被采用那份的子集，找不到的算"疑漏" |
| **重复待确认闸** | 出现让位 / 重复 / 疑漏时的人工确认弹窗，须点确认、留痕，机器不替你判 |
| **组合待确认** | 银行 1 笔 = 金蝶多张合计相等（如理财本金 + 收益），工具标候选交人工 |
| **可信度报告** | 每次稽核自动跑的三道勾稽（笔数 / 余额 / 数据齐），三道全过才算结果可信 |
| **pull_token** | 取件机与服务器之间的令牌，对不上就拒（401），保证只有授权取件机能推数据 |
