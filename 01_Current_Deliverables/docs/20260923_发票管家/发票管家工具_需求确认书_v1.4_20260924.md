## 一、为什么要做

**四件事现在都靠人：**

1. **登记**：发票信息要一张张录进台账——慢，录错了也没人知道。
2. **查重**：同一张票报两次，只能靠经手人的记性拦。
3. **后补票**：预付款、先付款后补票的，靠 Excel《发票&收据后补申请单》跟——票到没到、还差多少、该催谁，都得人去翻。
4. **抵扣**：月底在电子税务局一张张勾选。

**为什么是"扫码＋放高拍仪"，不是"拍照上传"。** 扫码枪"嘀"一声就调出审批单；发票往高拍仪下一放，自动拍、自动读出票面二维码，号码、日期、金额和查重结果当场就有。**能读码的不认图，能读原件的不认图**——速度和准确度都在这一步定了。

**为什么现在能做。** 钉钉审批打印件上的二维码，普通扫码枪就能读，系统凭它就能调出整张审批单（已实测，见 F1）。

## 二、定位：是什么，不是什么

| 是 | 不是 |
|---|---|
| **收票管家**：每张票挂到一张钉钉审批单上，登记、查重、审核、入台账 | **报销系统**：不替代钉钉审批，审批流照走 |
| **事前拦截**：扫的时候钱还没付，重复票当场拦下 | **在线查验工具**：不去国税查验平台逐张验（有验证码，不绕）；用税局清单对账验真（见十） |
| 预付、先付后票的**发票后补池**：登记、指定接收人、到期自动催 | **替人办税**：提交勾选、统计确认仍由人在电子税务局操作 |
| 抵扣勾选的**准备工具**：出「清单导入勾选」文件 | **做账工具**：一期不生成凭证 |

**四条铁律：**

1. **原件优先，识别兜底。** 能从电子原件、二维码读的，绝不"认图"。认图（OCR）得来的字段一律标"待核"，人核过才算数。
2. **缺什么就明说。** 二维码读不出、电子原件没拿到、明细没补全——直接显示缺什么，不假装登记完整。
3. **一张票的金额只能用一次。** 默认一票一单；确需拆给几张单（如一张票冲几笔预付），必须手工选"拆分"并留痕，合计不能超过票面。超了就是重复，拦。
4. **系统只做到"出文件"。** 凡是要登录电子税务局点的，都留给人。

## 四、在工作台里的位置

**「发票管家」是核算工作台的一级板块，和应付、成本、应收同级。** 四个二级菜单都是点了直接进页面：

| 一级 | 二级 | 主要谁用 | 干什么 |
|---|---|---|---|
| 发票管家 | 收票工作台 | 实习生 | 扫审批单建票夹，逐张放发票，实时出图片和字段，提交送审核（见五） |
| | 发票后补池 | 财务接收人 | 后补单都在这里；收到发票点一下（见七） |
| | 发票审核 | 会计 | 复核提交上来的票夹和后补收到的票，通过才进台账（见八） |
| | 发票台账 | 会计、财务经理 | 审核通过的票；查询导出、税局对账验真、抵扣勾选、新销方核查、期初导入（见九） |

- 板块排在应收后面（设置页可调）。上线初期各菜单状态为"开发中"，只有指定人可进；并行期改"人工并行"。
- 一张票的一生：**收票工作台**（或**发票后补池**）登记 → **发票审核**通过 → 进**发票台账** → 税局对账验真 → 抵扣勾选。

## 五、收票工作台：实时票夹

**工位配置**：电脑＋扫码枪（能扫二维码的）＋高拍仪（"免驱"的）。**也可以先不买硬件，一部手机就能跑完全流程**（见下"手机"）。

**一张单的操作：**

1. **扫审批单二维码（嘀）** → 屏幕自动开这张单的**票夹**：单号、类型、申请人、收款方或事由、金额；附件和「图片」栏里的电子票，系统自动拉下来读出、列进票夹，标"等纸质件"。付款单没附发票时，显示后补情况：已登记 → "发票后补，预计 9 月 30 日到票，接收人：李四"；**没登记 → 黄牌**。
2. **把发票放到高拍仪下** → 画面一静止就自动拍（也可按空格），系统从照片里读出二维码，**票夹里马上多一张**：
   - **第一拨，当场出来**：图片、号码、日期、金额、查重结果——✅ 已登记／🔴 **重复**（"已于 9 月 3 日挂在李四的费用报销单上"，红屏＋提示音，不能继续挂）／附件里已读到的票再放纸质件＝"纸质件已到"，**不算重复**；
   - **第二拨，几秒后补上**：销方、税号、税额、税率、项目类别——从电子原件读，或识别出来标"待核"。
3. **没有二维码的票**（出租车票、定额票等）→ 同样放上去拍，系统改走识别，字段标"待核"，当场对照图片核一下。
4. 票夹底部实时显示**票合计 vs 单据金额**（只提示，不拦）。
5. **点"提交"** → 送**发票审核**。有重复票没移除、或还有票在识别中，提交不了。
6. **扫下一张审批单**，开下一个票夹。

**手机＝扫码枪＋相机（业务方定）：**

- 电脑上点"手机当相机"，屏幕出一个**配对码**；实习生用**手机钉钉平常的"扫一扫"**扫它，手机就打开收票页面，**不需要任何额外配置**。用钉钉扫是为了**知道是哪个实习生**。
- 配对以后手机上两个按钮："扫审批单""拍发票"。**系统看码的内容自己分辨**：审批单的码开新票夹，发票的码进当前票夹；扫码枪也按同样规则。
- "扫审批单"如果想"对准就出"，需要钉钉管理员给页面开一下钉钉扫码的调用权限（和 Q1 同一后台）；**不开也能用**，改成拍一张、系统从照片里读码。"拍发票"本来就要留图，和这项配置无关。
- **配对规矩**：配对码几分钟内有效、只能扫一次；手机钉钉上的人记为登记人；**手机上的人要和电脑上登录的人是同一个**，对不上就配不上（需要实习生的工作台账号先和钉钉绑定，在设置里按名字搜人绑一下）。

**其它进票方式**：把 PDF／OFD／XML／图片／压缩包直接拖进票夹。

## 六、票面明细、电子原件和图片

**明细从哪来**（二维码只有号码、日期、金额）——先到的先用，后到的用来核对：

| 来源 | 谁动手 | 准确度 |
|---|---|---|
| ① 审批附件、图片栏里的电子票（PDF／OFD／XML／压缩包） | 系统，扫单时自动拉 | 原件直读 |
| ② 电子税务局「全量发票查询」批量下载的文件包 | 财务每周拖一次进系统，按号码自动对上 | 原件直读 |
| ③ 高拍仪／手机照片识别 | 实习生当场核，审核时再看 | 标"待核" |

**图片一律留存（业务方要求）：**

- 拍的：留原图（"原始图片"）；原图超过 2MB 的等比压到长边 2600 像素，字照样清楚——服务器硬盘不宽裕（F15）。
- 电子票：留电子原件，另生成一张预览图（相当于票总管的"虚拟图片"）。
- 附件（住宿水单、行程单、对账单等）挂在同一张单下，一起看。
- 每张图存三份：原图、放大用的预览图、列表用的缩略图；列表只加载缩略图，翻页不慢。
- **原件是凭证，要进备份**（见 Q20）。

**在哪看（收票工作台、发票审核、发票台账都一样）**：左边列表，右边详情——
- 右边上方一排**缩略图**：这张单的所有票和附件，点哪张看哪张；
- 点开**放大查看**：旋转、放大缩小、拖动、上一张下一张、下载原件；
- 下面是字段；**点任何一个字段，图上框出它是从哪读出来的**——核"待核"字段时不用满图找。

## 七、发票后补池

**现在**：业务同事另填 Excel《发票&收据后补申请单》（14 个格子），"实际收回"靠人手记。

**改成**：后补单都进工作台的**发票后补池**；财务在池子里看、收、催。

### ① 登记

- **业务同事自助填报**：打开一个网址，**用钉钉认人**（不需要工作台账号），关联自己的付款单、填 4 项、传资料、选财务接收人。⏳ **这一步要等钉钉管理员配好"钉钉登录"（Q1）才能开放**，所以放下一批。
- **本批先上"财务代填"** 🔨：财务在后补池扫一下付款单二维码（或输入审批编号），供应商、金额、事由、ERP 单号、申请人自动带出，再填 4 项、选接收人即可。等 Q1 配好，业务同事自助填报用的是同一张单、同一个池子。
- **关联付款单**时，公对公的**供应商信息**（收款方工商名、开户行、账号）、付款金额、事由、ERP 单号、申请部门自动带出。
- **填 4 项**：发票种类（专票／普票／收据）、预计到票日期、预计到票金额（默认＝付款金额）、税率（选填）。上传资料（选填）。**指定财务接收人**。
- 提交 → 进后补池；接收人的钉钉马上收到消息。

### ② 付款审核（实习生）

收票工作台扫这张付款单时，直接显示"已登记后补，接收人李四"。没附发票又没登记后补的，亮黄牌（拦还是只提醒，见 Q3）。

### ③ 收票（财务接收人，点一下）

- 池子默认显示"我接收的"，按状态分：待收、部分到票、已收齐、超期。
- **纸质票**：点一下"收到"，**顺手扫一下发票**（扫码枪或放高拍仪）→ 查重、冲减、送发票审核。
- **电子票**：拖进来或业务同事上传 → 接收人点一下"确认"。
- **自动比对销方**：发票销方和付款单收款方对不上——钱付给 A、票是 B 开的——**标红**。
- 部分到票余额继续挂着；一张票冲几笔预付、一笔预付分几次到票都能记。实在来不及扫，可以先只点"收到"，标黄"已收到、号码未登记"，直到补扫。
- 收齐后，钉钉通知业务同事"已签收"。

### ④ 催票

到预计日期前几天提醒申请人，超期后每周提醒一次，都抄送接收人（机器人单聊）；也可以手动"催一下"。月底一键导出欠票清单，**按供应商汇总**，用来对预付账款的挂账。

### Excel 后补单 14 个格子的去向

| Excel 格子 | 去向 |
|---|---|
| 申请部门、申请人、申请日期、钉钉审批号、收款单位、付款内容、付款金额、采购订单号（ERP） | **关联付款单后自动带出**（8 个）；公对公还多带出开户行和账号 |
| 发票种类、税率、预计收回日期、预计收回金额 | 填（4 个） |
| 实际收回日期、实际收回金额 | 接收人**点"收到"时系统自动记**（2 个） |

另外新增：**财务接收人**、**资料附件**。**收据**没有发票号码，不进查重，按金额冲减，标"收据"。

## 八、发票审核

> 按"会计复核"理解写的，请在 Q13 确认。

**是什么**：收票工作台提交的票夹、后补池收到的票，先进**审核队列**，由会计复核；**通过了才进发票台账**，退回的回到收票工作台，带退回原因。

**系统先标好，人来确认**：识别来的"待核"字段（点字段图上框出位置）；票合计 vs 单据金额；发票销方 vs 付款单收款方；抬头是不是这张单的公司主体、是不是本公司；可否抵扣（系统按票种＋项目类别给建议，**会计定**）；拆分、收据、只点了收到没扫号码的。

**两档处理**：没有任何异常的票夹**可以批量通过**；有异常的逐张过。

**谁不能审谁**：提交人不能审核自己提交的票夹；只有主管理员可以自审，留痕标"自审"（沿用 BOM 报价审核口径）。

**审核权限默认不给任何人，要管理员手工开**（见十一）。

## 九、发票台账

**审核通过的票都在这里，一票一行**：挂在哪张单（审批单号、类型、申请人／部门、收款方或事由、单据金额）；票面（票种、号码、开票日期、销方名称和税号、金额、税额、价税合计、税率、项目类别）；状态（来源、电子原件有无、纸质件到否、**验真结果**、抵扣状态）；留痕（登记人、审核人、各环节时间、改动记录）。右侧详情同第六节：缩略图、放大查看、字段、挂靠审批单、审核记录。

**页面里的页签：**

1. **台账查询**：按日期、销方、票种、验真结果、抵扣状态、审批单筛选；导出 Excel；作废（敏感权限）。
2. **税局对账（验真）**：把电子税务局「全量发票查询 › 取得发票」导出的清单拖进来，每张票标四色——🟢 清单里有、状态正常＝**已验真**；🔴 清单里有、已作废或红冲；🟡 清单里没有＝待核（可能还没上传、抬头税号填错、或假票）；⚪ 清单本来覆盖不到（定额、出租车、个人抬头等）。同时出两张表：**税局有、台账没有**（系统顺手和后补池里没收齐的单比一比）；**台账有、税局没有**。这里也可以拖入税局批量下载的发票文件包，补全明细和原件。
3. **抵扣勾选**：拖入「抵扣类勾选」导出的未勾选清单 → 系统逐张标"是否勾选"（已审核＋可抵扣＋已验真 → 是），**会计确认** → 导出原样文件 → 电子税务局「清单导入勾选」→ 人工提交、统计确认。
4. **新销方核查**：每月自动列出第一次出现的销方，专人去信用中国或省税务局公布栏按统一社会信用代码查一次，把结果填回（查询日期、渠道、结果、备注）。命中只提示、不自动拒付。
5. **期初导入**：把票总管导出的历史发票清单拖进来当查重底子（敏感权限）。

## 十、自动查验与失信检测（调研结论）

**业务方原话："可以看看这个"。结论：一期零费用，二期看并行结果再定要不要花钱。**

| 做法 | 时效 | 费用 | 覆盖 | 数据外发 |
|---|---|---|---|---|
| **税局清单对账（一期采用）**：全量发票查询 › 取得发票，每月或每周导一次 | 对账时才知道 | 0 | 开给我司税号的所有票（数电、税控、纸电、专普、通行费、铁路航空电子客票），还能看到作废、红冲 | 无 |
| 税务数字账户【发票查验】批量 | 人工上传时 | 0 | 只能查本企业的票，每批最多 500 张 | 无 |
| 全国增值税发票查验平台 | 实时 | 0 | 逐张录入＋图形验证码，每张每天最多查 5 次，**不能程序化** | 无 |
| 云查验接口（腾讯／阿里／百度） | 实时 | 约 0.24–0.30 元/张 | 所有增值税体系票，不含定额、出租车 | 号码金额要发给云厂商 |
| 乐企直连 | 实时 | 税局不收费，开发重 | 全面 | 无；但门槛高（纳税信用 A/B、上年营收 5000 万以上等） |

**失信检测**：依据《重大税收违法失信主体信息公布管理办法》（总局令第 54 号），名单由各省税务局和"信用中国"公布，**没有官方接口**、有验证码或反爬，不能写爬虫。第三方接口（如企查查"税收违法核查"）约 0.5 元/次。**一期做法**：台账每月列"新销方"，专人人工查一次、结果填回（第九节页签 4）。另外，勾选抵扣时税局会提示"异常凭证／疑点发票"，这个信号比失信名单更及时，要一并关注。

**二期（看并行结果）**：如果确实要"付款当下就知道真假"，再接云查验，只对"还没进清单且金额超过门槛"的票调；新销方多到查不过来，再对新销方调第三方接口（每月 50 家约 25 元）。两者都要先过数据外发审批。

**和票总管并行时顺便对照**：票总管判"查验通过"的票，理论上都应在税局清单里；两边结论不一致的逐张查明，作为停用票总管的依据。

## 十一、菜单与权限

**沿用核算工作台现行机制**：每个菜单自动生成准入点；新准入点**存量账号一律不给**；岗位是"一键套用"模板；**敏感动作点永远手工单给**。

**要特别说明的一点**：工作台有个既有规则——**非敏感的动作权限会在每次重启时自动补给所有核算组账号**。所以：
- 每个接口都**同时**校验"能不能进这个页面"和"能不能做这个动作"——没开页面的人，就算有动作权限也用不了；
- **审核（inv_audit）按敏感点处理**：审核是控制点，不能人人自动有，默认谁都不给，由管理员手工开给会计。

**准入点（自动生成，4 个）**：收票工作台、发票后补池、发票审核、发票台账。

**动作点：**

| 动作点 | 管什么 | 性质 |
|---|---|---|
| inv_intake | 收票工作台：建票夹、拍照登记、提交 | 非敏感 |
| inv_receive | 后补池：代填后补单、点收到、确认电子票、催票 | 非敏感 |
| inv_deduct | 发票台账：税局对账、抵扣勾选、新销方核查 | 非敏感 |
| inv_audit | 发票审核：通过、退回、判定可否抵扣 | **敏感** |
| inv_unbind | 作废、解绑改挂 | **敏感** |
| inv_opening | 期初导入 | **敏感** |
| inv_config | 设置：财务人员名单与钉钉绑定、本公司抬头、审批模板、催票规则 | **敏感** |

**岗位模板（草案，Q10）**：实习生＝收票工作台；应付会计＝四个菜单全进＋三个非敏感动作；税务会计＝发票审核、发票台账＋抵扣；财务经理＝整个板块。审核、作废、期初、设置都要管理员手工开。
