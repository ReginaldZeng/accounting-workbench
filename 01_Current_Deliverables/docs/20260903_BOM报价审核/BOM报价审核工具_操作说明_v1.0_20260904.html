核算工作台 · 工具线 08

操作说明 · Operation Manual

BOM 报价审核工具
怎么用

从钉钉「BOM表报价」审批的附件，到成本会计初审、财务BP终审，再到对外报价消费——一条链上，谁在哪一步、点哪个按钮、盖哪个戳，这份说明讲清楚。

版本　v1.0 · 2026-09-04 使用者　成本会计 / 财务BP 菜单　待办与复核 · 标准成本台账 · 基础设置
绿 · GO

终审通过 · 对外开放

财务BP 盖「已审核」戳。只有这一版进对外报价口，BP 定价才拿得到。

琥珀 · HOLD

初审 · 仅内部可见

成本会计盖「初审」戳＝定稿。台账内部看得到管线，但还没终审，绝不外发。

红 · STOP

不平 / 待修 / 作废

勾稽不平、上游链路被连带拦下、或标记作废——挡在对外之前，不静默放行。

这三种颜色贯穿全篇。看到颜色，就知道这一版能不能对外。

总览

一条链，两个戳

source → 立项 → 复核 → 初审 → 终审 → 消费

钉钉审批里躺着采购的商务版核算表、有时还有成本会计的商品版、评论区补传的 BOM。工具把它们抓下来、解析成含税五分项、做勾稽自检；然后走两个戳的审核：成本会计初审（琥珀）→ 财务BP终审（绿）。只有绿戳版对外。

00

谁用它 · 各管一段

两个人、两个戳、两套权限。分工是刻意的：终审要当第二双眼睛，所以初审权和终审权不宜给同一人，且初审人不能自己终审（代码强制）。

成本会计bom:audit
  • 录钉钉单号立项，把审批附件拉进待办
  • 走复核四步：③用量自洽、④报价核算逐项确认
  • 审核定性：定物料类别、判是否允许对外报价
  • 盖「初审」戳＝定稿（琥珀，仅内部可见）
  • 发起作废申请（不能自己批）
财务BPbom:final_review
  • 对初审版做形式审核（拿去报价前过一遍）
  • 盖「已审核」戳＝终审（绿，对外开放）
  • 发现问题退回成本会计重做（撤下定稿）
  • 批准 / 驳回作废申请
  • 在 BP 工作台只读消费终审成本，对外报价
怎么进

核算门户登录 → 左侧菜单 待办与复核（要 enter:bomdraft）做初审；标准成本台账（要 enter:bomstd）看已审核成品库。权限点默认都不给，逐一显式授予。

01

立项 · 录单号，生成待办

成本会计

不批量扫描、不回灌历史——一次一个单号，按需立项。一个核算表文件＝一组（复配料/半成品/成品同源归一组），审核顺序自下而上。

A

录入钉钉审批编号 成本会计

在待办页填「BOM表报价」的审批编号（形如 2026…251965）。工具按编号定位实例，抓表单附件 + 评论区补传的 BOM，一个都不漏。

B

解析成含税五分项 系统

识别来源方（采购商务版 / 成本会计商品版 / 研发BOM / 评论区），一单两版会自动配对补料。解析后立刻做勾稽自检。

C

勾稽不平 → 拦在门外 系统

原料小计＝Σ明细 等 6 项对不上，或侦测到疑似漏加料，这一批进「待修」，红标显示不平原因明细（可点进去下钻），不静默入账。修好替换文件后再入。

红线

勾稽不平的成本绝不静默放行。这是这条线最硬的一条——错数入了账，一路带到对外报价就是真金白银的错。

02

复核四步 · 前两步看，后两步确认

成本会计

详情页四个可点页签。①②是研发给的参考材料，只看不确认；真正要成本会计签字负责的是 ③④。

① 只看
BOM清单
研发清单本身：到位没、哪一版、结构与用量。缺清单可上传补挂。
② 只看 · 参考
工艺流程
就在 BOM 里，随附。有时带照片，仅参考，不做确认。
③ 要确认
用量自洽
添加量勾稽：明细加总＝小计，同名分段求和一致（食盐 5＝3＋2）。
④ 要确认
报价核算
含税五分项逐项核。改了费用/税率，审核态自动失效、要重审。

含税五分项 · 这一步核的就是它

原料 / 包材添加量 × 含税价 ÷ (1+税率)；对外含税 ×1.13
加工费(制造费用 ＋ 工厂费用) ×1.13　※加工费并入工厂费用口径
装卸费(运输 ＋ 装卸) ×1.13
管理费按加成计入
全成本五项合计 · 台账列强调显示
03

初审 · 定性弹窗，一盖即定稿

成本会计

③④确认完，点审核 → 跳出定性弹窗。定完性就盖「初审」戳、同时定稿——审核和定稿是同一个动作，不是两件事。

1

选物料类别（五选一）成本会计

复配料 / 自产半成品 / 自产成品 / 委外半成品 / 委外成品。编码判定只当建议值，最终由人定——规律稳了以后再回填自动化。

2

判是否允许对外报价 成本会计

不建议报价的必须写明原因（如「包材不全」「XX物料暂定」）。台账标红「禁报价」，原因一并带给 BP 定价侧，避免拿不完整的成本对外。

3

盖「初审」戳＝定稿 初审

这一版毕业进标准台账（内部可见），但还差终审，对外口拿不到。接着轮到财务BP。

04

终审 · 财务BP 盖章，才对外

财务BP

财务BP 拿初审成本对外报价前过一遍形式审核。盖「已审核」戳，这一版才进对外报价口。改过成本的版本会被强制打回，不让旧戳偷偷对外。

双人闸

bom:audit（初审）与 bom:final_review（终审）是两个默认不给的敏感权限，不宜给同一人；初审人不得自己终审——系统拦下，确保终审是第二双眼睛。

05

上游链路 · 一环不平，整链拦下

系统守卫

复配料 → 半成品 → 成品，成本一层建在一层上。任一层勾稽不平，它上面的所有产品都被传导式连带拦截——不让成本建在错数上的成品偷偷对外。

06

作废 · 标记不删除，两步批

成本会计申请 → 财务BP批准

一个钉钉单里若有多个作废版本，不是删掉——是标记作废（留痕不消失）。为防成本会计舍弃了不该舍弃的，作废走申请+终审两步，申请人不得自批。

① 成本会计
申请作废
详情页「⌦ 申请作废」，写原因。记录标为待作废，不立即生效。
② 待终审
待终审 banner
页面挂出待作废提示，等财务BP处置。
③ 财务BP
作废终审
「⌦ 作废终审」批准或驳回。批准后标记 active=0，历史仍可查。
为什么不删

钉钉审批本身也是这么走的：成本会计每单审完，财务BP都会再形式审核一遍（相当于知悉，因为要拿这数据去报价）。作废同理，留痕比删除安全。

附

速查 · 状态与权限

状态 → 谁盖的戳 → 能不能对外

状态谁盖的戳在哪个页面对外报价口
未复核 / 已复核—待办与复核✕ 不外发
初审（=定稿）成本会计 初审标准台账（内部）+ 待办✕ 未终审不外发
已审核（终审）财务BP 已审核标准台账✓ 只有此版对外
待修—（勾稽不平/连带）待办 · 待修批次✕ 拦下
作废BP批准（active=0）标记不删除✕ 退出
