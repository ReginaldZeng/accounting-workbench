## 1. 目标与价值

研发在钉钉「BOM表报价（研发使用）」审批里提交成本核算表 xlsx。现状：成本会计要在附件里一张张核研发填的用量、采购价对不对，靠人眼、易漏、无留痕、口径不统一。

本工具一句话：**按审批编号自动抓附件、解析成结构化台账（含税五分项），成本会计逐料复核（用量自洽 + 逐料核价，改税率费用留痕）后定稿，定稿版成为标准成本、供 BP 定价直接消费。**

1. **自动入账**：钉钉审批附件自动抓取解析，一单多产品自动出多条，勾稽不平不入账。
2. **两步复核**：①用量自洽（研发核算表 vs 研发 BOM清单）②逐料核价（研发填价 vs 金蝶实采应付），改税率/费用留痕。
3. **定稿即公开**：定稿版进「标准成本台账」，公开可查、供 BP 定价消费；未定稿只有权限人看。

### 2.1 信息架构：三级菜单 ✅（v1.0 新增，本期开发 🔨）

```
成本模块（一级）
└─ BOM报价审核（二级 · 分组）
   ├─ 待办与复核（三级）      ← 未审核工作台（按钉钉单号立项，见 §2.2）
   │    列表＝一行一个钉钉单号 → 点进「处理页」按组处理
   │    钉钉抓取/OA接入、手工入账、复核、定稿、价格校验、组内替换文件
   │    数据全是"草稿/未审核"，只有权限人能进
   │    （后续 OA 审批完成可自动推进这里 🔲）
   ├─ 标准成本台账（三级）    ← 已审核成品库
   │    只放已定稿的标准成本，公开可查、供 BP 定价消费
   └─ 基础设置（三级）        ← 公开版脱敏规则等（见 §5.3）
```

- **定稿 = 从「待办与复核」毕业进「标准成本台账」**——"审核"这个动作的物理含义，也把可见性（见 §8）落成两个页面，不靠隐藏。
- ✅ **标准成本台账（已审核版）BP 工作台也放一份只读**（业务方定 2026-09-03）：共享门户登录态，BP 侧直接看已定稿标准成本、供定价消费；核算侧为真相源、BP 只读。核算侧 `GET /api/bom/final` 即数据口。

### 2.2 待办的处理单元：钉钉单号 → 组 → 处理页 ✅（业务方定 2026-09-03，A 方案）

**组的定义**（业务方定）：**BOM表 + 成本核算表（商务版）解析在一起 ＝ 一组**。特例：半成品BOM + 成品BOM + 一个含半成品与成品双 sheet 的核算表，**三个文件也算一组**。
**组边界定案**：**一个成本核算表文件（连同其成品/半成品/复配料 sheet + 编码对得上的 BOM）＝ 一组**；一个钉钉单号传了几个核算表文件就是几组。

```
待办与复核（列表：一行一个钉钉单号 · 组数 / 产品数 / 待复核）
└─ 点进 → 处理页（该单号）
   ├─ 组 1（核算表文件 A）：成品 + 半成品 + 复配料 + 各自 BOM
   │    · 组内产品表：勾稽 / 用量自洽 / 来源方 / 商品版 / 复核两步 / 状态
   │    · 组内文件替换：⟳ 重连钉钉替换　⬆ 上传替换核算表　（BOM 逐产品可挂/替换）
   │    · 替换留痕 · 审核历史
   └─ 组 2（核算表文件 B）…
```

- **组锚点** `group_id = hash(源 + 审批号 + 成品归组键)`：确定性生成，**替换核算表后新文件里同一成品落回同组**。
- **替换语义**：新文件里**勾稽平**的产品顶替同组同产品旧版 → **旧版标「已被替换」留痕（`active=0`）、退出标准成本库并清掉定稿指针**；**仍不平的不入账并回报**（带漏加料诊断，见 §5.2 的不平原因明细）；**原先因不平未入的产品（如半成品）修好后作「组内新增」补入**。
- **红线**：被替换的旧版**只留痕不删除、不进标准成本库**；调该钉钉单号的审核历史时可见「谁在何时把哪个文件从旧版换成新版」。

### 2.3 两个戳的审核流：成本会计初审 → 财务BP终审 ✅（业务方定 2026-09-04）

全流程**就两个戳，别拆碎**：

```
未复核 → 已复核 →  【初审】(成本会计)  →  【已审核】(财务BP终审)
                   ③④确认 + 审核定性        盖已审核戳·对外开放
                   盖「初审」戳
```

- **成本会计初审**：复核四步里 **③用量自洽 ④报价核算 两步确认**（①BOM清单②工艺流程只看不确认，是研发给的参考材料）+ **审核定性**（物料类别五选一 + 是否建议对外报价，见 §5.1）→ **定性即定稿**，盖「**初审**」戳。
- **财务BP终审**：财务BP拿初审成本对外报价前**过一遍形式审核**，盖「**已审核**」戳；也能**退回**成本会计重做（退回撤下定稿指针，该版退出标准台账）。
- **只有终审版对外开放** ✅：BP 消费口 `GET /api/bom/final` **只放 `status=已审核`**——成本会计已初审但财务BP未终审的，**绝不外发**给 BP 报价。标准台账内部见 初审+已审核（成本组看得到管线），对外/BP 只见终审版。
- **改了成本必重审**：复核改费用/税率、采纳商品版调价 → **失效审核态**（降回「已复核」、清终审戳、清定稿指针），强制重新初审→终审。重新初审也会清空终审戳。
- **双人闸**：`bom:audit`（初审）与 `bom:final_review`（终审）是两个默认不给的敏感权限点，**不宜授予同一人**；且**初审人不得自己终审**（代码强制），确保终审=第二双眼睛。

### 2.4 作废：标记不删除，申请 + 终审批准两步 ✅（业务方定 2026-09-04）

一个钉钉单里可能有多个作废版本。

- **作废＝标记不是删除**：记录**留着、留痕**（`active=0, inactive_kind=voided`，区别于「被替换 replaced」），只是退出工作区与标准成本库，随时可查。
- **两步防一人闭环**：成本会计（`bom:audit`）**申请**作废（理由必填，申请期间记录**照常有效**）→ 财务BP（`bom:final_review`）**批准**才真作废、或驳回；**申请人不得自批**（代码强制）。
- 入口：详情页「⌦ 申请作废」→ 待终审 banner →「⌦ 作废终审」。

## 5. 解析器与口径 ✅（坑全踩过，9 单真实审批验证）

原则：**按表头标签定位列，绝不写死列号**（精简/完整两版模板列位不同）。逐附件、逐 sheet 认「成本核算样表」标记，一单 N 产品自动出 N 条；BOM清单等非核算表跳过。

- **6 项勾稽全平才可入账**（红线，见 §12）：原料小计=Σ明细、包材小计=Σ明细、变动=原料+包材、成本合计=变动+制造+工厂+运输+装卸、含税=不含税+增值税、全成本=含税+管理费。
- **含税五分项（元/kg，全成本口径）**：原料=原料小计×1.13、包材=包材小计×1.13、**加工费=(制造+工厂)费用×1.13**（比样机稳：样机只算制造费用，工厂费用样例恒 0 看不出，并入后源表对账差异恒 0）、装卸费=(运输+装卸)×1.13、管理费=管理费加成含税；全成本=五项相加=源表全成本含税。
- **明细逐料**：成本不含税=添加量×含税价÷(1+税率)；**成本含税=不含税×1.13**；**占比=该料含税÷全成本含税**。
- **归组键 = (产品名, 客户；客户为空用 CP 码兜底)** ✅：CP 码跨版本跳号、又有同名双产品，故归组不认 CP。
- **排版差异版去重**：数字指纹（归组键+日期+全成本+小计+逐料成本）相同=同一版，留**最全排版版**（有物料编码的完整版，精简版无编码会让价格校验形同虚设）。同日双修订（数字不同）都保留。
- 半成品嵌套三层：复配料 → 半成品 → 成品，每层有自己的核算表，靠「下层全成本含税＝上层里的含税价」串（作原料进上层）。

### 5.1 物料类别：审核定性为准，编码只作建议 ✅（业务方定 2026-09-03，**取代**原编码分类）

⛔ **原编码分类规律已降级**：业务方 2026-09-03 定「**编码暂时不固定了**，处理不了就交给成本会计指定」。

**物料类别（五类，新增「自产 / 委外」这一维）**：

| 类别 | 台账基础分类 | 委外 | 说明 |
|---|---|---|---|
| 复配料 | 复配料 | — | 作原料进上层，不单独挂渠道 |
| 自产半成品 | 半成品 | ✗ | 同上 |
| 委外半成品 | 半成品 | ✓ | 代工厂生产 |
| 自产成品 | 成品 | ✗ | 可挂渠道、供 BP 定价 |

- 「自产/委外」这一维**编码里没有**；建议值按「核算表带生产工厂/供应商 → 倾向委外」预选，成本会计确认。
- 定性同步 `semi`（BP 消费口按 semi 判）；非成品自动清渠道。

### 5.1.1 是否建议 / 允许对外报价 ✅（同一弹窗，业务方定 2026-09-03）

- 成本会计必须给出结论：**建议报价** 或 **不建议报价**。
- **不建议时必须写明原因**（如「包材不全」「XX 物料暂定价」）——弹窗给常用原因快捷标签：包材不全 / 物料暂定价 / 配方未定版 / 缺半成品核算表 / 勾稽存疑。
- 不建议的记录在台账标「**禁报价**」红标，并把 `quotable=false` + 原因**带给 BP 定价侧**（`/api/bom/final`），避免拿不完整的成本对外报价。
- **定稿前置**：物料类别 + 报价结论（不建议须有原因）**未完成则不许定稿**（与 §9 的①用量②价格两步并列）。

⚠ 「改配方必换编码」仍是 §6（缺清单按编码查历史）的依据，不受本节影响。

### 5.2 来源标注 + 一单两版核算表 ✅（业务方定 2026-09-03，实单 202608101601000105116 联调）

**流程实情**：一单核算表槽有三个——`商务输出`（采购·全量底稿，含供应商/型号/规格/实价/发票税率）、`商务复核`、`商品版本`（成本会计脱敏公开版，**只有采购版有问题时才出**，可能调过价/税）。分两条线：①新未审 OA 只有商务版；②已审 OA 另有商品版。

**关键实证（拉真单 diff）**：商品版 **不是缺料**，而是商务版**删掉「型号 / 规格 / 供应商(品牌)」三列**——物料行、编码、名称、添加量、采购价、税率、成本**全保留**；本单价/税与商务版完全一致（纯脱敏，未调价）。

| 来源方 `origin` | 判定（钉钉控件标注自动） | 入账处理 |
|---|---|---|
| 研发BOM `research` | BOM清单/原料信息附件 | 作用量自洽校验的清单来源（§6） |
| 采购商务版 `procurement` | 控件含「商务」/无标注核算表 | **永远以此为底稿入账**（全量） |
| 成本会计商品版 `costacct` | 控件含「商品版」 | **不单独入账**（缺三列），配到同产品商务版记录作**留档 + 价/税 diff** |
| 手工上传 `manual` / 评论区 `comment` | 渠道兜底 | 手工入账/评论区附件 |

- **diff 对齐用「行位置 + 物料名校验」**，**不能按物料编码**（源表编码列有「103系列」等非唯一系列占位）。
- **有差异才弹确认闸**：复核②步「成本会计商品版」面板列出 商务版→商品版 的价/税，成本会计核对后**采纳**＝覆盖底稿 + 按 成本不含税=添加量×含税价÷(1+税率) 重算 + 逐项留痕 + 价格核价步骤清空重认；**无差异静默过**（面板显「完全一致·仅留档」）。
- 台账「来源」列 / 详情「来源方 + 控件标注」/ 手工入账预检「来源方」列 均展示分色徽标；商品版原件另存留档。

### 5.3 公开版脱敏（基础设置·第三页 `bomconfig`）🔲 占位

- 公开台账（标准成本台账 / 给 BP）相比复核底稿要遮的敏感列，做成**基础设置**开关：供应商/型号/规格/报价说明。**默认全不遮（占位）**——口径＝成本会计商品版删的三列（型号/规格/供应商），日后业务方在此开启；复核底稿始终保留全量。权限 `bom:config`（敏感）。

## 6. 缺 BOM清单 → 按编码查历史 ✅

一单可能只附了部分产品的 BOM清单（半成品未变动、清单在别流程；或漏传）。本单未附清单时：

- **按产品编码在台账历史回查**带清单的同编码记录：找到 → 沿用其清单做用量自洽校验 + 标「沿用历史清单（第 N 号·审批尾号·日期）」；找不到 → 标「**疑似漏传**，请研发补传」+ 补挂上传口。
- 因「改配方必换编码」，同编码 = 配方未变 = 历史清单可复用；配方变了会换码 → 查不到 → 正确落到「疑似漏传/新品」。归组键兜底。
- **不做「唯一清单兜底」**：一单多产品只附一份清单时不乱配给没清单的产品（实测 202609011151000012138 有此情况）。

## 8. 可见性 / 对外门控 ✅（A 方案 2026-09-02；两戳收口 2026-09-04）

三级可见性，跟两个戳一一对应（详见 §2.3）：

| 状态 | 谁盖的戳 | 在哪个页面 | 谁能看 | 对外（BP报价口 `/api/bom/final`）|
|---|---|---|---|---|
| 未复核 / 已复核 | — | 待办与复核 | 须 enter:bomdraft（敏感）| ❌ 不外发 |
| **初审**（=定稿）| 成本会计 | 标准台账（内部可见）+ 待办与复核 | enter:bomstd（台账内部见管线）| ❌ **未终审绝不外发** |
| **已审核**（终审）| 财务BP | 标准台账 | enter:bomstd + bom:view_sheet | ✅ **只有此版对外** |

- **对外只认终审**：BP 消费口只放 `status=已审核`（财务BP终审版）。成本会计已初审但未终审的，标准台账内部看得到（成本组自己盯管线），但**对外/BP 侧看不到、拿不到**。
- **改了成本自动退出对外**：复核改费用/税率、采纳商品版调价 → 失效审核态、清终审戳，BP 口立即少这一版（审查加固，§14）。
- 实现：两页物理隔离（§2.1）+ 状态门控（不靠隐藏），待办与复核只对 enter:bomdraft 开放。
