## 1. 目标与价值

研发在钉钉「BOM表报价（研发使用）」审批里提交采购核算表 xlsx。现状：成本会计要在附件里一张张核研发填的用量、采购价对不对，靠人眼、易漏、无留痕、口径不统一。

本工具一句话：**按审批编号（或 OA 到成本核算节点时自动）抓附件、解析成结构化台账（含税五分项），成本会计逐料复核（用量自洽 + 逐料核价，改税率费用留痕）后初审，财务BP终审，终审版成为标准成本、供 BP 定价直接消费；复核完的采购核算表两版一次导出，由成本会计照旧传回 OA 表单。**

1. **自动入账**：钉钉审批附件自动抓取解析，一单多产品自动出多条，勾稽不平不入账。
2. **两步复核**：③用量自洽（研发采购核算表 vs 研发 BOM清单）④逐料核价（研发填价 vs 金蝶实采应付），改税率/费用留痕。
3. **终审即公开**：终审版进「标准成本台账」对外，供 BP 定价消费；初审版内部可见、不外发；未审核只有权限人看。
4. **OA 流程不动**（v1.3）：工作台只接管「复核审核」这一段；到节点自动立项、审完两版导出，OA 表单那一格照旧人传。

### 2.1 信息架构：三级菜单 ✅

```
成本模块（一级）
└─ BOM报价审核（二级 · 分组）
   ├─ 待办与复核（三级）      ← 未审核工作台（按钉钉单号立项 / 自动立项，见 §2.2、§2.9）
   ├─ 标准成本台账（三级）    ← 已初审/已终审（内部见管线；对外只终审版）
   └─ 基础设置（三级）        ← 公开版脱敏规则、发票规则
```

- **定稿 = 从「待办与复核」毕业进「标准成本台账」**。
- ✅ **BP 工作台放一份只读镜像**（§2.6）：核算侧为真相源、BP 只读。

### 2.2 待办的处理单元：钉钉单号 → 组 → 处理页 ✅（业务方定 2026-09-03，A 方案）

- V2.432/433：纯历史组（0 active）不占组号、收进「历史留痕」块；替换留痕默认折叠。
- V2.456：重连钉钉重拉时，同单其它 xlsx 附件里的研发 BOM 清单一并解析，供组内新增的复配料/半成品配清单。

### 2.3 两个戳的审核流：成本会计初审 → 财务BP终审 ✅

```
未复核 → 已复核 →  【初审】(成本会计)  →  【已审核】(财务BP终审)
                   ③④确认 + 审核定性        盖已审核戳·对外开放
                   + 换码承接确认            （补录单：初审即已审核，§2.5.3）
```

- **成本会计初审**：③④两步确认 + 审核定性（§5.1）→ **定性即定稿**，盖「初审」戳。定稿闸：四步齐 / 上游链路就绪（§2.5 上游闸口径）/ **换码承接已答**（§2.5）。（单位净重 v1.2 曾为闸，V2.445 撤，见 §2.7。）
- **财务BP终审**：在**核算工作台**「标准成本台账 → ⚑终审」做（不在 BP 工作台，§2.6）；通过盖「已审核」戳对外，或退回成本会计（撤下定稿指针）。终审弹窗显示初审信息、不建议报价理由、**本版通过后将替代哪些旧版**。
- **只有终审版对外** ✅；**改了成本必重审**（失效审核态）；重新初审清空终审戳。
- **双人闸 + 单人模式例外** ✅（业务方 2026-09-04 定「仅主管理员可自审」，V2.430）：初审人不得自己终审（代码强制）；**主管理员例外可自审**，戳与留痕**明记「自审·单人」**。普通账号仍强制双人。

### 2.4 作废：标记不删除，申请 + 终审批准两步 ✅

作废＝标记（`active=0, inactive_kind=voided`），申请（理由必填）→ 终审批准；**申请人不得自批，主管理员例外可自批**（V2.431，留痕标「自批」）。

**主管理员密钥删除** ✅（业务方定 2026-09-06，V2.459）：作废之外的**真删**，只给主管理员，每次输密钥（服务器 `conf.ini [bom] delete_key`，未配置＝通道关闭）。三处入口：标准台账/采购核算表详情「🗑 删除」（单条）、处理页「🗑 删除本组」（整组含被替换旧版）与「🗑 删除整单」、待办列表行「删除」（整单＝全部组 + 待修批次 + 留档文件）。删前先摆影响面（对外版计数、谁把它当上游、被它替代将恢复的旧版、并行组变化），理由必填；**全局审计必记**谁删了什么、为什么，密钥错也记。删后定稿指针自愈（V2.460/461：删了当前版则指向同产品仍有效的最新审核版）。

### 2.5 换码承接：同 CP 重核 / 不同 CP 同物料编码 ✅（业务方定 2026-09-05~06，V2.440→V2.462）

业务方规则原话：
1. **「CP 码不会重复；如果重复，成本会计审核时就要跳出来，原来那个是否失效。」**
2. **「1 月审核通过的 CP0001 带了物料编码 X，2 月审核的 CP0002 带同一个 X，那所有引用 CP0001 的定价都需要重新提示 BP。」**
3. **「有的火腿片就是各种各样的版本，CP 码不一样，有的用印刷袋、有的用空白袋，这些都是并行的。」**（并行版本都对外）

落法：
- **失效＝标记**（`obsolete_by/at/note`），不改 active、不改状态。与「替换」「作废」三者分开。
- **检测点**：初审（定性即定稿 / finalize）与「补物料编码」两处。命中同 CP 或同物料编码的有效已审核版 → 弹窗列出，**必须三选一**：**A「是，原版失效」**＝新旧版、本版替代；**B「否，并行但关联」**＝同一产品的并行版本，**都对外、互不替代**，串成并行组 `variant_group`（台账标「⇉ 并行」，接口带 `variantGroup/variants`）；**C「补录历史版」**＝本版比现有审核版**更早**，只盖初审戳、不替代、不动定稿指针、不对外，只为让同单的半成品/成品能定稿（本版核算日期早于候选时红字建议答 C）。不答＝只存定性不定稿。对比弹窗可直接「标为并行关联 / 解除」。
- **上游链路口径**（V2.460/462/478/479）：料行引用的半成品/复配料在台账里的状态。**同名配不上时按料行型号栏的研发码（CP）兜底**（V2.478：「钵钵鸡复合调味酱」vs 台账「钵钵鸡风味复合调味料」差一字曾漏列）；同名多版按 同组›同单›定稿版›不晚于本单›最新 挑；上游那版**审过即可**（初审/已审核，含历史版）且价格对得上。列序（业务方定 2026-09-06）：编号（上游 CP）· 物料名称 · 上游含税价 · 本批含税价 · 差异（含审核状态标签）· 看子采购核算表。
- **对外时点**：旧版在新版**终审通过那一刻**退出——终审前 BP 仍拿旧版。新版被退回 / 撤销定稿 / 改成本失效 / 作废 / 删除 → 旧版**自动恢复**。
- **对外口**：`/api/bomcost/final` 只发当前版；每行 `supersedes[]`、`variants[]`；同一物料编码若老数据仍有多条 → 只发最新 + `warnings[]`。**同一 erpCode 永远只返一行**（并行组例外，见对接回复 §9）。

#### 2.5.1 无物料编码的产品 ✅（业务方纠正 2026-09-05）

**没中试的产品本来就没有 ERP 物料编码** → ⛔ **物料编码不做定稿/终审闸**。无编码可正常初审、终审、对外。

#### 2.5.2 按 CP 到金蝶物料档案反查物料编码 ✅（V2.441）

金蝶物料档案 `BD_MATERIAL` 自定义字段**「研发编码」登的就是 CP 码**；同一研发编码可挂多个物料编码 → **只出候选让成本会计选，绝不自动写**。三处提示、一处都不拦；采用编码若撞码，立即进 §2.5 的替代确认。

### 2.5.3 历史补录：照常初审，初审通过即盖「补录」戳定稿，不经财务BP终审 ✅（业务方定 2026-09-06，V2.474；承接 V2.501）

- **初审通过那一刻直接定稿·对外**——状态「已审核」，终审戳 `ack.by=历史补录`（记初审人），占定稿指针，**不进财务BP终审待办**；换码承接、上游闸照常；

**采购核算表详情动作条**（V2.463，业务方定序）：‹返回上一级（灰）· ⤓导出采购核算表▾（灰，含 原版/重排版/**财务版+脱敏版 zip**/版本对比）· ⌦申请作废（琥珀边）· ✎修改价税费（蓝边）· ⚑审核归档（绿实心；已归档后为 改定性(蓝边)+撤销归档(琥珀边)）· ⌦作废终审（琥珀实心，财务BP）· 🗑删除（红实心，仅主管理员）。灰＝看，蓝＝改，琥珀＝可逆/待批，绿＝主流程，红＝不可逆。

### 2.6 BP 工作台只读标准成本台账：入口在 BP，动作在核算 ✅（V2.442）

- BP 工作台一张**不可修改**的镜像：已审核对外版 + **关联采购核算表 / 对比 / 下载采购核算表**（BP 侧自己渲染**脱敏版**，§5.3）；跳核算工作台看全量的深链**只给主管理员**。
- **财务BP 的终审在核算工作台做**（`enter:bomstd + bom:final_review`）。BP 页面顶部只放「有 N 条待你终审 → 去核算终审」（`/api/bomcost/pending-final`）。
- **被引用次数**是 BP 自己 `pricingMaterial` 的事，核算侧不知道也不该知道。
- 导出/预览接口对 BP 后台内部令牌**只准脱敏版、只准已审核版**。

### 2.7 单位净重 `net_weight_kg` ✅（V2.445 改为参考值）

**成本会计不知道最小销售单元** → ⛔ 不做定稿闸、核算侧页面不体现；接口只带规格文本解析出的每袋净重**参考值**；**BP 侧维护「最小销售单元 + 单位净重」，换算以 BP 为准**。

### 2.8 「核对」弹窗：金蝶反查 + 两张采购核算表逐料对比 + 金蝶 BOM 用量对比 ✅（V2.444/454）

右栏物料编码「核对」→ 弹窗：①金蝶物料档案候选；②金蝶 ENG_BOM 已登用量 vs 本表用量（同子件多行先汇总）；③与台账里同物料编码 / 同 CP 的其它采购核算表逐料对比。用途：判断两条是**同一产品的新旧版**（该替代）还是**两个并存产品**，再答 A/B/C。

### 2.9 与 OA 流程的衔接：自动立项 + 两版导出，OA 表单照旧人传 ✅（吴总定 2026-09-07，V2.504/505）

**定案**（财务总监吴卓文，2026-09-07）：复核审核在工作台做；做完由志鹏照旧把采购核算表手工传回 OA 表单「成本核算表（商品版本）」并点同意，**钉钉流程本身不动**。研发 BOM 审核以后也搬进工作台时，再考虑整个流程进工作台。

- **自动立项**：OA「BOM表报价」到**成本核算节点**（activity_id `23b2_ee20`，志鹏 + 冯辉或签、正常志鹏审），服务器每 5 分钟轮询在途单，台账没有的自动立项进待办（操作人「自动立项」），并给该节点**全部在办人**发钉钉提醒（入账/待修数 + 工作台路径）。只看启用日之后的单，**不回灌历史**；本地开发机不触发。conf.ini `[bom] auto_intake=1` 开、`cost_node_ids` 可改；`/api/bom/auto-intake/status|run`（主管理员可手动跑一轮、可静默）。
- **两版导出**：详情页「导出采购核算表 › 财务版 + 脱敏版（一次下两份）」→ zip：**财务版**全量活公式（财务看）、**脱敏版**遮型号/规格/供应商（给商品经理），附说明页。
- **为什么不自动传回表单**：钉钉官方审批**没有「审批人改表单字段」的服务端接口**（只有发起/同意拒绝/评论/撤销/转交/模板；名字带"更新实例"的只对第三方流程中心实例改状态），表单那一格只能人在客户端传。节点审批记录挂附件（同意时带 `file.attachments`）技术可行，但等于替人点同意、且差钉盘上传权限，吴总不要；评论区留言权限已有，业务方不要。
