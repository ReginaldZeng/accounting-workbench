## 1. 目标与价值

研发在钉钉「BOM表报价（研发使用）」审批里提交成本核算表 xlsx。现状：成本会计要在附件里一张张核研发填的用量、采购价对不对，靠人眼、易漏、无留痕、口径不统一。

本工具一句话：**按审批编号自动抓附件、解析成结构化台账（含税五分项），成本会计逐料复核（用量自洽 + 逐料核价，改税率费用留痕）后初审，财务BP终审，终审版成为标准成本、供 BP 定价直接消费。**

1. **自动入账**：钉钉审批附件自动抓取解析，一单多产品自动出多条，勾稽不平不入账。
2. **两步复核**：③用量自洽（研发核算表 vs 研发 BOM清单）④逐料核价（研发填价 vs 金蝶实采应付），改税率/费用留痕。
3. **终审即公开**：终审版进「标准成本台账」对外，供 BP 定价消费；初审版内部可见、不外发；未审核只有权限人看。

### 2.1 信息架构：三级菜单 ✅

```
成本模块（一级）
└─ BOM报价审核（二级 · 分组）
   ├─ 待办与复核（三级）      ← 未审核工作台（按钉钉单号立项，见 §2.2）
   ├─ 标准成本台账（三级）    ← 已初审/已终审（内部见管线；对外只终审版）
   └─ 基础设置（三级）        ← 公开版脱敏规则、发票规则
```

- **定稿 = 从「待办与复核」毕业进「标准成本台账」**。
- ✅ **BP 工作台放一份只读镜像**（§2.6）：核算侧为真相源、BP 只读。

### 2.2 待办的处理单元：钉钉单号 → 组 → 处理页 ✅（业务方定 2026-09-03，A 方案）

（同 v1.1，不变）**一个成本核算表文件（连同其成品/半成品/复配料 sheet + 编码对得上的 BOM）＝ 一组**；组锚点 `group_id = hash(源+审批号+成品归组键)`；替换语义＝新文件里勾稽平的产品顶替同组同产品旧版（旧版 `active=0` 留痕、退出标准库、清定稿指针）。
- V2.432/433：纯历史组（0 active）不占组号、收进「历史留痕」块；替换留痕默认折叠。

### 2.3 两个戳的审核流：成本会计初审 → 财务BP终审 ✅

```
未复核 → 已复核 →  【初审】(成本会计)  →  【已审核】(财务BP终审)
                   ③④确认 + 审核定性        盖已审核戳·对外开放
                   + 单位净重 + 换码承接确认
```

- **成本会计初审**：③④两步确认 + 审核定性（§5.1）→ **定性即定稿**，盖「初审」戳。定稿闸：四步齐 / 上游链路就绪 / **单位净重(kg) > 0**（§2.7）/ **换码承接已答**（§2.5）。
- **财务BP终审**：在**核算工作台**「标准成本台账 → ⚑终审」做（不在 BP 工作台，§2.6）；通过盖「已审核」戳对外，或退回成本会计（撤下定稿指针）。终审弹窗显示初审信息、不建议报价理由、**本版通过后将替代哪些旧版**。
- **只有终审版对外** ✅；**改了成本必重审**（失效审核态）；重新初审清空终审戳。
- **双人闸 + 单人模式例外** ✅（业务方 2026-09-04 三选一定「仅主管理员可自审」，V2.430）：初审人不得自己终审（代码强制）；**主管理员例外可自审**——小团队一人身兼时不必造假账号，但戳与留痕**明记「自审·单人」**，台账状态列显琥珀「自审」。普通账号仍强制双人。

### 2.4 作废：标记不删除，申请 + 终审批准两步 ✅

（同 v1.1）作废＝标记（`active=0, inactive_kind=voided`），申请（理由必填）→ 终审批准；**申请人不得自批，主管理员例外可自批**（V2.431，留痕标「自批」）。申请作废按钮 V2.431 恢复。

### 2.5 换码承接：同 CP 重核 / 不同 CP 同物料编码 ✅（业务方定 2026-09-05，V2.440）

业务方两条规则原话：
1. **「CP 码不会重复；如果重复，成本会计审核时就要跳出来，原来那个是否失效。」**
2. **「1 月审核通过的 CP0001 带了物料编码 X，2 月审核的 CP0002 带同一个 X，那所有引用 CP0001 的定价都需要重新提示 BP。」**（物料编码＝BP 眼里的身份，CP＝研发版本；后审核的替代先审核的）

落法：
- **失效＝标记**（`obsolete_by/at/note`），不改 active、不改状态——记录、留痕、历史都在，只是不再是对外版。与「替换」「作废」三者分开。
- **检测点**：初审（定性即定稿 / finalize）与「补物料编码」两处。命中同 CP 或同物料编码的有效已审核版 → 弹窗列出（CP/名称/编码/原因/审核日/全成本），**必须二选一**（业务方定 2026-09-05，V2.449）：**A「是，原版失效」**＝新旧版、本版替代；**B「否，并行但关联」**＝同一产品的并行版本（火腿片各版 CP 不同 / 印刷袋 vs 空白袋），**都对外、互不替代**，串成并行组 `variant_group`（台账标「⇉ 并行」，接口带 `variantGroup/variants`，同组共用物料编码不去重）。不答＝只存定性不定稿。补编码撞码按「后审核的替代先审核的」定方向后确认；同组并行成员共用编码不再问。对比弹窗可直接「标为并行关联 / 解除」。
- **对外时点**：旧版在新版**终审通过那一刻**退出——终审前 BP 仍拿旧版，不出现「没成本」空档。新版被退回 / 撤销定稿 / 改成本失效 / 作废 → 旧版**自动恢复**为当前版，再初审重新问。
- **对外口**：`/api/bomcost/final` 只发当前版；每行 `supersedes[]`（替代的旧版 entryId/productKey/erpCode）供 BP 翻引用旧 CP 的方案；同一物料编码若老数据仍有多条对外 → 按审核时间只发最新 + `warnings[]`。**同一 erpCode 永远只返一行**。
- **台账**：「已失效 · 被 CPxxxx 替代」（灰、默认收起，可切换）/「待替代 · CPxxxx 待终审」（琥珀，仍对外）/「替代 CPxxxx」；详情页双横幅；终审弹窗显影响面。

#### 2.5.1 无物料编码的产品 ✅（业务方纠正 2026-09-05）

**没中试的产品本来就没有 ERP 物料编码**（中试后才建档），BOM 报价审的恰恰多是新品 → ⛔ **物料编码不做定稿/终审闸**。无编码可正常初审、终审、对外。

#### 2.5.2 按 CP 到金蝶物料档案反查物料编码 ✅（业务方提议 2026-09-05，V2.441）

- 金蝶物料档案（`BD_MATERIAL`）自定义字段**「研发编码」登的就是 CP 码**（本账套实测 892 个物料带码）。
- **同一研发编码可挂多个物料编码**（97 例：名字不同的两料 / 正式码 + T 开头临时码并存）→ **只出候选让成本会计选，绝不自动写**。
- 三处提示、一处都不拦：核算表右栏「物料编码」行（无码自动反查列候选「采用」）/ 审核定稿弹窗候选横幅 / 台账「补物料编码」提示预填。采用编码若撞码，立即进 §2.5 的替代确认。
- 金蝶未登此 CP → 显示「多为未中试 / 未建档，可先无编码定稿，建档后再补」。

### 2.6 BP 工作台只读标准成本台账：入口在 BP，动作在核算 ✅（业务方定 2026-09-05，V2.442）

- BP 工作台一张**不可修改**的镜像：已审核对外版 + 三个动作 **关联核算表 / 对比 / 下载核算表**。**关联核算表与下载在 BP 侧自己渲染脱敏版**（`sheetUrl / previewUrl / downloadUrl`，见 §5.3）；跳核算工作台看全量的深链（`adminDetailUrl / adminCompareUrl`）**只给主管理员**（业务方定 2026-09-06）。
- **财务BP 的终审在核算工作台做**（统一门户账号 + `enter:bomstd` + `bom:final_review`）。BP 页面顶部只放「有 N 条待你终审 → 去核算终审」（`/api/bomcost/pending-final` + `finalReviewUrl` 深链）。理由：终审是对核算数据的控制，需要勾稽/上游/四步/留痕上下文；一份留痕一套权限；两处能审迟早对不上。
- **被引用次数**（哪些定价方案引用了这行）是 BP 自己 `pricingMaterial` 的事，核算侧不知道也不该知道。
- 导出/预览接口对 BP 后台内部令牌放行，但**只准拿已审核版**（初审版 403）。
- 页面怎么摆见《对接说明_BP只读标准成本台账_20260905.md》。

### 2.7 单位净重 `net_weight_kg` ✅（V2.439 上线为定稿闸 → **V2.445 改为参考值，业务方定 2026-09-05**）

台账元/kg、BP 电商按袋/盒定价，中间差「一个销售单位多少 kg」。**成本会计不知道最小销售单元**（一袋/一盒/一组几袋/一箱是定价的事）→ ⛔ 不做定稿闸、不要成本会计确认。核算侧**页面上不体现净重**（V2.446，业务方定），只在接口里带规格文本解析出的每袋净重**参考值**（`500g/袋`→0.5，解析不出 `null`）；**BP 侧在自己的物料表维护「最小销售单元 + 单位净重」，换算以 BP 为准**。

### 2.8 「核对」弹窗：金蝶反查 + 两张核算表逐料对比 ✅（业务方提 2026-09-05，V2.444）

右栏物料编码「核对」→ 弹窗：①金蝶物料档案候选（§2.5.2）；②与台账里**同物料编码 / 同 CP** 的其它核算表**逐料对比**——五分项并排 + 逐料（核算表添加量、含税采购价、成本不含税；两边都有 BOM 清单再并 BOM 用量），判定 一致 / 用量不符 / 价格不同 / 仅本单 / 仅对方，差异排前。「审核定稿」弹窗的换码候选也带「对比 ›」。用途：判断两条是**同一产品的新旧版**（该替代）还是**两个并存产品**（编码填错或共用 SKU），再决定答「原版是否失效」。
