# V2.523 · 成品导出采购核算表带上游链路：一本多页（复配料 → 半成品 → 成品），财务版 / 脱敏版 / 预览 / 两版 zip 一致

**日期**：2026-09-08　**业务方定**：「如果是成品，导出核算表，需要同时带出来他的半成品和复配料」。

## 口径

- 导出本品时，把它**上游链路**（按 `_upstream_status` 挑的那版：同组 › 同单 › 定稿版 › 不晚于本单 › 最新）递归带出，同一本工作簿一页一产品，**页序同原表：复配料 → 半成品 → 本品**，打开停在本品页；文件名尾缀「（含上游 N 页）」。
- 半成品导出带它的复配料；复配料单页。导入的无明细行不进链路。
- 财务版（全量）、脱敏版（遮型号/规格/供应商）、网页预览（多页顺序渲染）、两版 zip、BP 侧脱敏导出 全部同规则；`chain=0` 只出本品页。
- 各页仍是活公式自洽的重排版；成品料行里引用半成品的含税价是值（不跨页引用），与原表一致。

## 改

- kernel `build_pretty(..., wb=None)`：传 wb 则在同一本里追加一页（同名页自动加序号）返回 wb；不传照旧返回字节。
- router `_chain_entries(e)`（递归自下而上）、`_build_chain_xlsx(e, masked, formulas, chain)`、`_chain_suffix`、`_want_chain`；`/api/bom/export/pretty`、`/api/bom/export/pair`、`/api/bomcost/export` 三口改走；zip 说明加「上游链路同簿」一行。
- 前端导出菜单文案注明"成品/半成品自动带上游页"。

## 实测（沙盒 v515 库，251965 链路）

成品导出 3 页 `['复合调味酱','蘑力辣丝丝半成品','蘑力辣丝丝']`、打开停在成品页、文件名「…（含上游2页）」；半成品 2 页；复配料 1 页；`chain=0` 1 页；预览 HTML 含三页；两版 zip 各 3 页；说明.txt 带链路行。
