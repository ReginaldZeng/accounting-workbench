# V2.752 付款做账预览弹窗重排

用户：「有点乱了，重新设计下？」原来的问题：计提表和发票表并排，发票表超出弹窗；摘要被截断；凭证里每行都重复同一句长摘要；「6% → 9%」被挤成三行。

改成从上往下读：
1. **头部**：物流商编码 + 全称 · 主体 · 金额 · 账单月；下一行是审批、付款、票夹、纸质件状态，以及「先做账」放行按钮。
2. **结论条**：按做账类型着色（需红冲更正为红底）。其余提示放在下面的小字。
3. **① 按税率核对**（新增）：每个税率一行，写「计提 / 更正后 / 发票 ✓对上」，一眼看出为什么要红冲更正（易风达：6% 计提 17,868 → 更正后 17,568 = 发票；9% 69,300 → 69,600 = 发票）。
4. **② 计提凭证**、**③ 发票**：上下排，都占满宽度，列宽固定。计提表显示费用项目，原摘要放到鼠标悬停提示里；处理列写「核销」或「红冲 + 更正 · 原因」。
5. **④ 凭证预览**：
   - 同一块里摘要相同的写「同上」，核销块的待认证行写「发票号 + 同上」，鼠标悬停看完整摘要；
   - 核算维度压成一行；
   - 合计行显示「借贷平衡 ✓」。

本机用线上易风达那张单子的真实预览数据渲染核对过，表格不再超出弹窗。
