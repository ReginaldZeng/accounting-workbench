# V2.937 付款做账：「自动做账 / 做完提醒」那一块默认收成一行

- 日期：2026-10-13
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 付款做账

## 起因

V2.936 总表换成四步的表以后，用户截了表上面「自动做账」那一块：「这部分好占位置」。
这一块原来固定四行（档位和范围、上一轮结果、做完提醒、提醒说明），把下面的五个数和表往下顶了一大截。

## 改动

- `frontend/src/views/LogisticsVoucher.jsx`（自动做账条）
  - 默认收成一行：自动做账 · 档位（关 / 演练 / 真做）· 上一轮几点、会做（或做成）几张、不做几张 · 做完提醒发给谁 · 「现在演练一轮 / 现在跑一轮」 · 「展开设置」。
  - 点「不做 N 张」直接展开并打开「是哪几张、为什么」的清单。
  - 点「展开设置」回到原来的四行，所有设置（档位、范围、单笔上限、每轮最多、收件人、发一条试试、看发了什么）都在原处；右上角多一个「收起」。
  - 收起还是展开记在这台电脑的浏览器里，下次打开还是上次的样子。
  - 正在跑的时候，收起的那一行照样有「正在跑，看做到哪了」，进度窗照常弹。

## 验证

- 用真数据把真页面渲染出来自查（接口全拦截，不碰生产）：收起时这一块高 46 像素，展开 153 像素（四行）；展开 → 收起 → 记住了；四步表、弹窗、明细视图照常，控制台 0 报错。
- **没验的**：上线后的真页面没在浏览器里点过；「真做」档、正在跑时那一行的样子没有真数据可看。
