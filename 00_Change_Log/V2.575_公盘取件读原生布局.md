# V2.575 公盘取件读原生布局：按别名认店 + 按年月归期，免文件夹名写错

## 读原生布局（routers/ec_workbench.py）
- 公盘「一键取件」/「查看公盘」由死路径 `期间/店铺ID` 升级为读你们公盘原生 `年 / 年月 / 店铺-数据`。
- 新增 `_norm_shop` / `_shop_tokens` / `_period_of` / `_inbox_files`：
  - **店按别名精确认**（系统ID/管理名/金蝶名/基础资料填的公盘文件夹名别名归一比对），文件夹名怎么起都能对到店、也不串店；
  - **期间按 年月 文件夹容错解析**（2026年8月 / 2026-08 / 202608 / 2026.8 皆可）；
  - 未填别名则认不到该店文件（安全：不误收），提示去基础资料·店铺对照补公盘文件夹名；
  - 兼容旧的 `期间/店铺ID` 扁平布局；只读原文件不改不删。
- `/inbox` 与 `/inbox-import` 共用同一解析器。真函数切片单测通过（认店/换期/不串店/未填别名不误收/兼容扁平）。

取件机因此只需把公盘 `4.1 电商对账` 整棵树原样镜像，谁都不用改名。纯后端，不改核算、不写金蝶。
