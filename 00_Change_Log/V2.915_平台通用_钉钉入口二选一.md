# V2.915 平台通用：钉钉入口二选一

**起因**：钉钉里挂的「星衡智策」点开只通向工作台。没有工作台账号的同事（全公司大多数人）停在登录页，只看到"请联系管理员开通"；
而他们真正要用的发票后补登记页得另外打开专门的网址。用户要的是：从这里进来，没账号的直接到发票后补单，有账号的选一下去哪。
（讨论过"门户上加一张卡""右上角小入口"，用户定的是二选一页，并要求做好看——面向全公司。）

**改法**（只动前端，后端没改）：

- 新页 `DdEntry.jsx`：紫色品牌面板＋标志＋黄猫一家（和登录页一套素材），两张大卡「发票后补单」「财务工作台」。
  手机是上下排，电脑钉钉是和登录页同一个壳（左品牌、右选入口）。样机：`docs/20261012_钉钉入口二选一/prototype/entry_choice.html`。
- 什么时候出这一页（`App.jsx` ＋ `ddLogin.js`）：
  1. 在钉钉里打开首页、钉钉身份对上了工作台账号（或本来就登着）→ 出二选一。
  2. 选「财务工作台」→ 照常进门户；这次打开期间不再问（刷新、退出重登都不问），重新从钉钉点开会再问。
  3. 选「发票后补单」→ 换到申请人自助登记页 `#/invself`（那一页在钉钉里自己认人）。
  4. 钉钉认出是本公司的人、但没对上账号 → 不出二选一，直接去 `#/invself`。
  5. 链接里带着具体去处（`#/某一页`）→ 不问，直接去那一页。不在钉钉里 → 和以前一样。
- 发票后补登记页底部加「有工作台账号？进财务工作台 ›」：有账号的回工作台；有账号但钉钉还没对上的，过去会看到登录框，输一次密码就对上，以后就出二选一。
- 电脑浏览器登录页底部加一行「只是来登记发票后补？不用工作台账号，从这里进 ›」。
- 卡片上不放"你有 N 张发票还没交"（用户定）：系统只知道登记过的后补单，没登记的看不到，放了容易让人以为没提示就是不欠票。

  覆盖上面 1–5 各一条、不在钉钉里两条（没登录／已登录）、版式一条（375×603 小屏手机一屏放下、电脑左右两栏、标志显示得出、猫看向悬停的卡）。

- 本机起服务看过电脑浏览器登录页的新入口。

**遗留**：

- **真钉钉里没验过**。回归里的"钉钉"是装的；真机上要看：从钉钉点开是不是出二选一、没账号的同事是不是直接进后补单、后补页在钉钉里自动认人成不成。
- 已有账号的人每次从钉钉点开都要多点一下（用户知情，选的就是每次明确选）。
