# V2.769 物流复核台第③步：「发票与暂估」显示费用类型

日期：2026-10-03

## 背景
V2.768 上表一行一个税率，用户截图反馈「看不出来费用类型」。

## 改动（只改 `frontend/src/views/LogisticsInvCompare.jsx`）
- 上表改成 **一行一张计提凭证**：费用类型 · 产品线 / 计提凭证号 / 税率 / 含税 / 暂估税。
- 右边发票按税率合并对比（发票是按税率开的，对不到单张计提）：同税率的几张计提并在一格里比 发票含税、发票税额，格内小字写「N 张计提合计」，差额单列。
- 要改税率的计提（计提 6%、发票 9%）排到发票那个税率下面，税率格写「6% → 9%」标红。
- 某税率只有发票没有计提的，单列一行提示。
- 结论列加宽；单元格强制可换行（线上页面全局样式是不换行，V2.768 结论文字被截断）。
- 后端接口不变（accruals 已带 fee/biz/vno/month/rate/mode/new_rate）。

## 验证
线上 8 月真数据(极鲜达/易风达/天鹰/恒茂)本地渲染成静态页截图核对。
