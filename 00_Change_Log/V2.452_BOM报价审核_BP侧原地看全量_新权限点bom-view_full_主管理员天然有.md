# V2.452 · BP 侧原地看全量：新权限点 `bom:view_full`（敏感）；主管理员天然全量；`full=1` + `X-On-Behalf-Of`

**日期**：2026-09-06　**业务方定**：主管理员要能在 BP 工作台原地看全量；非主管理员想看全量→用权限点管，勾了才给。

## 规则

| 谁 | BP 侧 `/api/bomcost/sheet|export` 加 `full=1` | 不加 |
|---|---|---|
| 主管理员（Owner / 总监） | **全量**（不遮），文件名「全量版」 | 脱敏版 |
| 有 `bom:view_full` 的人 | **全量** | 脱敏版 |
| 其他人 | 照旧**脱敏版**（`full=1` 无效） | 脱敏版 |

每次以全量拉取都留审计 `bom_view_full`（谁、经 BP 还是门户、看了哪条）。

## 落法

- **权限点** `bom:view_full`「核算表全量查阅（BP侧原地看全量，含供应商/型号/规格）」：ws=accounting、组 BOM报价审核、**敏感**（默认不给、模板套不上、逐人手勾）。
- **谁在拉**（`_bp_actor`）：门户登录＝登录人；BP 后台内部令牌代拉＝请求头 `X-On-Behalf-Of`（URL 编码姓名，同 X-BP-User 写法）报上的人，核算侧到账号管理 `get_user` 查——查不到 / 停用 / 没报 → 只能脱敏。全量＝`is_super` 或 `user_can(bom:view_full)`。
- `sheet` 响应加 `fullAllowed`（本人能否全量，BP 据此显不显示「切全量」）、`viewer`、`masked`（本次是否遮了）；`/api/bomcost/final` 顶层也带 `viewer/fullAllowed`。
- `export` 全量时标题/文件名「全量版」，脱敏时「脱敏版（已遮 …）」。
- 不动核算侧内部页面（那里本来就是全量）。

## BP 侧要做

- 代拉 `sheet/export/final` 时带 `X-On-Behalf-Of: <当前登录人姓名（URL 编码）>`。
- 读 `fullAllowed`：true 才显示「切全量 / 下全量」，点了带 `full=1` 再拉一次。

## 验证

整 app TestClient：内部令牌 + 主管理员姓名 + full=1 → 不遮、hiddenColumns=[]、文件名全量版、审计落一条；有 `bom:view_full` 的普通账号 → 全量；无该点 → 照旧脱敏且 `fullAllowed=false`；未报姓名 → 脱敏；停用账号 → 脱敏；不带 full 的主管理员 → 脱敏但 `fullAllowed=true`。
