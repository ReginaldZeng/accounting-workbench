# V2.525 · BOM 专用取件码 + 成本会计电脑上的小取件机 bom_pull：初审通过的采购核算表自动落桌面（年/月目录）

**日期**：2026-09-08　**业务方定**：「传到成本会计本地是不是更好」→「桌面 C 盘」。机制与落公盘一样（一台电脑揣码去服务器取），只是取件机装在成本会计电脑上、目标是桌面。

## 口径

- **BOM 专用取件码**：conf.ini `[bom] pull_token`（纯 ASCII，未配＝专用通道关）。只放行 `/api/bom/outbox/*`：取得了采购核算表，**取不了报表、登录不了工作台**（报表取件码权限太大，不给成本会计电脑）。报表那台机器的码照样能取 BOM（公盘那条路仍在）。
- **小取件机 `bom_pull.ps1`**（零安装，PowerShell 自带）：读 `bom_pull.ini`（server / pull_token / dest_dir，默认 `%USERPROFILE%\Desktop\BOM报价审核`，不存在自动建）；每 2 分钟一轮，列 outbox → 按 `年\月\` 建子目录落本机；只比「服务器端 大小+修改时间」判变；只增不删；先写 .part 再改名。
- 配套：`bom_pull_hidden.vbs`（无窗口）、`install_bom_task.ps1` + `注册BOM取件.bat`（先试跑再注册计划任务「BOM采购核算表取件机」，每 2 分钟、无窗口、当前账号）、`BOM取件机安装说明.md`。

## 改

- router：`bom_pull_token()` / `bom_pull_token_ok()`；`_outbox_pull_ok` ＝ BOM 码 / 报表码 / 登录+标准台账 任一。
- app.py 登录门：`/api/bom/outbox/*` 带对 BOM 码放行（其它路径不放）。
- conf.ini.example `[bom] pull_token`；tools/ 新增五个文件 + 说明。

## 实测（本机起 8766 端口真服务 + 真跑 ps1）

BOM 码：`/api/bom/outbox/files` 200、错码 401、拿 BOM 码去开 `/api/rptexport/files` 401（越不了界）。`bom_pull.ps1` 第一轮下载 4 个到 `…\BOM报价审核\2026年\09月\（财务版|脱敏版）…xlsx`，第二轮全部跳过、不写日志；错码一轮日志「服务器拒绝（HTTP 401）：取件码不对…」退出码 1；父目录不存在时明确报错退出码 2。三个 ps1 均过 PowerShell 语法解析，UTF-8 BOM 在。
