# V2.768 物流复核台第③步：「发票与暂估」重排

日期：2026-10-03

## 背景
V2.767 的版式用户反馈「感觉有点乱」：每张请款单各放两张小表、列宽不齐；夹着「还没付款、先出红冲预览」这类和本步无关的提示；顶部四个大数和表内合计重复。

## 改动
- 新组件 `frontend/src/views/LogisticsInvCompare.jsx`（纯展示、自带样式），`LogisticsReview.jsx` 第③步改用它，旧版内联卡片与样式删除。
- 两张通栏表、所有请款单放一起、列固定对齐：
  1. **计提（暂估）对发票**：一行一个税率；含税金额(计提/发票/差额)、进项税(暂估/发票/差额)两组并排；差额为 0 显示「—」，不为 0 标红；
     左侧请款单格(主体/金额/钉钉进度/申请人)、右侧结论格(做账类型 + 不一致时一句原因)按请款单合并；底部合计行。
  2. **发票明细**：请款单(带发票管家票夹链接) / 发票号码 / 类型 / 税率(不抵扣标出) / 含税 / 税额 / 纸质件 / 做账凭证。
- 还没有发票的请款单：只标「还没有发票」，不显示差额和做账类型(否则整笔计提都显示成差额)；合计行同理。
- 去掉顶部四个大数、去掉与本步无关的提示。
- 后端接口不变。

## 验证
用线上 8 月真数据(极鲜达/易风达/天鹰/恒茂)在本地把组件渲染成静态页截图核过版式；空数据、读取失败、读取中三种状态也渲染过。
