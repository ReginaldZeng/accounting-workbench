## ① 结算风险单独成一页（④）

6 月有 **71 项待认**，原来整块压在「逐人核对」页顶，往下翻半天见不到逐人表。
现在是独立的第④步，**排在逐人核对之前**——它比工时偏离更要紧：
工时差一点是钱多付一点，同名重复和归属不符是**整个人的钱可能付两遍或付错对象**。

步骤变成八步：

```
①数据接入 ②核对总览 ③口径与单价 ④结算风险 ⑤逐人核对 ⑥逐日明细 ⑦表外临时工 ⑧报告出具
```

没有风险时那一页不留白，明确写「✓ 本期没有结算风险」并说明这页查的是哪两件事。

## ② 「确认无误」改成居中弹窗

原来是行内框：71 条的列表里点第 50 条，框子渲染在页面别处，人看不见就以为没反应。
改成遮罩 + 居中浮层，点遮罩或按 Esc 关，`max-height:86vh` 可滚。

## ③ 逐人加「只看异常」

判据写死在一处，勾上只留任一项对不上的人：

```
撑不起上报 / 报了工时没打卡 / 单价与合同价不符 / 合同价缺档 / 应付与结算表对不上
```

**合同价缺档也算异常**——那是「没法核」，不是「没问题」。

## ④ 逐日加同一套筛选框

逐日明细现在也有 部门 / 归属（派遣方）/ 姓名 三个筛选，跟逐人一模一样，
计数单位是「人日」。跟上一版的判定档按钮叠加使用：先按档筛，再按人筛。

筛选组件是同一个，逐日不显示应付合计（那是逐人才有的口径）。
