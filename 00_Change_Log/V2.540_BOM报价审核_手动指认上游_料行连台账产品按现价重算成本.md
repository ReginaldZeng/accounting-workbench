# V2.540 · 手动指认上游：料行连到台账产品，按其现全成本重算本品成本（撞名/带后缀自动连不上时用）

**日期**：2026-09-09　**业务方定**：撞名警告（V2.539「甲」）之后，「先做手动指认上游」——不等研发改表，成本会计在本品料行上直接指认它对应台账里哪个半成品/复配料。

## 背景（V2.539 那单的成本没连对）

单 27725 成品 CP04108204(SN5) 有一行料「菌菇辣丝丝半成品（油辣滋香风味）**-新内袋**」价 30.59（半成品旧价）。因带「-新内袋」后缀 + 半成品名撞名，自动连不上 → 成品成本搭在旧价 30.59 上，没跟半成品重算后的 34.21 走。

## 改

- 记录加 `manual_upstream` JSON 列：`{料行名: 上游产品键}`（或 `"__none__"` 明确外购非上游）。`_ensure_bom_columns` 自动补列。
- `_upstream_status`：**手动指认优先**——料行有指认就连到指认的台账产品（matchBy=手动指认），否则走原名/CP自动匹配。
- `POST /api/bom/set-upstream {entryId, matName, targetProductKey}`（需审核权限）：指认后 `_relink_recompute` 把该料行含税价换成上游现全成本、重算 costExcl→小计→全成本→勾稽；首次指认记原价，`__clear__` 撤销恢复原价，`__none__` 指认外购。改了成本→`_invalidate_review` 失效重审。逐条留痕。
- `_entry_view` 带 `manualUpstream` + `upstreamCandidates`（可指认的台账产品）。
- 前端详情料表：复配料/半成品行加「指认上游」下拉（自动匹配 / 外购非上游 / 指认→某台账产品），连上后成本自动重算。

## 实测（真钉钉 27725）

成品自动上游为空（-新内袋 连不上）→ 指认到 CP04113502-1：那行价 30.59→34.21（=半成品现全成本）、成品全成本 40.57→44.30 自动重算、上游连上勾稽平；撤销恢复 30.59。

## 已知（下一步）

处理页「审核顺序」深度树仍按同工作簿页名算（`upstream_refs`），暂不认手动指认；但定稿硬闸走 `_upstream_status`（认指认），所以成品要等半成品审过才放行——闸是对的，顺序图后补。
