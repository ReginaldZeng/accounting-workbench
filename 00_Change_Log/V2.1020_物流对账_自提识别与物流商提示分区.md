**【物流对账】自提识别与预览提示分区**。**起因**：销售出库表中的自提被未知物流商规则误判为“待补充”；“链盟4.2→链盟”等自动标准化记录混入异常/阻断，数量多且掩盖真正问题。**改法**：标准化时内置“自提/客户自提”为有效类型，无需补供应商；`carrier_normalized` 信息改为可折叠“物流商识别记录”，不计入异常数量、不阻碍确认。错误阻断和账期人工确认规则不变。10 个解析测试、11 个批次 API 测试、浏览器 QA 及正式构建通过。
