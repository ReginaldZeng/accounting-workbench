需求方本机验证后再调两条：

**①切片器终版定序+红色化**：全部 / 疑似漏账 / 疑记错户 / 做错·金额 / 金蝶单边·疑似做错 / 账户缺数据 / 内部往来 / 组合待确认 / 晚记 / 汇兑·账面调整 / 已匹配（较 V2.196：内部往来提前到账户缺数据之后、组合与晚记对调）。前六个"问题格"（漏账/记错户/做错/金蝶单边/账户缺数据/内部往来）计数改红色；**红底仅在计数>0 时亮**（0 时是普通格）——全红常亮太吵，有事才红。「账号对不上」维持藏零。

**②搜索框全字段模糊**（需求方定："支持模糊搜索户名，模糊账号（比如0388）以及金额"）：命中范围从 对方户名/摘要 扩为 **户名/主体/账号片段/开户行/对方户名/摘要 + 金额**。金额匹配：查询串去千分位/¥/空格后按"数字串包含"比对 借方/贷方/金蝶金额/差额（搜 933550 命中 933,550.93、搜 3000 命中 3,000.00、搜 0388 同时命中账号含 0388 的户）。提示语改「户名 / 账号片段 / 金额 / 对方 / 摘要」。

**验证**：前端构建通过；切片状态集合与后端状态零改动（纯排序与显示）。**遗留**：UI 未浏览器实测（登录墙、不代输密码）——需求方本机重启后看：切片顺序为终版、疑似漏账 7/账户缺数据 1/内部往来 3 亮红底、做错 0 等不红；搜索框输 0388 应筛出该账号片段的行、输 4503684 应命中 450 万那对。
