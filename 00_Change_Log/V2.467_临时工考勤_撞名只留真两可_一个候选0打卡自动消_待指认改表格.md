## 根因

V2.465 把「≥2 个不同的人」**全部**退回成本会计。但其中一大半是**送分题**：同名两人里
**一个当月 0 打卡**（本月没来上班），明摆着不是报了工时的那个——这种不该塞给人判。
再加上前端把 128 人**堆进一条 Note 的一行文本**，没法看。

## 改法

1. **取数侧 `resolve_dups` 消掉送分题**：定人认两类——① 合并手机号后只剩一个人（多账号）；
   ② **本月只有一个候选在打卡**（其余候选当月 0 打卡＝没来）。都不满足（≥2 个候选**都在打卡**）
   才是真两可 → 交成本会计。候选带上「定人理由」。这不是按 F1 猜，是看**当月有没有打卡**这个事实。
   → 128 缩回到「都在打卡、部门也分不清」的真两可那几个。
2. **前端待指认改成可折叠表格 `AmbigTable`**：姓名 / 候选钉钉部门 / 尾号 / 当月打卡，默认折叠、一眼可扫，
   不再是一长段跑马灯。取数结果的 `DupReview` 同步：已定人显示「定人理由」（多账号合并／对方 0 打卡），
   不再一律写「多账号已合并」。
