# V2.912 付款做账：自动做账跑的时候弹进度窗——正在做哪一张、做到哪一步

- 日期：2026-10-12
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 付款做账 › 自动做账

## 起因

用户把自动做账切到「真做」、点了「现在跑一轮」，页面上只有一个灰掉的「正在跑…」按钮，几分钟没有任何变化。
用户：「这里是不是可以加个弹窗，正在做那一笔，不然我完全不知道他在做什么」。

## 做了什么

点「现在跑一轮」（或者打开页面时定时的那一轮正好在跑），弹出进度窗，每 1.5 秒更新一次：

1. **现在在干什么**，分四段：
   - ① 正在找：付了款、票齐、还没做账的请款单
   - ② 正在逐张算怎么做：第 3 / 8 张　**主体｜供应商｜金额**（这一步只读金蝶、不写）
   - ③ 正在写金蝶：第 2 / 5 张　主体｜供应商｜金额　做账类型，下面一行是这一张已经做完的步骤：
     ✓ 付款单保存　✓ 付款单提交　✓ 付款单审核 FKD…　下一步进行中…
   - ④ 收尾：记结果、发提醒
2. **这一轮已经做完的**：一张一行——✓ / ✕、主体｜供应商｜金额、凭证号、说明（没做成的写原因）。
3. **跑完**：窗口不自己消失，写「做成 N 张、没做成 N 张；系统不自动做的 N 张」，演练档写「如果开着会做 N 张」。

窗口可以收起，不影响它继续跑；收起后「正在跑…」旁边有「正在跑，看做到哪了」可以再打开。离开页面再回来，只要那一轮还在跑，窗口会自己再出来。

## 改动

- `backend/routers/logistics_voucher.py`
  - 新增内存里的进度记录 `_AUTO_PROG`、`_POST_STEPS`，`auto_round` 在找单、逐张算、逐张写、收尾各处更新；出错、提前返回都会把「正在跑」落下来。
  - `_post_run` 把它边做边记的步骤列表登记到 `_POST_STEPS`（同一个列表，不改任何做账逻辑）。
  - 新增 `GET /api/logistics-voucher/auto/progress`，只读内存，不碰金蝶、不查库。
- `frontend/src/views/LogisticsVoucher.jsx`、`frontend/src/api.js`：进度窗 `AutoProgress`、轮询、再打开的入口。

做账本身的逻辑、顺序、写金蝶的内容一行没动；进度只是多记了一份「现在到哪了」。

## 验证

- 服务器上只读演练：新版路由别名加载，「保存到金蝶」换成假的（只等一会儿、往步骤里加字），写库、留痕、钉钉、数字员工办公室报到全部换成只记不做。
  另开线程跑一轮，主线程每 0.4 秒读进度：依次读到 找单 → 逐张算 1/8…7/8（每张的供应商）→ 写金蝶 1/3、2/3、3/3（步骤逐个出现，已完成 0→1→2）→ 跑完（做成 2、没做成 1 及原因）。
- **没验的**：进度窗本身没在浏览器里看过（我登不了页面）。
