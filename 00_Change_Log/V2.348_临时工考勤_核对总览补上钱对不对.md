# V2.348 · 临时工考勤 · 核对总览补上「钱对不对」

**日期**：2026-08-22　**分支**：main　**提交**：6224c4b

## 起因
使用者看着第②步核对总览那张四档表：**「这一块是不是要把单价不符的也放进来」**。

是。这一页叫「核对总览」，却只总览了工时那四档；单价不符只在状态条露一枚胶囊、
要点进第③步才看得到细节。**总览不总览钱，就不叫总览。**
而且四档判定讲的是「工时偏离」——这部分按定案本来就不影响付款；
真正关系到付出去的钱的那几项，反倒不在总览里。

## 改动
第②步拆成两块：

**一、工时对不对** —— 原那张四档判定表（与口径一致 / 弹性内多记 / 超弹性多记 / 少记 / 待查 / 白夜混合），未动。

**二、钱对不对** —— 新增一张四行表，每行「判定 · 结果 · 说明 · 去哪处理」：

| 核对项 | 判定 | 结果示例 | 去处 |
|---|---|---|---|
| 单价与合同价不符 | ⚠ 要查 | N 格（N 人 · N 小时） | 第③步逐格看 → |
| 合同价缺档 | △ 待核 | N 格（N 人 · N 小时） | 第③步登记 → |
| 结算表自查 | ⚠ 要查 / ✓ 全部通过 / — 未做 | N 处对不上 | 第⑦步看明细 → |
| 奖 / 罚 / 补贴 | ⚠ / △ / ✓ | N 笔，净额 ¥N（N 异常 · N 存疑） | 第⑦步看明细 → |

- 判定沿用全线三态：**⚠ 要查**（真对不上）／**△ 待核**（没登记，没法核）／**✓ 正常**；
  结算表没有金额列时是「— 未做」，**不装作正常**。
- 数全部取自后端 `stats`（`单价核对` / `金额核对` / `合同外调整合计`），与第③⑦步、导出报告**同源**——
  页面不再自己另算一套（那正是 V2.347 review 抓到的毛病之一）。金额核对剔掉已认定的项。
- 全部缺档时，「不符」那行不显示空的「—」，而是写明「本期用到的 N 格全部缺合同价，无从比对」。

## 实证（2026-07 原表，三种合同价状态）
```
一行都没登记      → 缺档 △待核 6 格（40 人 · 2,815 小时）；不符行「0 格 · 全部缺合同价，无从比对」
只登记锦绣且登错价 → 不符 ⚠要查 1 格（27 人 · 1,674 小时）、缺档 4 格、自查 54 处对不上
全部登记正确      → 四项全绿（一致 6 格）
```
内核测试 95 条全过（本次只动前端）。

## 留给下一个人的话
这一页的两块是**两个不同的问题**，别再合并：
工时偏离是「量出来的差」（不影响付款，少记不追）；
钱那四项是「对不上的账」（直接关系到付出去的钱）。
把它们摆成一张表，看的人会以为严重程度一样。

## 追加（同日）：结算风险卡搬去第④步

使用者看完第一版：**「感觉这个不应该在这里，应该在逐人核对那里，这个四档就是一个总览，
将这个异常提示在下面，并且告知在哪里处理就好了」**。

对——总览就该只总览。带「确认无误」按钮的结算风险卡是**要动手**的东西，摆在总览顶上
既挡住了四档表，又和「总览」这个定位打架。

- 风险卡（同名 / 归属不符 + 认定按钮 + 长期认定清单）**只在第④步逐人核对**
- ②总览里只在「二、钱对不对」留一行，排**第一**（它不是「算错多少钱」，
  是「同一笔钱付了两次 / 付给了不该付的那家」，比单价错更要紧）：
  `结算风险 ⚠要查 N 项待认 … 去第④步逐人核对 →`
- 步骤副标题跟着改：②「工时对不对 · 钱对不对 · 总量与差额」、④「一人一行 · 结算风险在此认定」

⚠ 实现上有个坑：认定弹层原来跟着 `RISK_STEPS` 走，但**第⑤步逐日明细有它自己的逐日
「确认无误」按钮**——弹层若只跟卡片走，⑤步一点按钮就没地方填理由了。故拆成两个常量：
`RISK_CARD_STEPS = ['people']`（卡片）与 `ACK_STEPS = ['people','daily']`（弹层）。
浏览器实测：⑤步点「确认无误」仍弹出「确认『沈武英 7 日 ⚠ 多记 2.5 小时(超弹性,异常)』无误」。

实测各步风险卡：②无 ③无 ④有 ⑤无。

## 再追加（同日）：删掉「本期状态」横幅

使用者：**「这个说了多少次删除」「这一页是概览，下面都有的，上面重复了」**。

对。V2.340 那次我只是把它从②③挪走，**没删**——而这一页补上「二、钱对不对」之后，
它整条都成了第二遍：

| 横幅上的项 | 下面哪里已经有 |
|---|---|
| ⚠ 单价与合同价不符 N 格 | 「二、钱对不对」单价行 |
| ⚠ 异常多记 N 日次 | 「一、工时对不对」多记（异常）行 |
| 已认定无误 N 项 | 第④步风险卡 |
| △ N 项待人工确认 | 下面那条黄色提示 |
| 本工具只读，不写金蝶 | 页面副标题 + ①使用说明 |

整条删除，`STATUS_STEPS` 常量一并删掉。两件下面没有的另作安置：
- **人数 / 人日** → 并进「一、工时对不对」的副标题
- **两表月份对不上** → 原来只在②出现，现在提到与错误提示同级，**哪一步都显示**
  （拿错文件这件事一旦成立，后面所有数都不必看）

「✓ 两表月份一致」这类"没事也报一句"的绿字不再出现——只在真对不上时给红条。
