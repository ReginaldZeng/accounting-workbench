# V2.742 发票后补：钉钉免登兼容与扫码登录

- 企业编号及线上签名接口核验正常；免登改为直接调用免登 API，不等待扫码用的 dd.config。兼容新版 clientId/corpId 接口、旧版接口和两种回调，保留原对象绑定并显示明确错误。
- 电脑端新增钉钉扫码登录。二维码五分钟有效，手机登录后核对电脑确认码并手动确认；电脑轮询取得自己的会话。
- 手机扫码凭证与电脑轮询凭证分离；扫码仅预览不登录，需已验证的手机会话明确确认。凭证仅存哈希，领取原子执行、一次性使用，拒绝过期和跨电脑 IP 领取。
- 手机如自动免登仍失败，可先用手机号验证码验证后确认电脑登录。

验证：接口测试 25 项；新旧免登与回退的 Node 自检通过；前端构建通过。实际手机容器免登需真机复验。
