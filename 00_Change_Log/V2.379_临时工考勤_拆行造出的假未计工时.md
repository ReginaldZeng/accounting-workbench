# V2.379 · 临时工考勤 · 「按业务线拆行」造出的 946 条假「未计工时」

**日期**：2026-08-29　**分支**：main

Reginald 筛出蔡庆一个人，问逐日明细「这是什么意思」：

```
4日  07:50–18:22  上报 8   重算 9.5   ✓ 打卡撑得住上报        （植物肉那行）
4日  07:50–18:22  上报 0   重算 9.5   ◇ 有打卡·当天未计临时工工时  （小料那行）
6日  07:46–20:31  上报 11  重算 11.5  ✓ 打卡撑得住上报        （小料那行）
6日  07:46–20:31  上报 0   重算 11.5  ◇ 有打卡·当天未计临时工工时  （植物肉那行）
```

同一天同一套打卡，摆了两遍，一遍说正常、一遍说「未计工时」。

## 原因

蔡庆当月在小料和植物肉都干过，工资要分摊到各车间，汇总表就把他**拆成两行**
（V2.353 认定的「按业务线拆行」，6 月有 117 组）。两行各自只在自己那几天有工时，
另一行那几天是 0。

逐日比对照单全收，就在「另一行的日子」上报一条「未计工时」——
**那天他明明记了工时，只是记在另一行**。纯属拆行造出来的假象。

## 规模

| | 改前 | 改后 |
|---|---|---|
| ◇ 有打卡·未计工时 | 1,242 | **296** |
| 比对人日 | 2,840 | 1,894 |
| ⚠ 撑不起上报 / ⚠ 待查 / ✓ 撑得住 | 4 / 0 / 1,594 | **一条没变** |

**1,242 条里 946 条是假的。** 这一档虽然是中性提示、不标红，但它撑着「比对人日」，
也让人翻逐日明细时满屏都是它——蔡庆一个人 6 行里有 3 行是废的。

## 改法

先扫一遍汇总表，记下「这个人这一天**在任何一行**上有没有工时」；
逐日比对时，本行这天没工时、而同一个人另一行有的，直接跳过不摆。

判据用**原始姓名**而不是归一名——张博G 和张博J 是两个人，不能并到一起。

内核测试 114 条全过。
