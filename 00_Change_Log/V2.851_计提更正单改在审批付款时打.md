# V2.851 计提更正单改在审批付款时一并打出来

日期：2026-10-06

V2.850 的做法是「谁装订谁打」（实习生扫到那张单时打）。用户看后定：「我觉得这样吧，在审批付款的时候一并打出来」——审批时纸质付款单还在自己手里，更正单当场订在后面一起流转。

改动（纯前端）：
- 复核台 · 钉钉请款单弹窗：多一行「做账预判」（计提和发票比对的结论：一致·只核销 / 要更正 / 要人工看 + 一句说明）；要红冲更正、尾差、记错主体的出「打印计提更正单」按钮。
- 复核台 · 「待我审批」那一排后面加「打印这几张的计提更正单」：把待我审批里要更正的一次打出来，不用更正的不出纸。
- 更正单版式：审批时还没有付款凭证，「调整凭证」处原来印「（保存到金蝶后生成）」，改成一道横线「____年__月 记-______（做账后填）」；调账月份标「预计」；页脚注明「审批时打印，还没做账：凭证号、调账月份以做账为准」。做完账再打的照旧印凭证号。
- 凭证装订：去掉「计提更正单」页签（不在这里打了）。扫到要附更正单的，结果卡提示「后面应订着计提更正单 · 把凭证号填上去」，留一个「补打一张」以防丢失。「还没扫到的」里更正单一栏照旧标「附」。

流程现在是：审批请款单时看做账预判 → 要更正的打更正单订在付款单后面 → 钉钉里审批 → 出纳付款 → 纸质单到实习生 → 工作台做付款凭证、财务经理审核 → 实习生在「凭证装订」扫码，把凭证号写到付款单和更正单上。

验证：用线上迅鸽孝感那张还在审批中的请款单（记-561 3,175.50 → 3,151.50）本地渲染了审批时的更正单，凭证号留空、调账月份标预计。线上 10 张审批中的请款单里现在有 2 张要更正（迅鸽两张）。**按钮没有在线上页面里真点过、没有真打过纸。**

上线：纯前端。
