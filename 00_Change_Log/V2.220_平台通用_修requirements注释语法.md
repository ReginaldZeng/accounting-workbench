**【平台通用】修 requirements.txt 注释语法**（需求方在服务器执行 `pip install -r requirements.txt` 报 ParserSyntaxError: Expected a marker variable or quoted string）。**根因**：清单里的中文行内注释用了分号 `;`——pip 语法中分号是**环境标记**（如 `; python_version<"3.9"`），"pandas 读 xlsx 要求…"被当标记解析即炸；单装某个包不触发，`-r` 整装必炸，故服务器一直没法按清单补依赖（这也是理财对账 OCR 组件 rapidocr_onnxruntime 明明在清单里、服务器却缺装的间接原因）。**改法**：全部行内注释 `;` → `#`（pip 合法注释），依赖与版本零变化。**验证**：pip 解析通过（语法错误消失、进入依赖解析阶段）；服务器 Python 3.11 按清单安装应正常。**当次应急**：已指导需求方在服务器单装 `pip install rapidocr_onnxruntime`（其余依赖服务器已有）。
