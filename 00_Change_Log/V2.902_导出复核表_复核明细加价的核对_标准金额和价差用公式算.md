# V2.902 导出复核表：复核明细加「价的核对」——标准金额、价差、结论都用公式算

- 日期：2026-10-11
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 物流账单复核台 › 导出复核表（「复核明细」页）

## 起因

V2.898 / V2.899 给复核明细加了「量」的公式（金蝶核对量、差异、复算）。用户看恒茂的导出后指出：「不对，除了量，还有价的核对」。
恒茂入库处置费在页面上本来就核价（吨重 × 19.4 元/吨），导出里却只有量的公式，价那一半没有。

## 改法

复核明细的「复核数据」一组里加五列，每张单一行：

| 列 | 内容 |
|---|---|
| 核价依据 | 这张单的价是按什么核的（见下），核不了的写明为什么 |
| 核价对象（账单金额） | 指到原账单页里被核的那一格（几行账单的是几格相加） |
| 标准金额 | 公式，逐行 `ROUND(量 × 价, 2)` 相加，量和价都指到原账单页的格子 |
| ★价差（账单−标准） | 公式 |
| ★价的复算 | 公式：价差在允许范围内「一致」，否则「核价不符」 |

原来的「★公式复算」改名「★量的复算」。

核价依据按「有什么用什么」：
1. **取数说明里定了算法的**：恒茂入库 吨重×19.4 元/吨、天鹰 吨数×18.5 元/吨。这是合同口径。
2. **包天包趟按报价**：数量 × 报价里这种车型每天/每趟的价（极鲜达短驳）。加班费报价里没列价的，结论写「运费和报价一致；加班 ×× 报价未列价，需确认」，不让公式盖过去。
3. **都没有的，按账单自己写的 单价 × 计费量**（极鲜达零担 计重×单价＝运费、山姆 结算重量×单价＝干线）。
   依据里写明「合同价系统里没有，只核账单算得对不对」——这只能说明账单自己没算错，单价本身对不对系统核不了。
4. 账单这一行没写单价（起步价、一口价）、系统里也没有合同价的：写明核不了，不写公式。

和量的公式一样的规矩：公式写之前先在系统这边按原账单格子里的数算一遍，和系统原有的核价结论对得上才写公式。

## 验证（线上只读，新旧各导一份；价的公式我把它指到的格子取出来算过）

| 承运商（8 月） | 旧表原有格子 | 价的核对 |
|---|---|---|
| 恒茂 | 0 处对不上 | 40 张按「吨重×19.4」，全部一致；1 张（出库装卸）账单没写单价，核不了 |
| 极鲜达 | 0 处对不上 | 24 张按报价（21 张一致，3 张加班未列价）；74 张按账单 单价×计费量，全部一致；28 张没写单价（起步价/一口价）核不了；1 张原账单页里没找到行 |
| 链盟 | 0 处对不上 | 66 张账单都没有单价列，核不了 |

导出用时：恒茂 27 秒、极鲜达 18 秒、链盟 17 秒，和加之前差不多。

## 没覆盖的

- **恒茂冷藏费**（313 行、34,326.36 元，天数×计费数量×冷藏单价）没有金蝶单号，不在复核明细里，这次的价格公式没管到它。
- **迅鸽**的价格卡核价（快递费按价格卡）没有做成公式，也没跑对比。
- 极鲜达零担、链盟这类没有合同价资料的，系统核不了单价本身。
