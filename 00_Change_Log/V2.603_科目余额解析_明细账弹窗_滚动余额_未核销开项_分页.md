# V2.603 科目余额解析（物流）：点开供应商 → 明细账弹窗（滚动余额 + 未核销开项 + 分页 + 追溯）

按用户定的方向重做下钻：不是平铺凭证 + 标最大金额，而是「点开供应商 → 看它的明细账，一眼看出期末余额是哪几笔构成」。

- 内核 `_annotate_ledger`：明细账逐笔加【滚动余额】(期初+累计借−累计贷、末行=期末)；再 FIFO 把核销与计提配对，标出【未核销开项】(它们的和=期末余额、就是这笔余额的构成)。`build_voucher_lines` 加 opening 参、按日期/凭证号排序、返回 余额末/期初开项；下钻/追溯各期都传该期期初。
- 前端下钻改**弹窗**：点维度行弹出该(科目,供应商)明细账——列含【余额】列、**未核销行标绿+「未核销」标**、顶部横幅说明"标绿的和=期末构成"、**分页**(每页15笔)、底部「追溯期初」逐期往前翻。原行内展开与"标最大金额/看全部凭证"改法退役。
- 顺丰样例实点验证：核销后余额0.00、计提行标未核销且余额=期末67.99。

验证：前端构建通过；py_compile/EOL 均过；样例弹窗+余额列+未核销+追溯正常。⚠真机：顺丰多笔时分页；开项那几笔和应=期末（费用类不核销则全为开项，属正常）。
