# V2.574 店铺对照加「别名 / 公盘文件夹名」列（认对店、防起错名的根）

## 别名列（EcomBasicData.jsx / routers/ec.py）
- 「基础资料 › 店铺对照」新增一列**「别名 / 公盘文件夹名」**：把一家店除系统ID/旺店通名/金蝶名之外的其它写法——显示名、公盘文件夹名、宝贝明细里的店铺名——都登在一处（多个用 、或逗号分隔）。
- 存进已有设置 `ec_document_shop_aliases`（`GET/POST /api/ec/basicdata` 增读写；仅接受在 shop_map 内的店铺、每店最多 20 个别名）。文件解析本就用它核对文件里的店铺名（`ec_documents.py`）——填全后，**文件的店铺名和这家店对不上就拒收报警**，即使文件夹/文件名起错也抓得出。

## 用法
- 一次性把每家店的公盘文件夹名、显示名填进「别名」列（如天猫填「星期零天猫店、星期零天猫旗舰店」）。
- 新店用「＋ 新增」建（金蝶客户名/旺店通名/平台），再补别名。
