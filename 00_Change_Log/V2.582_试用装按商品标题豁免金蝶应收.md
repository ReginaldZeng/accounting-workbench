# V2.582 试用装（试用/U先）按商品标题豁免金蝶应收，不再落待人工

## 现象
- 一批 0.01 元单（订单额 29.90 / 实付 0.01 / 已发货 / 交易成功）卡在「待人工介入 · 业务分类待确认」，金蝶应收列显「待同步」。
- 实为试用/0元活动单，金蝶本就不开应收，却因分类落在 `review`（试用待确认）→ 既待人工又待同步。

## 处置（kernels/ec_workbench.py + EcomWorkbench.jsx）
- **按商品标题识别、不按金额**：`title_kind` 认标题里的「U先 / 试用」→ `review`。把 `review` 与 `ufirst` 同一待遇——新增 `ar_exempt = typ in ('ufirst','review')`：
  - 不再追加「业务分类待确认」→ **不落待人工**；
  - `should_ar` 本就仅 `normal` 为真 → 不进「应收待同步」指标；
  - 前端「应确认收入」「金蝶应收」两列显 **「不适用」**（原来只认 ufirst，改认 `ar_exempt`）。
- `review` 标签由「待确认分类」改「试用装」；`pending_ship` 也随 `ar_exempt` 豁免（试用不催发货）。

## 口径 / 影响
- **纯标题判定**，故「先用后付」（真实销售、标题正常 → `normal`）不受影响，仍正常核对金蝶应收。
- 识别词目前为标题含「U先 / 试用」。如试吃/0元试/尝鲜等还有别的叫法，扩 `title_kind` 的关键词即可。
- ⚠ 生效需重建结果：部署后在收入确认点一次金蝶「只读同步」（bump input_version → 重建）即按新逻辑重算。
