# V2.488 · 核算工作台首页（轻量落地页，参照 BP 工作台）

**日期**：2026-09-06　**分支**：claude/accounting-workbench-logs-homepage

Reginald：核算工作台参照 BP 工作台做一个首页——一进工作台先落首页，别直接落在会取数的重页上。

## 背景

进核算工作台此前直接落「对账程序」（或该账号第一个有权限的模块），一进来就并行扇出一堆业务请求。
BP 工作台早已改成「进门先落首页、点板块才取数」。核算侧照此补一个同样定位的落地页。

## 改法（纯前端）

1. **新增 `views/Home.jsx`**：
   - 问候（按时段：早上好/下午好/晚上好…）＋当前登录人；右上角挂三枚状态胶囊：当前期间、本期已封存/未封存、数据源（金蝶/样例）。
   - 板块卡片按侧栏同一份 `navDef+mods` 渲染、按一级板块分组；**刻意不发任何业务请求**——数据全来自
     App 早已拉好的内存态（`cfg`/`navDef`/`mods`），点开具体卡片才真正进模块取数。
   - 卡片三态与侧栏完全同口径：① 可用＝可点；② 未上线＝灰显+状态字（模块开关没开）；
     ③ 🔒无权限＝灰显+锁（模块开着但这个账号没准入点）。全部展示、不过滤——让人知道有这么个板块可去申请。
2. **`App.jsx`**：初始 `view` 改 `home`；进核算工作台（Portal onEnter / 返回门户 / 退出）统一落 `home`；
   落地页重定向逻辑对 `home` 放行（首页恒可进、不设准入点）；新增 `view === 'home'` 渲染 `<Home/>`。
3. **`components/Sidebar.jsx`**：展开态与收起态都在最上钉一个「首页」入口（新增 home 图标），选中高亮。

## 校验

- 前端 build 通过；纯前端改动，未动任何后端接口。
- 三态渲染、分组、点击进模块、返回首页、深链（`#/<key>`）仍直达对应模块——本地验证通过。
