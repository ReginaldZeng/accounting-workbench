# V2.984 发票管家：下载原件统一命名＋批量打包下载

- 日期：2026-10-14
- 作者：Claude Opus 5.5
- 起因：用户：「我们是不是还缺下载原件命名和批量下载原件命名文件夹，下载地址这些」。原来只有看图器里一个「下载原件」，文件名是上传 / 钉钉附件的原名，没有批量。用户定命名「开票日期 2026年9月1日-深圳星期零-销售方-￥金额」，压缩包文件夹「主体 / 开票月份」。

## 改了什么

1. **单张下载原件统一命名**：`2026年9月10日-深圳星期九-徐州市云龙区粤彭大酒店-￥249.00.pdf`（开票日期-主体简称-销售方-￥价税合计）。没有销方的（铁路客票、行程单、出租车票等）写票种；读不到的写「无开票日期 / 未识别主体 / ￥无金额」。看图器里的「下载原件」对发票 / 收据走这个名字；别的附件、手机端照旧原名。
2. **一份 PDF 里装了几张票**（比如 16 页扫描件一页一张）：单张下载只给这张票那一页，不再把整份几十页都下下来。只有一张票的多页 PDF 照旧给整份。
3. **批量下载原件**：发票台账筛选条上「下载原件」——按当前条件，或勾了几张就只下这几张（按钮写「下载原件（勾选的 N 张）」）；打成压缩包「发票原件-导出人-日期-N张.zip」，里面按 **主体简称 / 开票月份 /** 分文件夹，文件名同上，同名的加 -2、-3；附「清单.xlsx」：每张票打进了哪个文件，没打进的写原因（只有二维码没原件、超上限）。一次最多 500 张、300MB，超了清单里写明，请缩小条件分几次下。作废的票不打包。权限同导出 Excel（能进发票台账就能下）。
4. **下载到哪**：网页不能替人选电脑上的文件夹，浏览器默认存「下载」目录；要每次自己选位置，在浏览器设置里打开「下载前询问每个文件的保存位置」。
