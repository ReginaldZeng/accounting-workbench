# V2.308 · 损益归集改按【核算维度·费用项目】分类，不再靠摘要

**日期**：2026-08-18　**作者**：Claude / c　**线**：main（存货台账）

上一版（V2.307）我为了把星期零那两笔从货损里摘出去，往摘要判据上加了个关键词黑名单。
业务方一句：**「不应该按照摘要吧，肯定有核算维度」**——对，而且找到了。

## 核算维度在哪

凭证分录 `GL_VOUCHER` 上挂着核算维度组合 `FDETAILID`，其中：

| | 字段 | 实测取值 |
|---|---|---|
| **费用项目** | `FDETAILID.FFLEX9.FName` | 产品货损／包材货损／原辅料货损／产品盘盈亏／原辅料盘盈亏／包材盘盈亏／处置固定资产净损益／产品领用福利／捐赠／快递费／项目认证服务费… |
| 部门 | `FDETAILID.FFLEX5.FName` | 永续风控中心／永续质量中心… |

⚠**这个字段不好找**：`FFLEX1/2/3` 报"字段不存在"，`FFLEX6/7/11/12` 存在但恒为 0，
只有 **FFLEX5 与 FFLEX9 真有值**——扫 1..30 才扫出来。别再从 1 开始猜。

顺带另一条也通了：其他出库单 `STK_MisDelivery` 的自定义字段 `F_ora_Assistant` 是辅助资料 id，
解出来正是「**报废出库／捐赠／福利领用**」（经 `BOS_ASSISTANTDATA_DETAIL` 反查）。
本次没用它——**费用项目是会计侧的口径，离"这笔钱算什么"更近**，而出库用途是仓储侧的。

## 改法

分类维度从「摘要里的性质词」换成「费用项目」：

- 含「货损」或「盘盈亏」→ **货损**
- 含「处置」→ **资产处置**
- 其余（产品领用福利／捐赠／…）→ **其他存货出库**
- **没挂费用项目的**才退回摘要黑名单兜底（老凭证可能没维度）

损益归集页第①块的分类也随之从「凭证单据类型」改成「**费用项目**」——
这正是成本会计底稿《货损明细-管理费》按「类别」分的那套口径，比
「报废出库无包材的其他出库单」这种拼出来的串清楚得多。

## 教训

V2.307 我发现摘要判据误伤后，第一反应是"给判据打补丁"（加黑名单），
而不是问"有没有更结构化的来源"。业务方问了那一句，才把维度挖出来。
**打补丁能让当前这组数对上，但判据本身还是猜的**——下次换个主体、换个措辞，一样会错。
