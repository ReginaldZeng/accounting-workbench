# V2.755 付款做账列表：费用类型带产品分类，审核结果和建议动作分成两列

用户：「费用类型是否要加编码或者产品项目之类的，以及审核结果是不是要分两部分，审核结果和建议动作？」

- **费用类型**：每张计提后面带产品分类，例如「出库运费 · 植物肉」「出库运费 · 小料」，原来三行都只写「出库运费」分不出来。费用项目编码每行都一样、又很长，只留在预览弹窗里。
- **审核结果**（比对出来的事实，逐张计提一行）：一致 / 一致 · 尾差 0.01 / 税率不符 / 有计提更正。
- **建议动作**（要做什么，逐张一行）：核销 / 核销 + 尾差 / 红冲 + 更正。
- 计提记错主体、金额不符这类整张单的问题，审核结果写一句话，建议动作写「原主体红冲、本主体补提后再做」或「人工核对差额」。
- 去掉审核结果格子下面挂的整单标签：它让那一列比别列高一截，和左边的计提凭证对不齐。顶上的「做账类型」筛选保留。
- 后端：`/plans` 每张计提多返回产品分类、尾差。
