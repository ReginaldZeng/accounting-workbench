# V2.884 钉钉免登：从钉钉工作台点开「星衡智策」直接认人登录

- 日期：2026-10-09
- 作者：Claude Opus 5.5
- 模块：门户 › 登录 / 账号管理

## 起因

用户已把工作台挂进钉钉工作台（应用名「星衡智策」，首页 `http://111.229.72.116`，和服务器 `conf.ini [dingtalk]` 配的是同一个应用），
问「怎么做免登识别账号」。用户定的原则：**进系统先得是企业员工（钉钉说了算），再看有没有权限（工作台说了算）**，账号以钉钉身份为准；
账号和钉钉上的人怎么对，由用户（主管理员）自己配。

## 做法

从钉钉点开 → 钉钉给一个免登码 → 后台向钉钉换出这个人的 userid → 找到记了这个 userid 的账号 → 发登录会话（和密码登录是同一种会话），不出登录页。

userid 怎么记到账号上，两条路：

1. **主管理员指定**：账号管理里每个账号多一行「钉钉免登」，点「直接指定」搜钉钉姓名选人；认错了点「解除」。
2. **本人认**（过渡用）：还没对上的人从钉钉点开，登录页提示「钉钉认出你是某某」，输一次账号密码登录成功就记上，下次直接进。

不做的两件事和原因：

- **不按姓名自动对**：账号名是手工建的，重名、改名都会认错人；认错一次就是拿别人的权限进系统。
- **不认发票管家设置里那份钉钉名单**：那份名单有「发票管家设置」权限就能改，拿它当登录凭据等于谁能改名单谁就能登任何人的账号。

规矩：

- 一个钉钉身份只对一个账号；账号已经认了人，别人顶不掉，要先解除。
- 禁用的账号从钉钉点开也进不去；新账号首登强制改密的闸照旧。
- 在钉钉里点了退出，这次打开期间不再自动进（否则换不了账号）。
- 指定、解除、本人认上、免登登录都留痕（日志中心可查）。钉钉姓名和账号名不一样时账号管理页标红提醒。
- 免登码换身份按 IP 限流（10 分钟 30 次）；「认人凭条」只存内存、10 分钟有效、用一次作废。

## 改动

- `backend/routers/dd_login.py`（新）：`GET /api/dd/hello`、`POST /api/login/dd`、`bind_after_login`。
- `backend/db.py`：`users` 加 `dt_userid`、`dt_name` 两列（老库启动时自动补）；`user_by_dt` / `bind_user_dt` / `unbind_user_dt`；账号列表带「认没认过＋钉钉姓名」（不外露 userid）。
- `backend/app.py`：`/api/login` 接「认人凭条」；`POST /api/users/dd-bind`（仅主管理员，钉钉姓名以通讯录查到的为准）、`POST /api/users/dd-unbind`；挂路由。
- `backend/core.py`：登录门白名单加上面两个登录前接口。`backend/ops.py`：埋点归类。
- `frontend/src/views/ddLogin.js`（新）、`App.jsx`（开页没登录且在钉钉里 → 先让钉钉认人）、`Login.jsx`（提示＋带凭条登录）、
  `Portal.jsx`（退出记一笔）、`UserAdmin.jsx`（「钉钉免登」一行：状态、指定、解除）、`api.js`。

## 验证

- 本地临时库＋假钉钉跑后台全流程 32 项全过：没认过不放行、密码错不认、输对才认上、凭条用一次作废、认过直接进、
  一人一号、主管理员指定/解除、通讯录里没有的人不认、普通账号不能指定、禁用进不去、限流。
- 本地在页面里造假钉钉环境走前端：没认过出提示并填好用户名、输密码后认上、再点开不出登录页直接进、钉钉认不出时照常能用密码登录、退出后不再自动进。
- 线上前提已核对：服务器配的钉钉应用就是「星衡智策」，企业编号线上已记着，上线不用另配。
- **没验的**：真钉钉（电脑版/手机版）里点开——本地模拟不了，上线后由用户点一下验。

## 上线注意

- 改了后端，自动部署会重启一次后端；账号表自动加两列，不动现有数据。
- 给新建账号「直接指定」后，对方首登仍要改密码（改密页要输初始密码），初始密码还得告诉本人——下一版改成「从钉钉选人建账号」时一并理顺。
