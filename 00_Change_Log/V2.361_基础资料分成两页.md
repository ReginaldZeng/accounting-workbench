# V2.361 · 基础资料页分成两页（照月结核对那条步骤条）

**日期**：2026-08-24　**作者**：Claude / c　**线**：main（存货台账）

业务方：「基础资料参考一下月结核对，分页」。

## 先澄清一件事：仓库表**早就分页了**

业务方截图里那张 143 行的仓库表一路铺到底，看着像没分页——其实 V2.296 就做了
（50 条/页），只是**分页条在截图看不见的下面**。所以要的不是表格分页，
而是**把整页那三大块拆开**：原来 ①类别↔科目 / ②仓库类型 / ③仓库对照 是一路往下滚的。

## 两页，不是三页

照「月结核对」同款步骤条（复用 `.steps/.step` 样式，同一个工具里两页的导航手感该一致）：

```
① 类别 → 科目对照      账实勾稽按此归集
② 仓库类型与对照        仓库透视按此分组 · 143 个仓库
```

⚠**②和③必须同页**：原来的「②仓库类型」是「③仓库对照」那张表的**筛选器**——
chip 上写着"点一下即筛出下方该类型的仓库"，拆到两页就断了。
正好也是本页副标题本来的分法：「类别→科目对照」｜「仓库类型与对照」。

## 一个实现上的坑

③ 那一区**不是单张卡片**：卡片下面还并排着 chips、表格、分页条。
第一次照"包住这张卡片"改，`</div>` 收在了卡片上，构建直接报
`Expected "}" but found "className"`。改成用片段 `<>…</>` 把整区包起来才对。
