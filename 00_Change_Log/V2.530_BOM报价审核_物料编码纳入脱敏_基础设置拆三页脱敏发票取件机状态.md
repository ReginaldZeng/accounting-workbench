# V2.530 · 物料编码纳入脱敏可选列；基础设置拆三页（脱敏设置 / 发票设置 / 取件机状态）

**日期**：2026-09-08　**业务方定**：「编码好像也属于敏感数据」「这里要做成三页：脱敏设置、发票设置、取件机状态」。

## 改

- **物料编码脱敏**：`_CFG_DEFAULT` / `_MASK_LABELS` 加 `hideMatCode`；`_masked_rec` 开启后把料行 `matCode` 置空（脱敏版重排版、BP 消费口、两版 zip 一并生效；核算侧全量不动）。默认关（延续现状），成本会计在基础设置里勾。基础设置脱敏页加「物料编码」一项。
- **基础设置拆三页**：`BomConfig` 顶部加 `Seg` 页签 —— ①脱敏设置（原公开版脱敏，含新物料编码项）②发票设置（原发票类型算法）③取件机状态（新增，读 `/api/bom/outbox/status`：服务器落盘目录、待取文件数、落盘失败清单 + 刷新；说明取件机每分钟同步到公盘）。单条记录的落盘/重落仍在该记录详情页。

## 实测（沙盒）

`_masked_rec` 开 hideMatCode → 料行 matCode 全空、遮列清单含「物料编码」；默认设置带该键。前端构建通过，三页页签在。
