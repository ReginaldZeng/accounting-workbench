# V2.616 发票管家：手机配对码打不开——改用电脑上正在用的地址（正式域名未备案被腾讯云拦截）

接 V2.615。真机：电脑上点「手机当相机」出的配对码，手机钉钉扫了打不开。

查因：配对码里写死的是 `https://finance.starfieldsz.com`；这个域名在腾讯云被拦——HTTP 访问 302 到 `dnspod.qcloud.com/static/webblock.html`（网站未备案拦截页），HTTPS 直接断开握手。服务器日志里手机的请求一条都没到。用 IP `111.229.72.116` 访问正常。

## 改法
- 设置里「站点地址」默认改为**留空**＝用电脑上正在用的地址（手机和电脑走同一个入口）；填了就用填的（域名备案＋https 开通后再填）。
- 用 IP 访问时配对码一律给 `http://IP`：证书只签了域名，`https://IP` 在手机上报证书错误打不开。手机页拍照走系统相机（文件选择调相机），http 也能用。
- 钉钉消息里的「点这里查看」链接：没填站点地址时用最近一次有人从外面打开工作台的地址。
- 文案：去掉"手机拍照需要 https"的误导提示；电脑高拍仪面板改说清楚——高拍仪预览要 https，正式域名开通前先用「手机当相机」或「拖文件」。设置页站点地址允许 http、说明留空的含义。

## 仍受限
- 电脑上的高拍仪实时预览（浏览器摄像头）只在 https 下可用；正式域名备案并接入腾讯云后填进站点地址即恢复。临时办法：在装高拍仪的那台电脑浏览器里把 `http://111.229.72.116` 设为可信地址。

验证：接口测试 69 个（新增 test_42：IP 访问给 http、带端口保留、域名访问照原样、填了站点地址用填的）、前端回归 21 个通过。
