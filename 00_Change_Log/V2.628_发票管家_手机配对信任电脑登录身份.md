# V2.628 发票管家：手机配对改「信任电脑登录身份」，免登认不出也能配上

用户真机：手机钉钉扫配对码后显示「配不上／要核对手机上的人和电脑上登录的是同一个」，同一个人也配不上。

## 原因
配对码是一个普通网址二维码，用钉钉「扫一扫」打开后，页面是普通网页、不是注册的钉钉微应用，所以钉钉免登（requestAuthCode）调不起来、拿不到身份码。原来「账号绑了钉钉就必须免登认出本人且和电脑一致，否则配不上」的规则，在这种打开方式下基本永远失败。

## 改法（用户定「信任电脑登录身份」）
- 配对是从**已登录的电脑**发起的，登记人本来就＝电脑上登录的人。
- 手机免登认不出身份（拿不到 code / code 无效）→ **照样配得上**，登记人＝电脑登录人，页面标注「没通过钉钉核对身份」。
- 只有钉钉**明确认出是"另一个人"**（和电脑账号绑的钉钉不一致）才拦——防在别人电脑上用自己手机配对。
- 页面/提示语相应改缓和（去掉误导的「建议用钉钉扫一扫打开」，因为扫链接本就调不起免登）。

## 说明
要让手机端真正按钉钉本人身份登记，需要把发票页在钉钉后台注册成微应用首页并开免登权限；在那之前，按电脑登录身份登记，功能可正常用。

验证：接口 69（test_20 改为免登认不出也配上、只有认出别人才拦；test_10 加绑钉钉账号无 code 也配上）、内核、前端浏览器回归 33 全过。
