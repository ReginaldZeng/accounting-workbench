# V2.558 账户流水查询精简与筛选分桶计数

- 账户流水页聚焦查询，去除业务范围、账户余额总表、登记和导入区；总览保留余额表，数据准备承接账户登记与合并导入。
- 筛选顺序：账户、业务分桶（笔数）、初审判定、开始日期、截止日期、金额搜索、模糊搜索、仅看异常。输入短暂防抖后自动检索，取消隐藏月份限制，日期由可见区间控制。
- 分桶计数保留账户及其他筛选条件，不受当前选中分桶限制；仅改变计数口径，不修改流水分类及财务数据。
- 表格顺序：账户/入账时间、流水号、业务订单号、业务描述/账务类型、收入、支出、余额、分桶、提醒。
- 列表隐藏重复商户单号和交易号，候选订单及补充描述使用淡色小标记；点击流水号或订单号查看全部原始字段和识别依据。
- 验证：34 项隔离后端测试通过；Playwright + Edge 模拟接口验证入口迁移、筛选、详情、人工定性、后台导入、桌面及手机宽度。Browser plugin not available。
