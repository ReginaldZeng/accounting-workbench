# V2.473 · 上报表/打卡表已上传就盖「已上传」戳、可替换，不必每次重传；切期间跳回①数据接入

**日期**：2026-09-06　**分支**：main

Reginald：①「每次都要上传人力上报汇总表吗？能不能自动落库……做成两个框，已上传的盖已上传戳，可以替换，做替换按钮」；
②「选中期间后，默认跳回①数据接入」。

## 改法

**1. 原表复用（本就落盘留档，现在 UI 认它）：**
- 第①步两个框：本期已有留档原表（还在留存期＝可重跑）时，盖**「✓ 已上传（本期留档）」**戳＋文件名＋留档时间，
  旁边一个**「替换」**按钮；不点替换就不用再传。点替换才露出选文件框，另给「取消替换，用回已上传的」。
- `开始核对`：每张表「本次选了的用本次的，没选就用本期留档原表」；两张都没有才拦。
- 后端 `/api/tempatt/review`：没重新上传的那张，用 `_period_files(month)` 的留档原表补上
  （上报表通常不变，不必每次重传）。`form()` 只发本次真选的文件；`从钉钉取打卡`照旧直接生成新打卡表。

**2. 右上角切期间 → 默认跳回第①步「数据接入」：**
- `pickMonth`/`openPeriod` 加目标步参数，切期间（无论该期核过没核过）都落到 `import` 步，
  从那看已上传/替换再决定往下走；切期时替换态归零。
