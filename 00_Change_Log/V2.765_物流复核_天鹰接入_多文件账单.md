# V2.765 物流复核：天鹰接入（一张请款单多个账单文件）

日期：2026-10-03

## 背景
天鹰是孝感工厂装卸费（吨×18.5 元，含 6% 税），一张请款单带 2～3 个文件、每个文件一类（蜜雪装货 / 小料·植物肉卸货 / 分步调拨卸货 / 成品装货）。
复核台原规则「同一家同一月新账单替换旧账单」，第二个文件会把第一个冲掉。

## 改动
- `kernels/logistics_intake.py`
  - `src_from_sheets`：份名取「取到数的表名」（去掉「(2)」副本号），几个文件各算一份、互不覆盖。
  - `amount_dp`：金额留几位小数（默认 2）。天鹰逐行是吨×18.5 的长小数，供应商只在合计处取整，逐行先取整合计会差几分。
  - `_merge_doc` 合并金额不再取整到分（只去浮点噪声）；核价差「超 1 分」先取整再比（免浮点噪声误报 0.01）。
- `routers/logistics_payreq.py`：取数说明带 `multi_file` 的，请款单里每个账单文件都导（`_import_multi`）；复核台已有同名那份的不覆盖，force 才换。
- 取数说明(库)：天鹰物流 7 类表（小料装货/植物肉装货/蜜雪装货/植物肉卸货/小料卸货/分步调拨卸货/退货），主体与标注按表固定（账单没有 类型/主体 列），
  单号向下沿用并单、吨×1000 比金蝶 kg、按 吨×18.5 核价；合计行按「产品名称」过滤（物料编码有 T 开头临时码和漏填）。

## 验证(8 月)
- 深圳星期零：小料装货 11,943.97 + 植物肉装货 493.21 = 12,437.18 = 请款。
- 孝感星期九：蜜雪装货 18,222.50 + 植物肉卸货 547.78 + 小料卸货 23,477.40 + 分步调拨 289.95(表单原件) / 286.36(评论里的已核对版)。
  请款 42,533.78：用已核对版合计 42,534.04，差 0.26（尾差，待确认）。
- 回归：其余 8 家解析结果不变。
