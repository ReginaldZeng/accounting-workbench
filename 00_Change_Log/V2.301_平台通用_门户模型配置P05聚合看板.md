## 验证（本机 8000 + BP 8010 实测）

- `GET /api/llm-hub/status`（带会话）：BP `reachable=true, configured=true, keyHint=sk-7***e09a, 76ms`，providers 4 家（deepseek 已配/kimi/glm/dashscope 未配）；`aiReady=true, readyCount=1`。
- `GET /api/llm-hub/usage?days=7`（管理员会话）：代理成功，byUser 4 人（含曾禹锡）、357 次/53.4 万 token、limits 全站硬闸 200 万 token。未登录→401、非管理员→403（前端显示「仅管理员可见」）。
- 浏览器（vite build 后 8000 实测）：首页胶囊绿灯「已接入 1 个工作台 · DEEPSEEK」，点击进模型配置页四个区块全渲染，P1 按钮灰显带角标，trustNote 横幅在。
- 修一处自查出的 bug：「今日已用」原用 `toISOString`（UTC 日期），本地 0–8 点会与 BP 的 `day`（本地日期）差一天 → 改 `toLocaleDateString('sv-SE')`。
- `py_compile` 过；前端 `npm run build` 过（产物已进 `backend/static`）。

## 边界与遗留

1. **key 零接触**：本次代码里不出现任何厂商 key；keyHint 是 BP 侧 `_mask` 打码后的，原样透传。
2. 状态接口登录即可见（只有打码提示与模型名）；用量/额度/豁免仅管理员。
3. BP 侧**零改动**（纯消费其现成接口），BP 台账无需记账。
4. 核算/数字员工接入路径：拷 BP `app/llm*.py` + 各自服务器 .env 配独立厂商账号（P0），本页自动点亮；**P1 网关触发信号**（工作台 ≥4 / 月费用显著 / 需即时吊销的治理事件）未达标前停留在 P0.5。
5. 服务器部署后：BP 的 usage `trustNote`（X-BP-* 伪造头未剥离）依旧成立，看板原样展示该声明，不粉饰。
