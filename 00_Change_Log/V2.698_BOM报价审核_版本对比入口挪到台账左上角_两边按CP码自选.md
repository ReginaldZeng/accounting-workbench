# V2.698 · BOM报价审核：版本对比入口挪到标准成本台账左上角；对比页两边都按 CP 码自选（不限同一产品）

**日期**：2026-09-30　**业务方定**：「版本对比应该是坐在左上角，然后挑选一个对比版本的 CP 码，一个当前版本的 CP 码。」（纠正 V2.696 放在每行操作列的做法）

## 改

- **入口**：标准成本台账标题旁「⇄ 版本对比」按钮（左上角）；撤掉 V2.696 每行「版本对比（N）›」。
- **对比页**：左「对比版本」、右「当前版本」两个搜索选择框（`VerPicker`），输 **CP 码 / 产品名 / 物料编码 / 单号** 搜台账里全部已初审/已审核版本，每项显示 CP · 产品名 · 核算日期 · 状态 · 全成本 · 编码 · 单号尾号。**不再限同一产品**——换码前后的新旧 CP 可直接对比。
  - 选好当前版本后，对比版本若未选则**自动带出上一版**（同产品键最近更早的一版；没有则同物料编码最近一版）；对比版本候选里「同产品 / 同物料编码 / 同名」排最前并打标签。
  - 两条既不同产品也无共用物料编码时，顶部提示「跨 CP 对比…确认选对了」；同物料编码/同名则标出关系。
  - 没选齐时显示引导文字，不出结果；表头改为「对比版 · CP · 日期 / 当前版 · CP · 日期」，信息差异表头同改。
  - 候选池排除历史标准成本导入（无物料明细）。
- **返回**：从台账进→「返回台账」；从详情 / BP 深链 `&compare=1` 进→预选本条为当前版本、上一版为对比版本，「返回采购核算表」。
