# V2.784 单据运费：「其他单据」页签收进账单里的其他出库单/采购入库单/调拨单

日期：2026-10-03

## 背景
销售出库单页签的提示里列了 268 笔迅鸽费用「是其他出库单」。用户：「其它出库单不是应该出现在其它单据类那里吗」。
原状：第三个页签「其他单据（登记制）」只放手工登记的(8 月只有货拉拉 7 张)；账单里的其他出库/采购入库/调拨单据上的运费，只有登记复核后才在第二个页签里看得到。

## 改动
- `routers/logistics_review.py` `doc-freight`(mode=other)：除手工登记的，加进本月账单逐单明细里**不是销售出库/退货**的单据：
  - 判定：本月销售出库单(含退货)里有的 → 不进；单号像销售出库(XSCKD/XQLCK/RK)但本月没有的，去金蝶查：是别的月份的销售出库/退货 → 不进；
    是其他出库单(如迅鸽 XQLCK 开头的媒介领用)或查不到 → 进；其余前缀(QTCK 其他出库/CGRK 采购入库/FBDR·FBDC 调拨…) → 进。
  - 每张单带 来源(账单/登记) 和 是否已复核；费用类型用复核台归口后的；往来列账单来源的显示金蝶上的领用部门/供应商/调拨仓。
  - 只有手工登记的行能删(账单来源的不给删除入口)。
  - 返回 `other_stat`(账单已复核/待复核/手工登记 各几张多少钱)。
- `LogisticsDocFreight.jsx`：页签改名「其他单据」；上方一句话说明构成；单据号下标「账单·已复核 / 账单·待复核 / 手工登记」。
