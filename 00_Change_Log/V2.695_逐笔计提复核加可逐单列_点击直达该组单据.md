# V2.695 逐笔计提复核加「可逐单」列，点击直达该组单据

日期：2026-09-30

## 起因
用户在逐笔计提复核页提出：能不能加一项「是否可以逐单核对」。有的计提（仓储费、托盘扣款、月结汇总）账单上没有金蝶单号，只能看汇总差异；有的能一单一单核。以前要切到第②步才知道。

## 改动
- 后端 `_build_lines`：按 主体×费用类型×产品线 统计带金蝶单号(非空、非「无单据」)的逐单明细（去重单号数 + 金额）；
  每个账单锚点行(按产品线 / 按组)挂 `od = {n, amt, ratio, fsub, ffee, fbiz, blabel}`，ratio=带单号金额÷该笔账单金额(截在0~1)；
  返回 `od_total`（整家账单里可逐单的占比）。按组的锚点取该组没配上产品线的剩余归口。
- 后端 `/api/logistics-review/result` 加 `fsub/ffee/fbiz` 筛选（fbiz 多个产品线用 | 连，空产品线记 -）；
  口径与逐笔复核同一套(_eff_subject/_eff_fee/_bill_biz)；小承运商单据视图缓存仍按整家建，筛在缓存之后；计数跟着筛后结果。
- 前端逐笔表在「差异」后加「可逐单」列：
  - ✓ N 单（绿，全覆盖）/ 部分 xx% · N 单（橙）→ 点一下跳第②步只看这一组；
  - 否 · 汇总核（灰）＝没有单号撑着，只能在本页看差异写解释；N 单 · 只核量＝有单号但逐单没金额(钱在汇总行)，如迅鸽退货；没有账单的行显示 —。
- 第②步顶部显示「只看：主体 · 费用类型 · 产品线」，可「✕ 看全部单据」或「‹ 回逐笔计提复核」。
- 账单合计格与合计行显示整家可逐单占比；口径说明补一句。
