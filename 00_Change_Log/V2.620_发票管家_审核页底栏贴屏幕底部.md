# V2.620 发票管家：审核页底栏真正贴在屏幕底部（内容少时也贴底），左边队列「共 N 个」同样贴底

接 V2.619。用户真机：单子票少时，底部「提交」栏跟在内容后面、停在屏幕中间；左边队列的「共 1 个」也浮在中间。

改法（只改样式 inv-audit.css）：审核页左右两栏都撑满屏幕高度（100vh − 页头与留白 122px）；左栏队列固定高度，「共 N 个」自然落到底部；右栏底栏 margin-top:auto＋sticky bottom:0——内容少时贴着屏幕底部，内容多往下滚时仍固定在底部可见。窄屏（≤900px）照旧自然高度。

验证：本机 2000×1053、1440×900 两种屏幕实测，底栏离屏幕底边 30px（页面留白）、整页无多余滚动条；前端回归 28 条全过。

发布：只改前端样式，自动部署不重启后端。回退＝反向提交本提交。
