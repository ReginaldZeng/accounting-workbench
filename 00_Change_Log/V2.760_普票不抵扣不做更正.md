# V2.760 付款做账：普票不能抵扣，按 0 税率核对、不做更正

日期：2026-10-02

## 背景
样张里孝感恒茂(普票 1%，原计提 0% 全额进费用)被判成「改税率 0%→1%」、要把 779.54 转待认证。用户确认：普票不能抵扣，不做更正。

## 规则
- 能抵扣 = 发票管家 inv_type 为 special(专票)、travel(旅客运输)；normal(普票)、taxi(出租车) 等不能抵扣。
- 不能抵扣的票按 0 税率、0 税额参与「按税率核对」：计提本就 0% 全额进费用的 → 一致·只核销；计提错分了税的 → 红冲后按 0% 更正(不出 0 金额税行)。
- 不能抵扣的票不出 2221.01.06 待认证行；号码写进支付摘要「（普票号码）」，发票管家按摘要里的号码认「已做账」。
- 预览发票表、计提更正单发票行标「不抵扣」；结论下方提示哪几张不能抵扣。

## 改动
- kernels/logistics_voucher.py：build 跳过 deduct=False 的待认证行；支付摘要追加普票号码；更正税额为 0 不出税行。
- kernels/test_logistics_voucher.py：加普票用例(0% 计提只核销 / 1% 计提红冲更正到 0%)，7 例全过。
- routers/logistics_voucher.py：_invoices 返 deduct；inv_in 对不能抵扣的票传 rate 0 / tax 0 / deduct False；加提示。
- LogisticsVoucher.jsx：按税率核对把不抵扣票算 0%；发票表与打印单标「不抵扣」。
