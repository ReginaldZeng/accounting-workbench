# V2.387 · 临时工考勤 ·「夏菊红」和「夏菊红（离职）」是同一个人

**日期**：2026-08-29　**分支**：main

Reginald 筛「夏菊红」，出来 **12 行**——4、6、7、8、9、11 日各两条，打卡一模一样：

```
夏菊红        小料   4日 07:50→20:40  上报 0     ◇有打卡·未计工时
夏菊红（离职） 植物肉  4日 07:50→20:40  上报 10.5  ✓打卡撑得住上报
```

## 原因：去重的键用错了

汇总表把这个人拆成两行（小料 + 植物肉），而人力**只在其中一行的名字后面加了「（离职）」**。
我判「是不是同一个人」用的是**原始姓名**，两个名字不一样就没并上，同一批卡摆了两遍。

为什么当初用原始姓名：`norm_name` 会把「张博G / 张博J」「黄亚军0415 / 黄亚军7327」
的后缀一起抹掉——那是**两个人**，公司就是用这种后缀区分同名者，并错了更严重。

## 改法：只去括号，保留字母数字后缀

```
夏菊红 / 夏菊红（离职）        → 夏菊红 / 夏菊红      同一个人 ✓
张博G / 张博J                 → 张博G / 张博J        不同的人 ✓
黄亚军0415 / 黄亚军7327        → 各自保留            不同的人 ✓
```

新增 `same_person_key()`，用在三处：「这天在任何一行上有没有工时」「同一天只摆一条空行」
「跨行的打卡归属」。两头的风险都在函数注释里写明了。
