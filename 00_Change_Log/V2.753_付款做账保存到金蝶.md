## 改动
- `POST /api/logistics-voucher/post`，前提条件：
  - 做账类型 ok；
  - 状态为可做账（已付款、发票齐、纸质件已到或已手动放行）；
  - 有金蝶付款单，且供应商、金额都和请款单对得上。
- 流程：
  1. 付款单 暂存 → 保存 → 提交 → 审核。已经被人审核过的不动，转人工。
  2. 30 秒内按「同账簿 + 付款日 + 贷 1002 = 付款金额 + 审核后生成 + 未审核」找到自动凭证，而且必须恰好是两行。
  3. 有了凭证号，核销摘要里的 □ 直接填上。
  4. 补红冲 / 更正 / 核销分录（2241 行带供应商分组 FF100005），支付两行改摘要。
- 写入成功后记入 settings `logi_voucher_posted`，并把请款单付款状态改成 C、留审计。
- 同一张单加锁、已写过的拒绝，不会重复写。
- 凭证不审核，留给人在金蝶核对后审核。
- 页面：
  - 凭证预览旁边加「保存到金蝶」按钮，点之前二次确认，写的过程中显示进度；
  - 写完弹窗顶部显示「已写入金蝶 · 记-N · 借 = 贷」；
  - 列表上这张单显示「已做账 · 已写金蝶 记-N」。
