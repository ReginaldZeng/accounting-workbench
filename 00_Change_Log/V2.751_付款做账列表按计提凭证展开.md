# V2.751 付款做账列表改版：按计提凭证逐张展开

用户：「这里应该是主体、物流商、费用类型、金额、税率、凭证号、审核结果、付款金额、付款单状态」；「物流商应该是全称，主体可以是简称，但都需要带上编码」。

- 列表列改为：主体（账簿编码 + 简称）｜物流商（金蝶供应商编码 + 全称）｜费用类型｜计提金额｜税率｜计提凭证｜审核结果｜付款金额｜付款单状态。
- 一张请款单对应的几张计提凭证，在费用类型、金额、税率、凭证号、审核结果几列里逐张上下对齐：
  - 审核结果每张写「核销」或「红冲更正」；
  - 税率开错的写成「6% → 9%」；
  - 下面再挂整张单的做账类型。
- 付款单状态显示规则：
  - 金蝶付款单显示单据状态（暂存 / 创建 / 审核中 / 已审核 / 重新审核）和付款日；
  - 已经记过支付凭证的显示凭证号；
  - 还没付款的显示「钉钉审批中」或「已通过 · 待付款」。
- 纸质件、发票张数和合计，放在对应格子下面的小字。
- 后端：`/plans` 多返回每张计提的费用项目、金额、税率、处理方式；`/list` 多返回账簿编码、金蝶供应商全称、付款单状态、钉钉状态。
