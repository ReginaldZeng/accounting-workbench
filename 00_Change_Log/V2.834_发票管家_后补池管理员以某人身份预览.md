# V2.834 发票管家：后补池「以某人身份预览」（管理员核对审批模板配得对不对）

管理员问："发票后补登记里，别人能选中哪些钉钉单据，我作为管理员怎么看？"

- 后补池页头（要发票管家设置权限）新增「以某人身份预览」：输入钉钉姓名 → 拉出这个人当前能选到的后补可登记审批单，**和他本人在"发票后补登记"里看到的完全一样**。
- 用途：核对审批模板配得对不对（只有勾了「可登记后补」且模板名与钉钉一字不差的，本人才选得到）、看谁手上有可登记的单。
- 每行标「后补情况」：可登记 / 已登记 #N·状态 / 已附发票；可选近 30/60/120 天；重名先选部门。
- 新接口 `GET /api/inv/s/preview?name=&days=&pick=`（要发票后补池页面＋发票管家设置权限；按本人钉钉身份、只查允许后补的模板）。

验证：接口 30（新增 test_25：权限 403/401、重名选、按本人 userid＋天查、只查允许后补模板、后补情况标注）全过；前端浏览器回归新增「以某人身份预览」一条通过。注：自助登记 3 条回归用例因登录方式已改手机号（另一条线）而待更新，与本功能无关，已另派任务。
