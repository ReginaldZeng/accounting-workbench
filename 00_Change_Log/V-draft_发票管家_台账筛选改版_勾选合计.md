# V-draft 发票管家：发票台账筛选改版＋勾选几张看合计（未上线）

- 日期：2026-10-14
- 作者：Claude Opus 5.5
- 起因：用户截图（发票台账·台账查询的筛选条）：「这里字段改为，主体，开票月份，做账月份，票种，抵扣，做账，销方，审核人。还有是不是可以做一个勾选上面当前条件那一行绿色显示多少价税合计，税额多少，可抵扣多少？」

## 改了什么

1. **筛选条顺序**：主体｜开票月份｜做账月份｜票种｜抵扣｜做账｜销方｜审核人｜搜索（发票号码 / 审批单号 / 申请人）。其余（开票日期起止、验真、票总管、纸质票、含作废）收进 **「更多条件」**，点开才显示；有条件在用时按钮写「更多条件（有在用的）」并自动展开。搜索框我留在第一排（找某一张票离不开它）。
2. **新条件「做账月份」**：系统在金蝶对上的凭证在这个月（一张票挂了几个月的凭证，哪个月都算）。
3. **新条件「审核人」**：谁审核通过的，下拉列台账里出现过的审核人。
4. **当前条件那一行多一项「可抵扣税额」**：会计判了可抵扣的票的税额合计（铁路客票票面没有税额，不在里面）。
5. **勾选看合计**：表格第一列加勾选框（表头一个勾＝这一页全勾）；勾了几张，「当前条件」那一行变成绿色，只算勾上的——已勾选 N 张｜价税合计｜税额｜可抵扣税额｜清掉勾选；勾上的行也是浅绿。跨页记着，条件一改就清掉；作废的票不能勾；拆分票按本单分摊额算（和合计一个口径）。
6. 导出 Excel 跟着新条件筛。
