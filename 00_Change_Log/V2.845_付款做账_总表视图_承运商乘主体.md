# V2.845 付款做账：照复核台总表整理——承运商一行、三个主体各一组列

日期：2026-10-06

用户贴了物流账单复核台的总表：「做账的页面，也可以按照这个整理下吗」。

付款做账页原来是一张请款单一行、十二列的长表，一家承运商三个主体的请款单散在三行里。改成和复核台总表同一个骨架（纯前端，`LogisticsVoucher.jsx`）：

- **总表（默认）**：一行一家承运商（名称 + 供应商编码），深圳星期零 / 深圳星期九 / 孝感星期九 各一组列：
  - 计提＝这张请款单要核销的金蝶计提合计，下面一行小字是凭证号（一张）或「N 张计提」，鼠标停留看是哪几张；
  - 付款＝请款金额，下面的状态（可做账 / 已做账 记-264 / 票不齐 / 付款单编码不对 / 未付款…）点开就是凭证预览；
  - 做账＝计提和发票比对的结论（✓ 一致 / 尾差·红冲 / 红冲更正 / 记错主体 / 金额不符…），能批量做的带勾选框，表头的勾选框按主体全选。
  - 同一格有几张请款单的（迅鸽同月两张）上下排；账单月和多数不一样的打一个小标（诚煜「6月」）。
  - 右边：这家的做账状态（已做账 n/n、可做账 k 张、或卡在哪）+「凭证预览 / 查看」按钮（打开还没做的第一张）。全部做完的整行淡绿。底部合计行按主体出付款合计和已做账张数。
- **明细**：右上角「总表｜明细」切换，原来一张请款单一行的表原样保留（看每张计提的费用类型、税率、凭证号）。
- 顶栏加「账单月」下拉（有不止一个月时出现）；状态筛选默认从「可做账」改成「全部」；状态 / 做账类型筛选、搜索、批量保存、自动做账、扫码查凭证都照旧，两种视图共用。
- 装订那一条（装订对照清单 / 凭证号贴条 / 本月计提更正单）从表格上面挪到表格下面。

验证：用线上真实数据（28 张请款单、16 张的做账类型）本地渲染看过两种情形——只看已出付款单的、把未付款的也展开（含迅鸽同格两张）。**没有在线上页面里实际点过**（勾选批量、点状态开预览走的是原有逻辑）。

上线：纯前端。
