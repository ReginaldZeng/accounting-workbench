# V2.639 单据运费·两 tab 统一为物料级字段

- Date: 2026-09-28 | Author: Claude Opus 4.8

## 背景
用户看到「单据运费」两个 tab（销售出库 / 其他单据）字段不一致，且其他单据只到「单据」粒度、看不到具体物料。定稿：两 tab 用同一套物料级字段。

## 字段（两 tab 一致）
费用主体｜费用类型｜业务线｜单据号｜客户/需求部门｜物料编码｜物料名称｜基本单位数量｜基本单位｜运费｜单位运费｜费比（如有）

## 口径
- 一行 = 一张单据里的一个物料行。
- 运费按「基本单位数量」在单据内摊到各物料：`摊得运费 = 单据运费 × 该物料基本数量 / 单据基本数量合计`。
- 单位运费 = 摊得运费 / 基本单位数量。
- 费比 = 摊得运费 / 该物料销售额（仅销售出库单有销售额时显示）。
- 业务线从费用标注解析（植物肉/鲜食/山姆零售/零售/小料/豆蛋制品/电商/kikiherb/海外）。
- 金蝶查不到该单据物料时，退化为单据一行（运费照挂，物料留空）。

## 后端
