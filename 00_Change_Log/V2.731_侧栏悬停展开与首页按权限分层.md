# V2.731 侧栏悬停展开 + 首页按权限分层 + 申请开通推钉钉（移植财务BP工作台 V2.549–V2.556）

## 1. 侧栏：悬停展开
- 常态 72px 图标轨。鼠标移入或 Tab 键进入时浮出到 240px，盖在页面上，不推挤右侧内容。宽度过渡 220ms 缓出；文字晚 80ms 淡入，收起时立即淡出。
- 图钉 = 固定展开（记在本机 `fw_nav_pinned`，默认不固定）。固定后占 240px，页面让出位置。原来的「收起/展开」按钮和 264px 展开态去掉。
- 每行左侧固定一个 52px 的图标格，展开前后图标不位移。三级子项在收起态也占位，显示为树线上的小圆点；板块标签收起时换成一道短横线。展开时条目不跳。
- 上下分区：
  - 顶部：logo，角上绿点表示数据源是金蝶；标题；标题下一行「数据源 · 金蝶 V2.xxx」，版本号常驻可见；图钉。点 logo 或标题回首页。
  - 底部：基础数据、系统设置、色调开关，以及账号区。账号区为头像（显示姓名末字）、「姓名 · 岗位」、门户按钮、退出按钮。
- **无权限菜单改为上锁灰显**（原来是隐藏）；状态为「隐藏」的仍然隐藏。
- 触屏：点板块或分组展开，点侧栏外收起。开了「减少动效」时关闭动效。
- 颜色全部用核算的 CSS 变量，深色主题自动适配。动效写在独立的 `src/sidebar.css`。
- 本机清掉了全局 `.brand` / `.acct` / `.foot` 的旧样式串扰（全局 `.acct` 是等宽数字字体）。

## 2. 首页：按权限分层
- 问候区（紧凑）：问候 + 岗位；右侧「已开通页面 x / y」+ 进度条，分母只算已上线的页面。只有开了期间类页面（对账、台账、资金、理财、月结、科目余额、物流）的人才显示「当前期间 / 本期封存」。
- 两个高亮按钮「我有权限的 N / 显示全部 N」，选择记在本机。没记过时：权限没开全 →「我有权限的」；一个都没开 →「显示全部」；全部开通 → 不显示切换，只写「全部 N 个页面已开通」。
- 卡片三色：
  - 绿 = 已开通，可点；
  - 灰紫 + 锁 = 没权限；
  - 未上线不做成卡片，只在组标题旁一行小字。
- 卡片统一两行等高。锁卡上的「申请开通」是标题行右侧的一个小链接。「我有权限的」开得少（≤6 个）时平铺，最近使用的排前并打小标。
- 首页不调用任何业务数据接口；唯一例外是轻量的「我的申请记录」，且只在有没开通的页面时才取。
- V2.500「首页只留真的工具」不变：基础数据、系统设置这类配置页不进首页。

## 3. 申请开通 → 钉钉推送
- 新增 `routers/access_request.py`：
  - 只能申请自己没有的准入点（已有时返回 400「刷新即可」）。
  - 同一人同一准入点 24 小时只推一次（429）。
  - 钉钉单聊推给接收人，消息含：姓名·岗位、页面、权限点、用途、处理指引（门户 › 账号管理）。
- 接收人：系统设置 → 常规设置「权限申请推送」，可搜名字选人。不选 = 默认管理员，即 `conf.ini [dingtalk]` 的 `to_userids` 加上由 `to_mobiles` 换成的 userId（`notifier._all_userids`）。BP 踩过的「只配了手机号 → 接收人为 0」在核算这边天然规避。
- 设置卡显示生效接收人数（为 0 时红字提示）和最近 10 条申请（是否送达）。
- 本机 sqlite 库一律打桩，不真发钉钉。
- `/api/me` 增加返回 `post`（岗位）。
