# V2.309 · 账实对比并进「按类别」表 + 货损明细改回业务方的列序

**日期**：2026-08-18　**作者**：Claude / c　**线**：main（存货台账）

业务方两条：①「最终展示可以做成这个样子吗——A~L 是透视数，M~N 是总账取数，O 列相减对比」；
②「货损的表格抬头最好还是按照我们之前的格式，取数填入。我这边还需要增加产品项目」。

## ① 账实对比并进「收发存汇总·按类别」

原先要在「汇总透视」和「勾稽与归集」两页之间来回跳，才能知道"这几个类别加起来对不对得上总账"。
现在一张表：

```
A–K  收发存透视（SUMIFS 活公式）   L 科目余额（总账取数）   M 差异（相减，非 0 标红）
```

**L/M 按科目纵向合并单元格**——它是科目级的数，逐行重复会让人以为每个类别都有一个余额。

两处不这么做就会错的地方：

- **单列科目放在合计之后**：在途物资/委托加工物资不走收发存表，只有总账侧。
  混进上面的合计，差异会凭空多出这几笔——🧪 3 月实测会显示 **40,347.09**，而真实差异只有 ±1.92。
- **合并范围要跟着并页搬**：`merge_sheets` 原来只搬值与样式，**合并范围是页级属性**，
  不搬的话并进「汇总透视」后合并全丢。搬的时候偏移要用**源页第 1 行的实际落点**——
  「来源」注释行会把数据整体下推一行，拿 `first` 算会让合并整体高一行、压到表头上（这个坑当场踩了一次）。

🧪 3 月：原材料 7,461,672.58 / 差 1.92；周转材料 482,136.91 / 差 −1.92；库存商品 3,970,768.40 / 差 0.00
——与「账实勾稽」块逐项一致。

## ② 货损明细改回业务方底稿的列序，并把两列手工填的补上

```
归属｜原单编号｜类别｜产品项目｜物料编码｜物料名称｜规格型号｜基本单位｜发出数量｜单位基本单价｜金额｜仓库｜批号｜存货类别｜事务类型｜日期｜凭证字号
```

业务方底稿里**手工填的那两列，工具直接取数填上**：

| 列 | 取自 | 说明 |
|---|---|---|
| **类别** | 凭证的【费用项目】 | 产品货损/包材货损/原辅料货损/原辅料盘盈亏…（V2.308 接上的核算维度） |
| **产品项目** | 金蝶的【物料分组】 | 豆蛋制品/零售其他/植物肉/零售山姆/小料…取值与底稿一致 |

⚠**一张单据拆成多条分录、每条费用项目不同时**（7 月 QTCK011302 就是），
按物料的【存货类别】大类对回去：产成品/自制半成品/委外半成品→产品、包材→包材、其余→原辅料。

🧪 7 月逐类别与凭证侧对照：

| 类别 | 明细页 | 凭证侧 |
|---|---|---|
| 产品货损 | 225,621.63 | 225,621.66 |
| 包材货损 | 72,334.24 | 72,334.27 |
| 原辅料货损 | 26,577.91 | 26,577.89 |
| 原辅料盘盈亏 | −4.00 | −4.00 |

差的几分是流水报表自身尾差，合计仍是那 0.04——损益归集页的勾稽行照旧摆着。

⚠连带两处：**合计行要落在【金额】列**（列序改后金额是 K 列、末列成了凭证字号，
原先按"最后一列"求和会把合计写到凭证字号下面）；**损益归集勾稽公式的金额列 P → K**。
