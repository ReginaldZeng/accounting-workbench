**【发票管家】后补单可恢复删除**。**起因**：测试后补单只能关闭，仍会混在正常列表里；用户希望本人可删，并能在「已删除」中找到。**改法**：新增 `deleted` 软删除状态及删除前状态、删除人、删除时间；财务代填单仅当前登记账号可删/恢复，自助登记单仅当前钉钉登记人可删/恢复，管理员和接收人均不能越权。财务后补池及申请人「我的后补单」新增「已删除」分类和删除/恢复操作，默认全部排除回收站。删除只切换状态，票据、资料、文件、日志及做账记录全部保留；回收站记录停止催票、欠票统计、修改、收票、上传和做账，撤回相关待办并取消未开始排队。恢复回到删除前状态，原已关闭仍保持关闭，其余重算到票状态并按需恢复做账联动。老库启动自动补三个删除字段。**验证**：`python -m unittest tests.test_invoice_books_api` 52 项通过；存储及迁移聚焦测试 9 项通过；系统 Chrome 运行两条删除/恢复浏览器 QA 均通过；`npm run build` 成功；相关 Python 文件 `py_compile` 通过。**遗留**：完整存储套件另有既存 `test_ledger_iter_streams_same_rows_without_json` 失败，旧自助登录 QA 仍按姓名输入框断言，均与本功能无关；构建仍有项目原有的重复字段提示及大包体积警告。
