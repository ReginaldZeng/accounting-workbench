# V2.1055 物流对账：动态费用系统复核导出

日期：2026-11-05

## 需求

人工上传使用 A–G＋动态费用列＋账单备注；系统接入金蝶后，导出追加金蝶数量、check、复核备注，形成可下载、可回传的系统复核表。

## 改动

- 新增 `logistics_dynamic_review.py`：按当前账单行动态费用生成 Excel，保留账单备注，追加金蝶数量、check、复核备注；原始附件页保留。
- 按账单行 ID 读取当前金蝶快照，输出通过、数量不符、金蝶无此单、免核、待确认、待取数、无金蝶单号和人工确认；快照缺失不自动刷新。
- `/api/logistics-review/standard-bill?format=review` 正式导出；默认 A–J 与 A–N 不变。
- 回传解析识别账单备注后的三列系统结果并忽略，不计入费用；金额仍按动态费用列逐行勾稽。
- 数据接入页增加「导出系统复核表」；技能验收脚本支持动态费用及系统复核表。

## 验证

- 新增系统复核导出测试 3 项；动态解析 5 项、A–N 转换 2 项、物流凭证回归 55 项，合计 65 项通过。
- 覆盖费用合计、各核对状态、人工确认、未取数、无单号、原始页保留、复核表回传及错误尾部结构。
- 生产极鲜达 2026-09 文件待部署后下载验收；不自动刷新金蝶、不审核发票、不登记复核、不写金蝶。
