# V2.735 费用类型：物流部填 vs 系统判，两边对比复核

## 用户口径（2026-10-01）
「我们系统做归系统做，他们填归他们填……我们就可以复核做的对不对」。
所以规范第 4 列「费用类型」改为每行必填（v1.1 原写「有单号的运输费不填」，作废）。系统再按金蝶单据独立判一遍，两边不一致的标出来。

## 改动
- 解析：spec 新增 `fee_col`，读「费用类型」列存进 bill_lines.fee。
- 系统判 `_sys_fee`（规范附表 H）：
  - XSCKD / XQLCK / RK → 出库运费；
  - CGRK / CGTL / FBDC / FBDR → 入库运费；
  - QTCK 看领料部门：研发中心领料 → 研发外购，其余 → 出库运费。
- 物流部填 `_fill_fee`：
  - 新列：按附表 F 名称归一（销售出库/出库装卸 → 出库运费；成品·原料入库/调拨/入库装卸 → 入库运费；研发设备采购 → 研发外购；仓储 → 仓储费；设备调拨 → 搬运费）；
  - 老账单（8 月）：从「类别」标注推（研发 / 仓储 / 销售单·样品单·福利·退货 / 调拨·入库）。
- 结论 `fee_chk`：
  - ok = 一致；
  - diff = 不一致；
  - nofill = 物流部没填；
  - nosys = 无单号，系统判不了；
  - na = 仓储、搬运这类不看单据。
- 逐单页新增分组「费用类型不一致 N」。不一致的行在主体下标红「物流部填 X ≠ 系统判 Y」，没填的标「物流部未填 · 系统判 Y」。
- 比对只核到类别这一层；科目层面（6601 / 6401 / 5101）仍由逐笔计提对账管。
