**【平台通用】接线自动识别 + 模型配置页 UI 打磨**

## 一、接入方式自动识别（Owner 问「②和②-c 有什么区别」引出的可视化缺口）

② 的「接入方式」列原来写死「直连」——工作台切到网关后不会变，②（各台现状）与 ②-c（网关钥匙串）
的关系看不出来。改：`llm_hub._probe` 从工作台自报的 `baseUrl` 判定 `viaGateway`（指向 GW_BASE 即
经网关）——**事实态不是配置态**，工作台改 .env 的瞬间这里跟着变。前端显示「经网关」绿标（tooltip：
凭证额度/吊销对它生效、用量以 ②-c 网关流水为准）或「直连厂商 ⓘ」（tooltip：网关凭证对它不生效）。

双向实测：BP 临时切网关 → ② 实时变「经网关」、keyHint 变 tok_***；回切直连 → 变回「直连厂商」、sk-***。

## 二、视觉打磨（Owner「这里的前端UI可以改好看点吗」，对着截图逐项修）

| 问题（截图可见） | 修法 |
|---|---|
| ④ 审计表出横向滚动条、表头发白 | `.mc-scroll` 容器：`table-layout:fixed` + colgroup 定宽 + 内容列省略号 → **横条绝迹**；表头 `position:sticky` + 深色底（#1d1830）；细暗紫滚动条（webkit-scrollbar 8px） |
| ②-b 策略表单排版糙 | 栅格化 `.mc-form`（96px 标签列右对齐 + 输入行呼吸感）；保存钮升级渐变主按钮 |
| ③ KPI 平淡 | 左侧 3px 色条：调用=紫、token=青（--ai）、失败=红（为 0 时灰）、人数=灰；数字 tabular-nums |
| 控件东一套西一套 | 统一 `.mc-inp`（焦点紫边）/ `.mc-btn.pri`（门户同款渐变+投影）/ `.mc-btn.danger`（吊销红）；pill 加状态圆点；卡片 hover 微亮边 |

浏览器实测：审计区 `scrollWidth==clientWidth`（无横滚）、表头计算色 rgb(29,24,48)、策略栅格与
4 个 KPI 色条渲染正常。vite build PASS。
