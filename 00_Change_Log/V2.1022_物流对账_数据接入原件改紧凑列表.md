# V2.1022｜物流对账：数据接入原件改紧凑列表

日期：2026-10-26
状态：本地已构建验证（未提交、未发布）

## 实现

- `01_Current_Deliverables/app/frontend/src/views/LogisticsIntake.jsx`
  - 将第①步数据接入的账单原件双栏卡片改为单张紧凑表格：账单份名/原文件名、解析金额、来源/操作人、解析时间、大小、操作。
  - 长文件名允许换行，并通过 `title` 保留完整名称；解析金额按 `src` 取 `data.bills` 中对应项。
  - 新增“下载原件”和“替换”，替换按钮带当前份名打开原账单管理弹窗并自动选文件；保留重新解析、`busy` 防重复、`locked` 禁用写操作和原空状态，锁定不影响只读下载。
  - 钉钉附件改为表格下方单行汇总，显示总数、角色数量及自动接入说明。
  - 表格桌面紧凑；390px 下仅表格容器内部横向滚动，不造成页面横向溢出。
- `01_Current_Deliverables/app/frontend/src/api.js`
  - 仅增量添加 `reviewRawUrl(carrier, period, src)`。
- `01_Current_Deliverables/app/backend/routers/logistics_review.py`
  - 新增只读 `GET /api/logistics-review/raw?carrier&period&src`，复用 `_perm` 和 `BR = bill_raw`。
  - 严格按承运商、账期、份名匹配，按 ID 取最新原件；无权限 403，无匹配或非 Excel 原件 404。
  - 支持 xlsx/xls，按原文件名设置 UTF-8 下载响应头。
- `tests/qa_inv_frontend.cjs`
  - 在 ENTRY 增加 `IntakeStep` harness，新增 LIK1 合成 5 份原件用例，覆盖长文件名、金额映射、下载 URL、重解析/busy、locked、附件汇总及 390px 页面无横溢。
- `tests/test_logistics_readiness_api.py`
  - 复用现有 `_load_module`/`_Request` fixture，新增 SQLite 原件下载测试，覆盖最新内容、xlsx/xls 原文件名、权限、跨期、跨承运商及 404。
