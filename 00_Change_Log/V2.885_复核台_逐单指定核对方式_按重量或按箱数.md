# V2.885 复核台：可以逐张单指定核对方式（按重量 / 按箱数）

- 日期：2026-10-09
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 物流账单复核台 › 第②步 逐单核价核量

## 起因

V2.883 之后极鲜达山姆页的单大多按托核过了，还剩两张（XSCKD214377、XSCKD214378）是按实际毛重 624 千克收的，留在「按重量核」里判不符。
用户问「所以其实我可以针对每一张单改计费标准？」——当时不能，核对方式只有系统自动挑和一家承运商一档的设置。用户答：加。

## 改法

- 第②步点开一张单，展开区「归类」下面多一行「核对方式」：系统自动 / 按重量核（账单重量 对 金蝶重量）/ 按箱数核（账单件数 对 金蝶箱数）。
- 选完即保存、马上重判。结论里写明「人工指定按箱数核（谁 哪天）」，操作日志留痕；选回「系统自动」就撤掉。
- 只换「拿什么比」，尺子不变：按重量仍是这家的毛重比范围（没设就是 2% 以内），按箱数仍是原来的箱数规则。
- 账单这一行没写重量的不能选按重量，没写件数（或账单量是天、趟、方、板）的不能选按箱数；万一指定了比不了的，系统不听，照自动的办法并写明。
- 已登记复核的月份不能改。按件数核的快递（迅鸽）没有这一项。
- 指定是按「承运商 + 账期 + 单号」存的，重新解析账单后仍然有效。

## 改动

- `backend/routers/logistics_review.py`：`_doc_modes(carrier)`（设置键 `logi_doc_mode`）、`_box_docs` 里应用、`POST /api/logistics-review/doc-mode`；单据上带 `force_mode / can_mode / can_weight / can_box`。
- `frontend/src/views/LogisticsReview.jsx`、`api.js`：展开区的「核对方式」下拉。

## 验证（线上只读，极鲜达 2026-08，140 行）

- 不指定：新旧逐行完全一样。
- 内存里试指定（不写库）：XSCKD214377 / 214378 指定按箱数 → 账单 48 件 对 金蝶 48 箱，一致；
  XSCKD213218 指定按重量 → 650 对 522.24 千克，不符（按托的单强行按重量会判不符，符合预期）；
  XSCKD213265 指定按箱数 → 52 件 对 35 箱，仍不符（没有因为换了比法就放过）；
  一张包天的调拨单指定按重量 → 账单没有重量，系统不听并写明。
- 除了指定的这几张，其余行没有变化。
