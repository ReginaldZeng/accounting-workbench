# V2.785 物流复核：给 BP 工作台读物流账单的内部只读口

日期：2026-10-04

## 背景
BP 工作台「STEP5 出库费用归属」原来靠人上传两样东西：金蝶「销售出库单（含运费）」Excel 和天鹰装货表。
用户（2026-10-03）：「这一页应该去接入核算工作台才对」「不管是装卸费还是运费，那边都有已审核过的」。
复核台里各家承运商的账单已经逐单进库、分好 运费 / 装卸费 / 其他（V2.778），但「单据运费」页的接口要登录、分页、
按出库单所在月取（账期不限），BP 后端读不了，口径也不是它要的（BP 要和序时账的计提对，得按账单月）。

## 改动（只加接口，不改任何既有行为）
- 新文件 `routers/bp_logistics_feed.py`：`GET /api/internal/bp-logistics-lines?period=YYYY-MM`
  - 一次给出该**账单月**全部逐单明细行（`grain=detail`，含没写单号的），不取金蝶、不分页、不写任何数据。
  - 每行：承运商、归口后的主体 / 费用类型、单号列表（一格多单拆开）、含税金额、运费 / 装卸费 / 其他三类拆分、是否已复核、账单份。
  - 每家承运商：全称、是否已登记复核（登记制算已复核）、复核人 / 时间、税率维表里的税率。
  - 口径直接复用 `routers/logistics_review.py` 的 `_eff_fee` / `_eff_subject` / `_line_buckets`，不另写一套——页面改口径，这里跟着变。
- `app.py`：注册这个路由（两行）。登录门对 `/api/internal/bp-*` 的放行是 V2.728 已有的，不用动。
- 鉴权同 `/api/internal/bp-identity`：仅 BP 后端同机回环 + `X-Internal-Token`（`BOMCOST_INTERNAL_TOKEN`），路由里再验一遍。不对浏览器开放。

没有动 `routers/logistics_review.py`（另一条线当天在密集改它）。

## 自测
- 临时 SQLite + TestClient 12 项全过：无令牌 / 错令牌 / 非回环来源 401；缺账期 400；只给本账单月的 detail 行（计提粒度、别的月份不出现）；
  一格多单拆开；分项拆成 运费 + 装卸；登记制与已登记承运商算已复核；「无单据」单号列表为空；每行三类之和 = 金额。
- 服务器只读验证（上线前，用同一个 `build_feed` 对 2026-08 真实账单）：7,205 行 / 939,824.75 元；归口出库运费 730,274.47
  （运费 642,278.42 + 装卸 75,105.97 + 其他 12,890.08），其中销售出库单号上的 717,310.14，减去不在本月出库单里的 5,232.08
  后 = 页面「销售出库单」合计（不含退货费用 228）。

## 部署
纯后端，随 main 自动部署后重启生效。服务器 `.env` 已有 `BOMCOST_INTERNAL_TOKEN`，无需新配置。
BP 侧对应版本 V2.571（「从核算同步运费」）要等这个口上线后再部署。
