# V2.434 · 核算表导出支持网页预览（原版 / 重排版，不下载先看）

**日期**：2026-09-05　**分支**：main

Reginald：导出的核算表能不能先预览。

## 做法

服务端把 xlsx 转成只读 HTML，前端在新标签页打开——**不引前端 xlsx 库、离线可用**。

- 后端新增通用助手 `_xlsx_to_html(data, title)`：openpyxl 读值渲染成 HTML 表格，合并单元格按 rowspan/colspan 合并，数字右对齐。原版（真 Excel 有缓存值）、重排版（build_pretty 写的是字面值非公式）都能正确出值。
- `/api/bom/export/pretty` 与 `/api/bom/export/original` 加 `preview=1` 参数：带上时返回 `HTMLResponse` 预览，不带仍是 xlsx 下载。权限口径不变（`CAP_EXPORT`）。
- 前端导出下拉每项下加一条「🔍 预览…（不下载，在新标签页查看）」，`target=_blank` 打开 `…&preview=1`。

隔离测试 `_xlsx_to_html`（含合并单元格）通过；后端 py_compile、前端 build 均过。
