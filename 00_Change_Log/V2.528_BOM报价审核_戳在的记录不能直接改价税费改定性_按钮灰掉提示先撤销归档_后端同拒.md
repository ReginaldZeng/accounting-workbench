# V2.528 · 初审/终审戳在的记录不能直接改：修改价税费、改定性按钮灰掉并提示先「撤销归档」，后端同样拒绝

**日期**：2026-09-08　**业务方问**：「两个戳都盖着，还能修改价税费，这些按钮应该灰色吧，提示要先撤销归档之类的？」

## 口径

以前改了成本会自动「失效审核态」打回已复核（V2.4xx `_invalidate_review`）——能改，只是改完戳自动掉。业务方定：**戳在就不能直接改**，必须先明确点「撤销归档」，改完再重新审核归档，动作留痕清楚、不会"顺手"改掉已审核的数。

## 改

- 前端详情页：`entry.status ∈ {初审, 已审核}` 时「✎ 修改价税费」「⚑ 改定性」置灰，悬停提示「已归档（初审/终审戳在），先点「撤销归档」」；「撤销归档」照旧可点。
- 后端 `/api/bom/review`（改费用/渠道）与 `/api/bom/apply-goods`（采纳商品版）：状态为 初审/已审核 → 400「已归档，先撤销归档」，直连 API 也绕不过。`_invalidate_review` 保留给其它路径兜底。
- 静态包重建。
