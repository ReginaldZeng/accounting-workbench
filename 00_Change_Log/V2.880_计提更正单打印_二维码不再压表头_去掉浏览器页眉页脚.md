# V2.880 计提更正单打印：二维码不再压表头；去掉浏览器自己加的页眉页脚

- 日期：2026-10-09
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 复核台 / 付款做账 › 打印计提更正单

## 起因

用户打链盟 8 月的计提更正单，发打印预览截图问「这个能直接打印吗」。内容没问题，但版式有两处毛病：

1. 右上角二维码下面那行字「装订时扫这里」压在表头最后一列「更正人/日期」上（抬头三行比二维码矮）。
2. 浏览器自己在纸的四角加了页眉页脚：打印时间、网页标题、服务器 IP 地址、页码。订进凭证里不好看，IP 也不该印出来。

## 改法

- 抬头外面包一层，有二维码时至少留 30 毫米高，表格从二维码下面开始；同一主体几份合成一张（右上角几个二维码）的同样处理。
- 打印样式里自己定义页边的内容：四角留空，只在右下角印小号页码「1 / 2」。新版 Chrome / Edge 见到网页自己定了，就不再加它那套页眉页脚。
  老版本浏览器不认这个写法，仍要在打印框里取消勾选「页眉和页脚」。

## 改动

- `frontend/src/views/LogisticsVoucher.jsx`：`adjustSheet`、`mergedSheet` 抬头包 `.hd`；`SHEET_CSS` 加 `.hd.q` 和 `@page` 页边内容。

## 验证

本机 Edge 无头模式按默认（带页眉页脚）出 PDF 样张两页：二维码和说明文字都在表格上方，不再重叠；四角的时间、标题、网址没有了，右下角是页码。
真打印机上的效果以用户实际打印为准。
