# V2.659 复核结果导出：附上原始账单整表 sheet（可追溯）+ 接复核列

- Date: 2026-09-28 | Author: Claude Opus 4.8

## 用户口径
后面的 sheet 页要跟着原始账单——把顺丰原始账单整表放进导出，右侧接上复核列。

## 做了什么
- 原始账单持久化到 `finance_workbench/raw_bills/<承运商>_<账期>.json`（顺丰8月2个明细sheet已存；后续账单上传管线写同结构）。
- 导出末尾若有原账单，逐 sheet 原样附「原账单-<sheet名>」，右侧接 3 列：金蝶出库重量kg｜换算系数(账单/金蝶)｜核量结论(重量一致/顺丰多报/少报)，按金蝶单号匹配。
- 至此导出 = 费用项汇总 + 复核明细(ERP/账单/复核分组配色) + 原账单整表(接复核列)，对齐 Codex 三段式。
