# V2.274 电商对账 · 剔除留痕定性登记

## 一句话
需求方定："旁边是不是要做一个操作啊？识别出来的做个记录之类的？"——剔除明细每笔旁边加**定性登记**：对上活动/推广=正常（记活动名）、对不上=违规·要追（记去向/追款说明），闭环 V2.273 的"逐笔过目定性"。

## 改了什么
- db：新表 `ec_excl_notes`——按 **期间×店铺×流水号** 记（不挂 run_id，**重跑不丢**）；一笔一条，改判即覆盖，留最后判定人/时间；kind/flow_ts/amount 登记时抄档防失联。
- routers：GET excl-notes（进得了页就能看）；POST excl-note（要 ec_settle_upload 权限；verdict 只收 正常/违规，**空=撤销登记**；每次写都进审计台账 ec_excl_note）。
- EcomSettle.jsx：明细表第五列「处理记录」——未登记=登记按钮（无权限者显示"未登记"）；编辑器=判定下拉（对上活动/推广 / 违规·要追）+说明框+保存/取消；已登记=绿✓/红✗徽章+说明+判定人·日期+改/撤；旧跑批无流水号的行明说不可登记。

## 验证（E2E，测试记录验后已撤销）
登记（正常+"7月万相台推广充值·运营已确认"）→ API 按 2026-07×官旗店 查得（不挂跑批号）→ 改判违规（✗ 违规·要追 呈现）→ 撤销（库空、行恢复登记按钮）。审计台账每步留痕。
