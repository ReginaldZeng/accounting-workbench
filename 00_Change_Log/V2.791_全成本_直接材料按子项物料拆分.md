# V2.791 全成本溯源：直接材料按子项物料拆分（可叠加底稿对比、带差异率与差异原因、半成品可展开）

日期：2026-10-04　作者：Claude / c

起因：用户看了产品明细后说「没看到一个直接材料的拆分」，并给了自己的 Excel 版式——每颗子项物料一行，ERP 侧单耗/单位成本/含税单价/含税成本，报价侧单耗/单价/成本，用量差异率、单价差异率、整体差异率、差异原因，底部合计，半成品（高浓豆浆）下面再列它自己的用料。

原页面的问题：「工单用量参考」按工单一行行列，同一颗料在每张工单重复出现；汇总到产品、按每公斤算的表只在「核算底稿对比」里，**没有底稿就整张不显示**；没有差异率、没有合计、没有差异原因、半成品不能展开。

## 改动

产品明细第一个页签由「核算底稿对比」改为 **「直接材料拆分」**：

- **没有底稿也能看**：本期净领用（领料＋补料−退料）按子项物料汇总到产品，折成每公斤完工产品的单耗、出库单价、单位成本、占比；底部合计＝本期材料投入。
- **选了核算底稿就并排对比**（版式照用户的 Excel）：实际（金蝶）｜底稿（报价）｜用量差异率、单价差异率、整体差异率｜差异原因。差异率＝实际÷底稿−1。原来的「用量影响/计价影响/成本差额」金额挪到点开行里。
- **不含税 / 含税切换**：底稿侧含税用含税采购价；实际侧按这颗料在底稿里的「含税采购价÷不含税计价」折成含税（专票约 1＋税率，普票为 1，不重复加税），底稿里没有的料按本期应付单税率折，都没有就不折并注明。差异率两种口径下一致。
- **差异原因**：每颗料一格，直接写、回车或点别处保存；跟「期间＋产品」走，重新试算后还在；留痕到操作日志。需要「成本台账维护」权限。
- **半成品展开**：子项物料如果本期是本账簿自制的（出现在本期全成本表里），标「本期自制」，点开后把它自己的用料按「每公斤本产品用了多少公斤半成品」折算列在下面，最后一行「其余」＝半成品的人工、制造费用及计价差。目前只展开一层。

后端：
- `actual_cost_standard.py`：新增 `breakdown()`（无底稿的拆分）；`compare()` 每行补 `qty_rate / price_rate / cost_rate`、占比、含税字段，汇总补含税合计与整体差异率。原有字段的值不变。
- `routers/actual_cost.py`：`/product` 带上 `breakdown` 和 `notes`；新增 `POST /material-note`。备注存在期间输入表里（`ac:n:` 前缀），没有改库表结构。
- 前端 `ActualCostStandard.jsx` 重写，`ActualCostTrace.jsx` / `ActualCost.jsx` / `actualCostShared.jsx` / `actualCost.css` 配合。

## 验证

- 新旧对比结果核对：300600104（冷冻米麻薯）13 行原有字段逐行一致，只有「底稿里没有的料」的税率由空变为取应付单税率（本次有意为之）。
- 单测 `kernels/test_actual_cost.py` 增 3 项（共 8 项）：拆分的单耗/单价/成本/占比/衔接差额、差异率、含税倍率（专票与普票）。
- Codex 离线校验（接口、下钻）改指向本工作树后端后通过。
- 本机整套工作台实点（本地库＋金蝶只读）：
  - 305000016 低脂低 GI 豆腐面（没有底稿）：读取金蝶明细后拆出 9 颗料，合计 15.8192 元/kg，与页面上方的直接材料一致；其中豆腐面（细）13.7738（87.1%）标「本期自制」，展开后列出它的 10 颗用料和「其余」8.4293。
  - 300600104 冷冻米麻薯（本地测试库放了一份样本底稿）：对比表、三个差异率、合计（实际 7.9531 对底稿 8.9764，−11.4%）、含税切换（8.9679 对 10.1206）、差异原因保存与回读都正常。
