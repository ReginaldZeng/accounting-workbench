# V2.773 单据运费：账单在复核台登记已复核后，逐单运费自动进来

日期：2026-10-03

## 背景
用户：「我们是不是在核对的同时，确认后应该补充到逐单运费上」。
查现状：「单据运费·销售出库」页签只认账单行 `fee='销售出库费用'` 的数据，8 月只有顺丰冷运 24 张；链盟/极鲜达/易风达/迅鸽等 7,000 多张单、90 多万都进不来，也不看复核状态。

## 改动
- `routers/logistics_review.py` `GET /api/logistics-review/doc-freight`（mode=sales）：
  - 数据＝本月 **已在复核台「确认通过并登记已复核」** 的承运商的逐单账单明细（带金蝶单号的）。不复制数据，直接读中间表按登记状态过滤
    （登记后当月归类、备注锁定，读到的就是定稿）；撤销登记即退出。
  - 所有单据类型都进（销售出库 / 采购入库 / 调拨 / 其他出库），费用类型用复核台归口后的（出库运费 / 入库运费 / 研发外购…），主体、产品线用人工改过的归类。
  - 按「承运商 + 单号」分组（同一张单可能有两家的费用，如链盟运费 + 天鹰装货费）。
  - 新增筛选 `carrier` / `ffee`；返回 `facets`(已登记的承运商及金额、费用类型)、`pending`(已导入未登记的承运商及金额)、`nodoc`(没有单号、到不了单据的费用)。
- `LogisticsDocFreight.jsx`：第一个页签改名「账单复核（已登记）」；上方列出已登记的承运商(可点选筛选)、费用类型下拉、未登记的承运商提示、无单号费用提示；
  费用类型列显示归口后的类型(下面小字是账单原费用名)。
- 「其他单据（登记制）」页签不变。

## 行为变化
- 顺丰冷运 8 月原来未登记也显示，现在要登记已复核后才进来（在「还没登记复核」提示里能看到）。
