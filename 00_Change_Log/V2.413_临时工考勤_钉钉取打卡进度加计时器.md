# V2.413 · 从钉钉取打卡：进度加计时器（已用 / 用时）

**日期**：2026-08-30　**分支**：main

Reginald：「这里要不加一个计时器吧，真的跑了好久」。

钉钉取打卡慢（整月＋跨月边界能三五分钟，2026-06 实测 143 秒 / 311 秒），进度条只有
「取打卡 8400/9120」的计数，看不出跑了多久、心里没底。

## 改法

`DingPull` 组件里加一个本地计时器：
- **进行中**：从取数发起那刻起，每秒滚动显示「已用 M:SS」，跟在进度说明后面；
- **完成**：定格成「用时 M:SS」，进结论行（取到 X 人 / Y 人日 · 用时 …）；
- 下次再取数自动从 0 重新计时。

纯前端、只读——不碰取数逻辑、不改任何数据。hooks 放在组件早返回之前无条件调用（守 React 规则），
计时用 `Date.now()` 差值 + `setInterval` 每秒刷新，状态离开「进行中」即清 interval、起点归零。
