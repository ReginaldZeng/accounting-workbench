## 新页面

- **① 成本总览**：一句话结论（全成本 旧 → 新、涨跌额与 %、影响最大的三项）＋五分项表（原料/包材/加工费/装卸费/管理费/全成本 两版并排、变化额、**主要原因**——原料/包材列出影响最大的两行物料）。
- **② 逐料对比**一张表：每行一种物料，列＝变化标签 / 物料（名称，编码·型号，信息变化以「旧 → 新」写在名下）/ 添加量 / 含税价 / 税率 / 成本（含税）/ 对全成本影响；**每格「对比版 → 当前版」，没变只写一个数**；按原料/包材分段，段头写行数与变化行数，段尾小计 旧 → 新。
- 变化标签：新增 / 移除 / 调价 / 调量 / 税率 / **换料**（名称编码变了但同型号同用量，按一行看而不是一增一删）/ 信息变化 / 一致。
- **配对**：真实物料编码（「XX系列」占位码不算）› 名称+型号 › 名称 › 型号+用量（换料），一对一不重复消费。
- 「**只看有变化**」开关（默认开，段内显示已隐藏几行）取代两套表。
- **导出差异清单**：CSV（带 BOM，Excel 直接打开中文不乱码）＝版本抬头 + 成本总览 + 逐料明细（两版添加量/含税价/税率/成本、影响、信息变化）。
- 选版本（V2.698 左上角入口、两边按 CP 搜选、自动带上一版、跨 CP 提示）保持不变。
