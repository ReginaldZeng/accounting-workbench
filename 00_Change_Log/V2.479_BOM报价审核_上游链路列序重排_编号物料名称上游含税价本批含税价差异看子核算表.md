# V2.479 · 上游链路列序重排：编号 · 物料名称 · 上游含税价 · 本批含税价 · 差异 · 看子核算表

**日期**：2026-09-06　**业务方定**：「上游链路也要带出来那个型号，就是复配料或者半成品的编码。字段顺序是：编号，物料名称，上游含税价，本批含税价，差异，看子核算表」。

## 改（只前端 `UpstreamSection`）

| 列 | 取值 |
|---|---|
| 编号 | 上游产品的研发编码（台账 `cp_code`，即料行型号栏的 SZF/SZY/CP 码） |
| 物料名称 | 本品料行名；按 CP 配上的（V2.478）下方小字「台账名「…」（按 CP 配上）」 |
| 上游含税价 | 上游那版全成本含税；同名多版仍带「取同组/同单… · 共 N 版」小字 |
| 本批含税价 | 本品料行用的含税价 |
| 差异 | 本批 − 上游（红字带正负）+「价格对不上」标签；对得上显 0.00。**上游审核状态标签（已定稿/初审/未审核/补录）并入此列**，不单列 |
| 看子核算表 | 原链接 |

后端 V2.478 已带 `upCp/upName/matchBy`，本版不动接口。静态包已重建。
