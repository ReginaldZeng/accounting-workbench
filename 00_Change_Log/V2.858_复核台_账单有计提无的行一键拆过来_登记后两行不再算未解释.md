# V2.858 复核台第①步：「账单有、计提无」的行可以一键从多提的那笔拆过来；登记后两行不再算未解释

日期：2026-10-06

用户讲清了业务实质：「计提的时候全都归集在了零售，但是我们在付款复核发现有问题，他应该是电商，所以计提数肯定是0」。

页面上这种情形是两行：零售那笔计提比账单多 X（+X），电商那行账单有、计提无（−X）。原来两行各自要人写「为什么差」，登记了拆分更正以后也还算「2 笔有差异未解释」。

改动：
- 「账单有、计提无」的那一行多一个按钮「计提在 记-N 里 → 拆 X 过来」：系统在同主体里找那笔多出来的计提（先看同一费用类型、差异最接近这行金额的），点一下就打开它的「改维度」，已经填好「只改其中 X」「产品分类＝这一行的」，核对后保存。
- 登记了这种拆分更正以后：
  - 计提那行（差异正好等于拆出去的金额）注明「多出的 X 由这笔更正拆走」；
  - 账单那行显示「待更正 ← 从 记-N 拆 X 过来」；
  - 两行都不再标红、不算进「有差异未解释」。差异数字本身不变（金蝶还没改，付款做账时才红冲重提）。

验证：线上只读叠加，丰源 8 月——登记前未解释 2 笔；模拟登记「记-389 其中 1,450 改电商」后未解释 0 笔，记-389 标「由更正拆走」、电商那行标「从 记-389 拆过来」。页面上没有真点过。

上线：后端有改动，需重启。
