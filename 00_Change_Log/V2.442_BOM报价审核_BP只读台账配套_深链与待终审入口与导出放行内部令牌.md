# V2.442 · BP 只读标准成本台账配套：接口带深链 + 待终审入口 + 导出/预览放行内部令牌（只准已审核版）+ SPA hash 深链

**日期**：2026-09-05　**分支**：main

## 业务方定的原则

BP 工作台要一张**不可修改**的标准成本台账，带「关联核算表 / 对比 / 下载核算表」；财务BP 的终审**在核算工作台做**（成本会计初审 → BP 终审，两个戳都在核算侧）。
→ **入口在 BP，动作在核算。** BP 页面只放链接和数字，不复制审核流。

## 核算侧改动

- `GET /api/bomcost/final` 每行加 `links{detailUrl, compareUrl, previewUrl, downloadUrl, originalUrl}`（相对门户根路径），顶层加 `pendingFinalCount` / `pendingFinalUrl`。契约只增不改。
- 新增 `GET /api/bomcost/pending-final`（鉴权同 final）：待终审行（定稿指针 + 状态初审）`count/rows/listUrl`，每行 `finalReviewUrl=/#/bomstd?entry=…&final=1`、`replaces[]`（本版将替代的旧 CP，BP 终审前看得见影响面）。
- 导出 `/api/bom/export/pretty|original`：鉴权改 `_export_auth`——门户用户仍须「导出」权限；**内部令牌（回环）放行但只准已审核版**，初审未终审 403（对外门控不因换通道而松）。
- 前端 SPA hash 深链：`App.jsx` 登录后见 `#/<菜单key>` 直落核算工作台该菜单（准入仍走 canView）；`BomPrice` 解析 `?entry=…`（详情）/`&compare=1`（版本对比）/`&final=1`（有终审权限直开终审弹窗，否则退到详情），只消费一次并把 hash 收回 `#/bomstd`。
- 文档：`docs/20260903_BOM报价审核/对接说明_BP只读标准成本台账_20260905.md`（BP 侧页面怎么摆、链接怎么拼、引用次数归 BP 自己算）；回复文档加 §7（身份键建议改 `productKey`，**待 BP 线确认**）与 §8（本版配套清单）。
