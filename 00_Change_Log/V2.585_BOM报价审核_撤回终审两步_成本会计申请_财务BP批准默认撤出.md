# V2.585 · BOM报价审核：撤回终审改两步——成本会计申请、财务BP批准（默认＝撤出对外）；已终审对外的版本不能再被单方面撤销/替换

**日期**：2026-09-15　**业务方问**：「如果要撤回终审，是不是要我同意，或者有独立授权码？」→ 定：**申请 + 批准**（不用授权码），**默认撤出**。

## 现状里的漏洞

两道戳保证了成本会计"推不上去"错的数（改了必重审、只有终审版对外），但没保证"拉不下来"对的数：「撤销审核」和「更新源表/重连钉钉替换」都只要成本会计权限，对已终审、正在对外的版本也能直接动，撤/换那一刻旧版就退出对外，BP 拿不到成本，而财务BP毫不知情。

## 改

- **`_bp_stamped(e)`**：已审核 + 终审戳是财务BP盖的（补录/导入自封的不算）＝受保护版本。
- **撤销审核收口**：受保护版本成本会计点「撤销审核」→ 拒，提示走申请；**主管理员例外可直接撤**（单人模式，留痕「主管理员直接撤回终审」）。初审版照旧自己撤。
- **替换收口**：`_do_replace_sheet` 里旧版受保护 → 非主管理员不能替换，该产品记 `blockedFinal` 回报「请先申请撤回终审」；其余草稿产品照常替换。
- **两步流程**（新列 `unfinal_req` JSON `{state,by,at,reason,decidedBy,decidedAt,note,mode}`）：
  - `POST /api/bom/unfinal-request`（成本会计）：理由必填；**申请期间本版照常对外**；钉钉发给**终审人**（戳上的人，按姓名查花名册，退到门户送达收件人）；重复申请拦。
  - `POST /api/bom/unfinal-review`（财务BP）：**批准＝撤出**——立即清指针、退回复核、恢复它替代过的旧版（`_unfinalize_apply`），`mode=撤出`；**驳回**理由必填、本版继续对外；**申请人不得自批**（主管理员例外）；结果钉钉发申请人。驳回后可再申请。
- **前端**：详情动作条——受保护版本非主管理员显「申请撤回终审」（待批时灰「撤回申请待批」），主管理员仍「撤销审核」；详情横幅「待批撤回终审：谁·何时·理由——期间照常对外」+ 财务BP见「批准撤出 / 驳回」；标准台账行标「待批撤回」；台账接口回 `needUnfinal`。
- 通用 `_notify_person(name, text)`、`_unfinalize_apply`、`_portal_link` 抽出。
