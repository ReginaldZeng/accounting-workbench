# V2.801 付款做账：扫付款单二维码查凭证

日期：2026-10-05

用户：「或者有没有办法，扫描那个付款单二维码，就知道是什么凭证，那个主体」。

纸质付款单右上角的二维码是钉钉审批单链接，能解析出审批实例号；系统记着每张请款单的做账记录（凭证号、账簿）。接起来即可。

- `routers/logistics_voucher.py`：`POST /api/logistics-voucher/scan {code}`（只读）。
  - 认码沿用发票管家「扫审批单」那套（`classify_code` / `resolve_link`）：钉钉审批二维码链接、或 20 位审批编号。扫到发票二维码会提示扫错了。
  - 物流请款单：返回主体、凭证号、凭证月份、供应商、金额、审批编号、金蝶付款单号；主体更正的红冲凭证一并列出；还没做账的写明状态。
  - 不是物流请款单的：退一步看发票管家票夹里同步到的金蝶凭证号（报销单等也能查到，前提是发票管家收过它的票且已同步）。
  - 做账记录里多存一项 `n_adjust`（有几笔计提更正），以后扫码能提示「附计提更正单」；此前已做的三张没有这项。
- `LogisticsVoucher.jsx`：右上角「扫码查凭证」→ 弹窗：输入框一直占焦点，扫码枪扫一张出一张；大字显示 主体 + 记-号 + 凭证月份；下面列本次已扫的（按主体计数、重复扫会标红）；可勾「读出来」。
- `api.js`：`voucherScan`。

验证：线上真数据只读试了 8 个码——3 张已做账的物流单（审批编号、带空格的审批编号、带 procInstId 的链接三种写法）都查到对的主体和凭证号；丰源那张返回「还没做账（可做账）」；一张差旅报销单查到「深圳星期零 记-140」；发票二维码、乱码、不存在的编号各给了对应提示。弹窗用这些结果本地渲染看过。
**没试的**：纸质单上真实二维码（钉钉短链接，要去钉钉服务器换实例号）没有实物可扫，这条路和发票管家扫审批单是同一段代码；扫码枪实机未试。
