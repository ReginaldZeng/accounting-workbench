# V2.429 · 前端报错弹后端业务原因，不再只剩「url 400」

**日期**：2026-09-04　**分支**：main

Reginald 点终审被拒，屏幕只弹「操作失败：/api/bom/final-review 400」，看不到真正原因。

## 根因

`api.js` 的 `j()` 在非 2xx 时 `throw new Error(url+' '+status)`——**把后端响应体里的 `{ok:false,msg}` 业务原因整个丢了**。各处 `catch(e)=>flash(e.message)` 于是全显通用状态码。这是全站通病，不止终审。

## 改动

`j()` 非 2xx 时先尝试解析响应体，拿 `msg`（回退 `detail`）抛出；无 JSON 体才回退到 `url status`。一处改，全站每个业务 400/403 的 catch 立刻显真实原因（如终审的「本版初审人是您本人，不能自己终审——终审须由另一人（财务BP）把关」）。

> 说明：终审被拒本身是**设计控制**（[bom_quote.py:1572] 初审人不得自己终审，双人把关方可对外开放），不是 bug；本次只是让被拒原因看得见。

前端 build 过。
