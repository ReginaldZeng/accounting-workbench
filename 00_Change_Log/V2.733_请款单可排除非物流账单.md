# V2.733 钉钉请款单：不属于物流账单的可以排除

## 背景
顺丰速运（物流运输服务001）同一家供应商下，还有「深圳/上海办公室顺丰月结」的请款（8 月 7,537 + 1,972）。这是按部门分摊的办公室快递费，不走物流计提，却被事由里的「8月」认进了总表顺丰速运那一格，格子显示 3 张已付款。用户定：排除。

## 改动
- `logistics_payreq` 加 `excluded` 列（migrate 自动补列）：
  - NULL = 没判过 → 按规则自动判；
  - '' = 人工确认属于物流账单；
  - 非空 = 排除原因。
- 自动规则：事由或附件名带「办公室」的 → 「自动：办公室快递月结」（`kernels/logistics_payreq.auto_exclude`，有单测）。只判一次，人工改过的不再动。
- 排除的请款单不进总表格子、不进「待我审批 / 没认出月份」，也不自动建票夹、不自动导账单。
- 请款单弹窗加「不属于物流账单（排除）」/「恢复：算物流账单」按钮（`POST /api/logistics-review/payreq/exclude`，留审计）。
- 钉钉栏列出「本月已排除」，点开可以恢复。
