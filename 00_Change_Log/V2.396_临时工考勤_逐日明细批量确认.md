# V2.396 · 临时工考勤 · 逐日明细也能批量确认

**日期**：2026-08-29　**分支**：main

Reginald（逐日明细·撑不起上报截图）：「这些都要加批量确认」

## 背景

⑤逐日明细里，撑不起上报 / 报了工时无打卡 / 仅1次卡这些异常，每行右边一个「确认无误」。
一批往往同一个原因（例：几场夜班都跨零点、打卡属实），逐行点、逐行抄同一句理由没意义——
跟⑦合同外调整之前一模一样的问题。

## 加了什么

跟⑦合同外调整同一个做法：

- 每个可认定行前面一个勾选框，表头有「全选当前筛出的可认定行」
- 勾一批 → 批量条弹出「已选 N 项」+ 一句理由 → 一次确认
- 勾到已确认的行 → 出「撤销确认」；混选则两个按钮各管各的
- 只有异常行（撑不起 / 待查 / 仅1次卡）有勾选框，✓撑得住、◇未计工时这些不给（没什么可认的）

## 一个实现细节

逐日异常分两类：**多记**（撑不起上报）和**待查**（仅1次卡等）。后端批量接口一次只收一个类型，
所以前端按类型把选中的分成两组、各调一次。理由一句管这一批，写进每一条记录。

复用 V2.390 已有的 `POST /api/tempatt/ack/batch`，没动后端。

## 校验

2026-06 实测：撑不起 4 行 + 待查 3 行批量认定 → 重跑后都带「已认定」+ 理由，
状态条的「撑不起未认定」归 0；批量撤销 4 条回到 0。测试前备份本期认定、跑完还原，无残留。
