# V2.938 付款做账：去掉「明细」和「凭证装订」按钮；账单月、刷新挪到页头右上角

- 日期：2026-10-13
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 付款做账

## 起因

用户看新总表右上那一排（全部账单月 / 总表·明细 / 凭证装订 ↗ / 刷新）：「现在这个明细还有用吗」。
我对了一下：明细里有的，新总表和「做账步骤」弹窗基本都有；独有的只剩每张计提的费用类型、税率，和按做账类型筛选。
用户：「去掉，然后切换账单月和刷新（注明刷新日期和谁）挪到右上角，跟别的模块一样，装订凭证也删掉」。

## 改动

- `frontend/src/views/LogisticsVoucher.jsx`
  - 去掉「明细」视图和「总表 / 明细」切换；跟着它的状态筛选条、做账类型筛选条、「另有 N 张还没付款单」那一行、老的批量条一起去掉（这些只在明细里用）。
  - 去掉「凭证装订 ↗」按钮（凭证装订在「其它模块 › 凭证装订」，菜单里还在）。
  - 「全部账单月」下拉和「刷新」挪到页头右上角，和别的模块一个位置；刷新左边写「10-13 21:05 刷新 · 曾禹锡」——这一页的数是什么时候、谁读的。刷新的时候按钮显示「刷新中…」。
  - 四步说明那一行现在只剩说明。
- `backend/routers/logistics_voucher.py`：列表接口多带回 `at`（读的时间）、`by`（谁）。

## 没动的

- 页面最下面「装订用 · 凭证月份 … 打印装订对照清单 / 计提更正单」那一条还在：它是打印，不是跳转，别处没有这两个打印入口，没敢一起删。要不要也去掉等用户定。
- 每张计提的费用类型、税率：在「做账步骤」→「凭证预览」里看。
