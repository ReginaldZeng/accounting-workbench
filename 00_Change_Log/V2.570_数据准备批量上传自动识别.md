# V2.570 数据准备批量上传·自动识别 + 请求错误可读化

## 批量上传·自动识别（EcomPreparation.jsx / routers/ec_workbench.py）
- 数据准备页新增「批量上传 · 自动识别」：一次选多个文件，**按表头自动识别资料类型**（平台订单 / 商品与子订单 / 旺店通销售出库 / 退款售后明细），逐个入库，返回逐文件结果（识别为哪类 · 行数 · 是否重复跳过 · 无法识别的列出来，不静默）。免去逐类选择、选错文件、表头对不上的坑。
- 新增只读端点 `POST /api/ec/workbench/upload-auto`：识别只看列结构、不用文件名；单文件内容指纹与 `/upload` 一致，两条通道去重互通；资金流水（支付宝/聚合）仍提示走账户导入，金蝶走只读同步。
- 这是后续「公盘一键取件」共用的同一识别+入库引擎——取件只需把文件来源从本地选择换成读服务器 `EC_INBOX_ROOT` 目录（路径待定，先备好引擎）。
- 本地实测：订单报表→商品与子订单(21268)、退款单→退款售后明细(2614)、旺店通出库→旺店通销售出库(7057)、宝贝销售明细→平台订单(20837)，识别全对，重复正确跳过。

## 请求错误可读化（ecomWorkbenchApi.js）
- `requestJson` 抛错时，非字符串的错误详情（如 FastAPI 校验错误的 detail 对象/数组）自动转成可读文字，避免界面出现「[object Object]」（此前点「查看公盘」在某些服务器返回下即显此串）。

仅前端交互 + 只读入库，不改核算规则、不写金蝶。
