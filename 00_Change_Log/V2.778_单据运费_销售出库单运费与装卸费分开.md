# V2.778 单据运费·销售出库单：运费、装卸费分开

日期：2026-10-03

## 背景
用户：「我觉得运费和装卸费要分开，不然我们就不知道哪些是不含运费的了」。
原来每张出库单只有一个「运费」合计，天鹰的装货费（18.5 元/吨）也算在里面——一张单只有装货费、没有运输费，也显示成「有运费」。

## 改动
- `routers/logistics_review.py`
  - 账单行按分项归三类：**运费**(运输本身及附加：运费/快递费/提货费/送货费/保费/回单费/压车等其他费用)、**装卸费**(装货/卸货/装卸/搬运/上楼)、
    **其他**(仓储/冷藏/处置/操作费/箱子(包材)/退货服务费)。先看行内分项(sub_fees)，分项不够金额的差额和没有分项的行按该行费用名归类；三类之和恒等于该行金额。
  - `/outstock-freight` 每张单返回 fee_tr / fee_ld / fee_ot / fee(合计)，承运商来源也带三类；
    「有运费 / 没有运费」改按运费判（只有装卸费的算没有运费）；state 加 `ldonly`(只有装卸费) / `nofee`(什么费用都没有)；统计加三类合计与两种「没运费」的张数；排序键加三类。
- `LogisticsOutstockFreight.jsx`：费用拆成 运费 / 装卸费 / 其他 / 合计 四列；没有运费的在运费格标「没有运费」；
  合计橙色＝其中有待复核（原「其中待复核」一列并入，鼠标悬停看金额）；卡片显示三类合计；展开行的费用来源按承运商列三类。
