# V2.732 顺丰速运接入物流复核台

## 背景
用户给了《8月顺丰速运960.xlsx》，顺丰速运（金蝶 物流运输服务001）此前在总表上显示「未配」。

## 账单结构
- 「账单总览」：月结总览，本期应付 960。
- 「账单明细」：第 2 行是表头，一行一张运单。物流部在后面补了几列：金蝶单号 / 类别（标注，如 样品单-小料）/ 重量（金蝶）/ 差异 / 组织（主体全称）/ 百分比 / 备注。末行是「合 计」，下面还有一张按类别汇总的透视表。

## 改动
- 取数说明（写入线上库 logistics_intake_spec）：
  - 账单明细 → detail；
  - 单号 = 金蝶单号；金额 = 应付金额；重量 = 计费重量；省份 = 到件地区；产品 = 产品类型；
  - 标注 = 类别；主体 = 组织列（全称）；
  - 账单总览、月结报告 = 忽略。
- `_WEIGHT_CARRIERS` 加「顺丰速运」：按计费重量比金蝶出库重量核量（同顺丰冷运）。
