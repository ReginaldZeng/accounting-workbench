# V2.622 发票管家：发票后补单「税率」改必填

用户看自助登记页（真机）：税率要必填。

- 专票、普票：税率必选，改成下拉（13% / 9% / 6% / 5% / 3% / 1% / 0% / 免税 / 不征税），不再手打。
- 收据：没有税率，框变灰写「收据没有税率」，不用填。
- 业务自助登记页、后补池「新建后补单（财务代填）」两处一致；后端同样拦（没选或认不出的税率不让登记），手写的 3、0.03 统一记成 3%。
- 顺手：表单里改了哪一项就清掉那一项的红字提示（换成收据时「请选税率」一并清掉）。

验证：接口 74（加税率必填、非法税率、3→3%）、前端浏览器回归 33（加没选税率拦、收据不用填）全过。
