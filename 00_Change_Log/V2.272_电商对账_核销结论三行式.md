# V2.272 电商对账 · 核销结论三行式

## 一句话
需求方定：抽屉「核销结论」由一长行改三行——账户到账 / 应收单 / 差异，一行一件事。

## 改了什么
- EcomSettle.jsx：核销结论改 76px 标签列 + 内容列的三行网格：
  - **账户到账**：金额 + 到账时间 · 渠道 · 流水号（标签沿用 V2.260「账户流水」命名口径——渠道有支付宝也有聚合，不写死"银行/支付宝"）；
  - **应收单**：金额 + 应收单号（原结论行没有单号，本次带上）+ 退款调节（有才显示）；
  - **差异**：绿零红非零；机器初判黄字仍在网格下方整行。

## 验证
用户所指订单 3311337975225007168 实测：账户到账 68.11（07-12 13:10:10 · 支付宝 · 流水号 1570807…）/ 应收单 68.11 AR00303280 / 差异 0.00 三行呈现；该单 07-08 下单，时间链前半截（买家下单/付款）同屏在列。
