# V2.253 电商对账 · 两页样式对齐全站设计令牌

## 一句话
需求方看了 V2.251/252 首版说"好难看"——首版沿用了老页面的硬编码配色（#e8ecf5 系），与全站令牌脱节、不支持暗色主题。整体重做为定稿样机的视觉，逻辑零改动。

## 改了什么
- **EcomSettle.jsx / EcomBasicData.jsx**：全部配色改用 styles.css CSS 变量（--bg/--line/--ink/--accent/--red 等，自动适配暗色）；KPI 左侧色条卡、分桶四宫格（点选高亮）、标签药丸、表格 thead 底色+圆角外框、桶色行底（串单红/真差异黄）、btn-primary/btn-sec 复用全站按钮类。
- 布局细节照定稿样机：页头 title+sub、卡片 12px 圆角、tabular-nums 数字、店铺名去前缀省宽。

## 验证
重构建后预览实测：收款核销页 KPI/四宫格/逐单表新样式渲染正常，跑批结果数据不变。

## 教训
样机的样式令牌当初就是从 styles.css 抄的——正式页却没抄回去。以后新页面一律以样机为视觉基准起稿，不参考旧页面的内联配色。
