# V2.749 应付板块 › 物流对账 › 付款做账（合成凭证预览）

## 用户要的（2026-10-01～02）
物流请款单付款后，按做账思路合成一张凭证：**红冲 → 更正 → 核销（暂估转待认证）→ 支付**。原始附件只有两份（计提凭证 + 钉钉付款单），所以合成一张，不拆。
- 能做账 = 已付款 + 发票齐 + 纸质件已到。纸质件没到可以手动放行。
- 物流的发票内容审核放在这一页（分工 A）。
- 第一版只预览，不写金蝶。

## 做法
- `kernels/logistics_voucher.py`（纯函数，单测 6 项）：
  - `plan`：计提凭证和发票按税率分组比含税。
    - 对得上的整张核销；
    - 计提税率开错的（找出哪几张计提挪到发票税率能补平），整张红冲 + 更正到发票税率；
    - 复核台登记过计提更正的，整张红冲 + 更正；
    - 同税率含税一致、税差 ≤0.05 的记尾差（照孝感 8 月记-221）；
    - 含税合计都对不上的 → 人工处理。
  - `build`：
    - 红冲 = 原分录全额取负；
    - 更正 = 按新税率 / 更正值重做，税挂 2221.01.07 暂估；
    - 核销 = 每张票一行 2221.01.06 待认证（摘要以发票号开头，发票管家 V2.746 同步时据此自动标「已做账」），每张计提一行贷暂估（更正过的那笔引用本凭证号，先用 □ 占位）；
    - 支付 = 借 2241.02 / 贷 1002（我方账号取自金蝶付款单）。已经有支付凭证的不再出。
  - 摘要按用户定的写法：
    - `红冲8/565#计提…`，跨年写 `2026-6/424#`；
    - `{发票号}核销8/552#、9/□#计提{供应商}8月线下A、B`；
    - `{申请人}提起支付{供应商}8月线下A、B`。
- `routers/logistics_voucher.py`：
  - `/list`：9/1 起的物流请款单，按状态分组：可做账 / 纸质件未到 / 发票≠请款 / 票不齐 / 未付款 / 已做账。
  - `/preview`：
    - 计提凭证：金蝶本期 2241 贷方挂该供应商、摘要含「计提」的整张分录，带全部核算维度。一张凭证里有多家供应商的转人工。
    - 发票：按审批实例号找票夹。
    - 计提更正：复核台登记的。
    - 付款单：日期 + 我方账号。
  - `/paper-override`：纸质件手动放行，留审计。
- 菜单：应付板块 › 物流对账 › 「付款做账」（`logisticsvoucher`），状态「开发中」，只有开发名单里的人可见。
