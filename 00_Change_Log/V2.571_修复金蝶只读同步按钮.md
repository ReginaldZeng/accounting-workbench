# V2.571 修复金蝶「只读同步」按钮 + api.js 错误可读化

## 金蝶只读同步失效（api.js）
- `ecKdRefresh(period)` 一直把 period **当字符串**塞进 POST body，而后端 `/api/ec/settle/kd-refresh` 用 `period: str = Form(...)` 接收 → 表单解析失败返回 **422**，前端把校验错误对象渲染成「[object Object]」，金蝶应收缓存从来没被这个按钮刷新过。
- 修复：`ecKdRefresh` 兼容字符串 period（内部装成 FormData）；传 FormData 的旧调用不受影响。数据准备页「只读同步」现在真正只读拉取金蝶应收并落缓存。

## 请求错误可读化（api.js 的 j 助手）
- `j` 抛错时非字符串的错误详情（如 FastAPI 422 的 detail 数组）自动转可读文字，避免全站出现「[object Object]」。此前 V2.570 已修 `ecomWorkbenchApi.js` 的同类问题，本次补上 `api.js`。

仅前端修复，不改后端、不改核算、金蝶仍只读。
