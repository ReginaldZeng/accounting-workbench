# V2.987 物流对账：账单复核台第②步改版（7 张卡 + ③归类 + 单据弹窗 + 怀疑重复收费）

日期：2026-10-17

照 2026-10-16 定版的样机改第②步「逐单核价核量」，接上 V2.986 的归类判定。用户 10-16 定范围：这一步做页面、归类、重复收费；「价」只有现有依据(包天包趟报价、恒茂这类按公式核)的打 ✔✘，其余如实写「价没依据」，「价的依据库」(报价单/历史价/整车行情/称重区间)另起一步。

- 数字卡改成一行 7 张（用户 10-16 定）：账单金额 / 可逐单复核比例 / 复核无误 / 数量有误 / 金额有误 / 分类有误 / 怀疑重复收费，点卡片筛单；张数按单号去重（一张调拨单账单上常有几行），金额按行加；可逐单比例的分母＝逐单运费＋没单号的正数费用。
- 表格加「③ 归类」列（归类一致 / 标注不对 / 计提记错 / 判不了，带一句应记哪一行）；「核对结论」下标「怀疑重复收费」。原「物流部填 ≠ 系统判」(V2.735) 在全量模式下由③归类接替，不再重复写。
- 点一张单改成弹窗（不再就地展开）：结论条(带「要做」、归类一句、重复收费＋「不是重复」) → 钱＝量×价(账单 vs 复核量 vs 复核价，✔✘？) → 金蝶出库明细 → 记到哪(金蝶推 ＝/≠ 物流部标注 → 本月计提有没有这一列，断的那环标红＋要改什么) → 处理(原展开行的改主体/费用类型/原因、核对方式、多收扣回、备注，一个不少)；底部上一张/下一张(按当前筛选，键盘 ← →)、确认无误。包天包趟的单「量」写按天/趟收、不比金蝶量。
- 单据 1500 张以内的承运商(后端本来就整家现算缓存)一次取全量，卡片筛选和翻页在页面上做；迅鸽这种几千张的照旧按页取、保留原来的分组标签，也能点开弹窗。
- 后端：
  - `kernels/logistics_classify.find_dups`：同一张单本月或上月别家也收了运输费，或本家同一张单有两行金额一样的运输费（包天包趟一车一行、车型不同金额不同的不算）；装卸、仓储、冷藏、处置、保费、提货送货不算运输费。
  - `GET /api/logistics-review/dups`、`POST /api/logistics-review/dup-ok`（标「不是重复」带原因，存 settings `logi_dup_ok`，登记复核后锁定）。
  - `/classify` 每张单多带物流部原始标注 `annot`。
- 前端：新组件 `views/LogisticsDocPanel.jsx`（DocCards / ClsCell / DocDialog）；`LogisticsReview.jsx` 接线；`api.js` 加 reviewClassify / reviewDups / reviewDupOk，reviewResult 可带 size。
