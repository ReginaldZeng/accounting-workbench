# V2.578 数据准备页体现取件机自动接入：状态带 + 取件记录

数据准备页原来像「手工上传」的样子、底部还写「未挂载公盘」，与取件机每分钟自动接入自相矛盾、误导人。

## 后端（routers/ec_workbench.py）
- `/sources` 增 `pickup`（`_pickup_status(period,shop)`）：全局取件机是否在跑/最近扫描/host + 本店本期由取件机（operator='取件机'）接入的份数与最近时间 + 上轮全盘扫描聚合（接入/去重/跳过认不出/涉及店铺）。

## 前端（EcomPreparation.jsx，已构建进 backend/static）
- 清单上方加**状态带**：🟢 自动接入中·最近扫描·本店本期最近接入 N 份 / 🟠 静默（可能关机或任务停）/ ○ 未部署。
- 「查看公盘」按钮改**「取件记录」**：面板显示取件机运行状态 + 上轮扫描成绩 + 本店接入份数 + 认不出店铺去店铺对照补公盘文件夹名的指引。
- 移除 push 模型下已冗余的「一键取件（inbox-import 拉取）」按钮；批量上传/补充资料保留作手工兜底。
