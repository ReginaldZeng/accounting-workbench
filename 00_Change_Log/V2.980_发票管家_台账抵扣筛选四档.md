# V2.980 发票管家：台账「抵扣」筛选改成四档

- 日期：2026-10-14
- 作者：Claude Opus 5.5
- 起因：用户截图（抵扣下拉：全部/可抵扣/不可抵扣/未判定/已标注勾选/票总管已有）：「这里有点模糊，应该是已标注勾选，可勾选未勾选，不可抵扣，票总管」。原来的「可抵扣」把已标注勾选、票总管已有的票也算进去了（它们也是可抵扣），几档互相重叠。

## 改了什么

- 抵扣下拉改成：**全部｜已标注勾选｜可抵扣未勾选｜不可抵扣｜票总管**，四档互不重叠：
  - 已标注勾选：导出过勾选清单的（含税局已显示勾选的）；
  - 可抵扣未勾选：会计判了可抵扣、还没标注 / 勾选、也不归票总管——就是还要去勾的（新条件 `deduct=open`）；
  - 不可抵扣：会计判了不可抵扣的（含普票）；
  - 票总管：记了「票总管已有」、勾选归票总管做的。
- 台账「抵扣」那一栏原来写「可抵扣」的，改写「可抵扣未勾选」，和筛选一个叫法。
- 老的 `deduct=yes / unset` 参数后端照旧认（导出链接、老书签不坏），只是下拉里不再列。
