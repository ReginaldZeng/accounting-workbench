# V2.716 物流账单中间表金额/数量列 FLOAT → DOUBLE（修 1 万以上金额丢角分）

日期：2026-09-30

## 起因
V2.715 重导迅鸽后账单合计 33,951.08，比两份账单实际 33,951.13 少 0.05：第三方快递费 16,256.05 读回 16,256。
logistics_bill_lines 的 amount 等列是 MySQL FLOAT(单精度，约 6 位有效数字)，7 位以上有效数字的金额丢尾数。

## 改动
- 表定义 Float → Float(53)(MySQL 建为 DOUBLE)；migrate_cols：MySQL 上把 logistics_bill_lines 的 qty/amount/charge_wt/kd_qty/kd_kg/std_amount/price_diff/qty_diff
  与 logistics_price_card 的 price/first_kg 从 float 改 DOUBLE(只改仍是 float 的列，可重复跑)。
- 已存单精度值：13 万以下转双精度后按两位小数取整可还原到分；迅鸽 8 月两份账单改完后重导一次。
