# V2.436 · 重排版核算表按星期九「成本核算表（财务版本）」原版模板重做

**日期**：2026-09-05　**分支**：main

Reginald 给了原版源文件：「变动成本没问题了，但加工费也要参考我发的」「重排版也按照这个来」。据此把 `build_pretty` 整体重写，对齐原版排版；原版预览不动。

## 排版（对齐原版 39 行 × B~Q 列）

- **表头信息区**（行 3~6）：供应商名称/审核日期、产品名称/包装规格、物料编码(ERP)/研发编码、客户/预估订单需求，C:H 与 K:Q 合并。
- **①变动成本**：类别（原料成本/包装成本 竖向合并）· 物料编码 · 物料名称 · 型号 · 规格 · 品牌 · 添加量 · 单位 · 含税含运采购价 · 税率 · **发票类别** · 成本不含税 · 占比 · 报价说明 · **订单对应用量**；小计 / 变动成本合计；B 列「1、变动成本」竖向合并。
- **②制造费用**：人工成本（生产人员数量/月均工资/产量，加工费挂此：K 单价含税、N 成本不含税=÷1.13，K/N/O 竖向合并）+ 制造成本（水/电/燃气/折旧 N/A、0）+ 小计。**③工厂费用**（管理费用/厂商利润 N/A、0）+ 小计。**④运输费用**、**⑤装卸费**：每公斤消耗量 1.0000、税率（运输 9% / 装卸 6%，模板惯例）、发票专票；装卸成本不含税＝单价÷1.06（原版 0.18→0.17 同法）。
- **6~10 汇总**：成本合计(不含税)→增值税(×13%)→成本合计(含税)(×1.13)→管理费→全成本；**值跨 C:N 合并居中**（原版 C35:N35 合并单元格）、占比在 O、说明在 P。末行「源表全成本（对账）」+ 差异。

## 口径

写**计算后的值**（非公式）——网页预览才能显数。全成本按原版链条重算（变动+加工÷1.13+装卸÷1.06 的不含税合计 ×1.13 ＋ 管理费），与台账「含税不含运」同构；数值差异仅来自台账费用参数与源表不同（对账行可见）。原版把加工费拆制造/工厂/运输、台账合并存一个数，故加工费归入制造费用、工厂/运输 N/A 占位——脚注写明。

## 底色（业务方逐条定）

「颜色可换，但有色分布照原版」：**灰**＝B 列分区标签 + C 列类别 + ①表头/小计；**费用段数据区不铺底**（只 C 列留灰）、6~10 右侧说明格不铺底；**黄**＝6~10 五行值格统一；**取消**加工费/装卸费单价的琥珀高亮。

## 预览渲染修正（`_xlsx_to_html.fmt`）

显式小数位格式优先于整数快捷路径（1.0 按 `0.0000` 显 1.0000，同原版）；小数位数按小数点后**连续 0** 计（会计格式多段 `;` 不再数错）。

用原版同一份数据本地生成对照，逐版发业务方确认（v1→v7）；kernel / router py_compile 过。
