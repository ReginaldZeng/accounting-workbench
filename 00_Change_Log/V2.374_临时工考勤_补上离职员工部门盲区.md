# V2.374 · 临时工考勤 · 补上离职员工的部门，钉钉路线不再有归属盲区

**日期**：2026-08-29　**分支**：main

Reginald：「我还是偏向于用钉钉API」。那就把钉钉这条路的盲区补上，而不是让他退回手工表。

## 我上一版判断错了

V2.373 我写「离职员工在钉钉查不到部门，215 人的『归属不符』没法查」。
**这个结论是错的**——当时抽样抽到的是几个测试账号（"test"、"杨宥丞"），
拿真实的临时工再试，`sys00-dept` **12/12 全有值**：

```
艾霞    结算归属=锦绣   钉钉部门=锦绣人力
陈沙    结算归属=天募   钉钉部门=天幕人力     ← 正是要查的那种不符
```

教训：字段拿不到就说拿不到，但**抽样要抽真实的目标人群**，别拿名单头几条了事。

## 做了什么

`build_roster` 取离职员工时把 `sys00-dept` 一并取回来存进缓存。
顺带发现并修掉一个更隐蔽的问题——

**缓存结构变了却没换版本号。** 加完部门字段后重跑，盲区还是 215，
因为 `roster_for` 用的是**加字段之前存的**那份花名册缓存，被当成好的接着用。
现在 `_ROSTER_VER` 一变，旧缓存一律不认、自动重建。
==缓存里存的东西结构一改，就必须换版本号==，这条已写进代码注释。
