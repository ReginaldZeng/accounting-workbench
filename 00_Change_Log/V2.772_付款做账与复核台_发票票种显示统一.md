# V2.772 付款做账 / 复核台第③步：发票「类型」显示统一成 票种 + 特定业务

日期：2026-10-03

## 问题
用户截图：发票明细「类型」一列有的写「货物运输服务」、有的写「电子发票（增值税专用发票）」，看着奇怪。
原因：发票管家的 `type_label` 存的是票面左上角那行字；数电票带「特定业务」的（货物运输服务/建筑服务…）存的是特定业务名，不是票种。
物流这边直接拿它当类型显示，于是票种和特定业务混着出现（这几张其实都是专票）。

## 改动
- `routers/logistics_voucher.py`：`_inv_type_text(inv_type, type_label)` → (全称, 简称, 特定业务)。票种一律看 `inv_type`
  （special=专票 / normal=普票 / 其余按发票管家 `INV_TYPE_LABELS`），`type_label` 属于发票管家「特定业务」清单的单独给出。
  `_invoices` 返回 `type`(全称，如「增值税专用发票（货物运输服务）」)、`type_short`、`type_tag`。付款做账预览、计提更正单用全称，自动跟着变。
- `LogisticsInvCompare.jsx`：发票明细列头改「票种 · 特定业务」，显示「专票 · 货物运输服务」/「专票」/「普票」。
- 没动发票管家的数据和识别逻辑。
