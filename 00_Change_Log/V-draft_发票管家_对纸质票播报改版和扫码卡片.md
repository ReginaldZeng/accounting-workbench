# V-draft 发票管家：对纸质票播报改版（先判主体）＋电脑上扫一张弹一张卡片（未上线）

- 日期：2026-10-14
- 作者：Claude Opus 5.5
- 起因：用户问对纸质票时「不是这个主体 / 不是这个月份 / 就是这一批」怎么播报、速度多少。查下来原来**不判主体**：对「深圳星期零 10 月」清单扫到孝感星期九 10 月做账的票会念「10 月的」，听着像这一批；同主体同月但没进清单的票也念「10 月的」。用户定：按我提的方案改、语速 1 倍；电脑扫的时候要有动画、扫到下一张自动关。

## 改了什么

**播报（对着认证清单扫）**，先判主体、再判月份、最后说原因：

| 情况 | 念 |
|---|---|
| 就是这一批 | 不念，只「嘀」一声 |
| 又扫了一次 | 重复 |
| 别的主体 | 主体简称＋月份，如「孝感星期九，10 月」；没做账/没审核/普票就是「孝感星期九，没做账」等 |
| 同主体、普票 | 普票 |
| 同主体、别的月 | 9 月 |
| 同主体、没审核 / 没做账 | 没审核 / 没做账 |
| 同主体同月但没进这份清单 | 勾过了 / 导出过 / 票总管 / 不抵扣 / 不在清单 |
| 系统里没有 | 没有这张 |
| 不是发票码 | 不是发票 |

- 语速电脑、手机都改成 **1 倍**（原来 1.3 / 1.25）。对上的电脑「嘀」一声，手机「嘀」一声＋短震。
- 按票夹对（不是清单）的照旧：对上嘀一声，不在选中票夹里念「不在这里」。

**电脑上的扫码卡片**：每扫一张，窗口正中弹一张大卡片——对上了绿卡打勾＋外圈扩散（大字「这一批」）；重复黄卡晃一下；别的主体/别的月橙卡滑进来（大字就是念的那句）；没有这张红卡抖一下。**扫到下一张自动换成下一张**，点一下也能关。手机扫的电脑上也弹（标「手机扫的」）。

接口：扫码结果多回 `show{tone,big,small}`；点验全貌多回 `last`（最近扫的那张，电脑据此弹手机扫的）。主体判断用清单记下的购方税号，票面没读到税号的按抬头对本公司设置。
