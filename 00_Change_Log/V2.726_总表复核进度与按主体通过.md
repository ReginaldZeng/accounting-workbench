# V2.726 物流复核总表看得出复核进度；可按主体标「通过 / 有疑问」

日期：2026-10-01

## 起因
用户："这一页我现在不知道哪些是我已经复核通过的"；"有时候我们只是某个主体通过了，另外两个主体还有疑问"。
原复核状态只认整家「确认通过并登记」，做到一半看不出。

## 改动
- 新表 logistics_review_subj(承运商/账期/主体/status ok|question/疑问/人/时间)，`POST /api/logistics-review/subject-mark`(空=撤销，锁月不可改)。
- 逐笔计提页每个主体组头：「✓ 本主体通过」「? 有疑问」(写一句疑问)，标后显示标记人，可改/撤销。
- 总表：主体三格按标记着色(通过浅绿 ✓、有疑问浅橙 ?，悬停看疑问)；复核状态分档 已登记 / 主体全通过·待登记 / 复核中 / 账单已传 / 未传账单 / 未配，
  下附进度小字(n/N 主体通过 · n 个有疑问 · 确认 n 单 · 解释 n 笔 · 更正 n 笔)；表头上方按状态筛选；已登记整行浅绿。
