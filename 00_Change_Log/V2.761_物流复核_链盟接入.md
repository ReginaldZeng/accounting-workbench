# V2.761 物流复核：链盟接入（读 .xls / 前缀认列 / 吨换千克）

日期：2026-10-03

## 背景
8 月请款单附件全量拉档后盘点：链盟 473,215 占 8 月物流请款约一半，账单是老格式 .xls，复核台读不了。

## 改动
- `kernels/logistics_intake.py`
  - `open_book`：xlsx 走 openpyxl；OLE 头(D0CF11E0)的老 .xls 走 xlrd，套成同样的 worksheets/iter_rows 接口。
  - `find_col`：列名以 `*` 结尾按前缀认（「蜜雪卸货费/0.45元/箱(含6%税,单独开票)」）。
  - `wt_scale`：账单重量单位换千克（链盟「重量/吨」×1000），核量统一比金蝶 kg。
  - `summary_cols`：合计/汇总行标记可看前 N 格（链盟「汇总」在 B 列）；默认 1，其他家不变。
  - `merge_doc`：同一单号的几行并成一单（金额/箱数/重量/分项相加）。链盟一张出库单分两车送同一仓，第二车单号空、只写卸货费，配 `doc_ffill` 沿用上一行单号后并单，才能和金蝶整单重量比。
- `routers/logistics_review.py`：链盟进 `_BOX_CARRIERS`（有账单重量按重量核，比金蝶出库 kg）。
- 取数说明（库里 logistics_intake_spec，非代码）：链盟三张主体页 detail，主体取「主体」列、标注取「类型」列，
  金额=物流费用+其他费用+蜜雪卸货费（分项记 sub_fees），第二车没写单号的沿用上一行单号并单。

## 验证
- 8 月链盟账单解析：并单后 66 张单，合计 473,215.00 = 请款；按主体×类型 36,500 / 409,795 / 7,100 / 18,420 / 1,400 与复核簿一致。
- 逐笔对计提：三主体差异 0。
- 回归：迅鸽(starfield 32,897.89 / kikiherb 1,053.24)、恒茂 78,733.53、顺丰速运 960 解析结果与改前一致。
