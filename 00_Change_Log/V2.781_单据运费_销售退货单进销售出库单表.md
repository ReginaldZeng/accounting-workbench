# V2.781 单据运费：销售退货单也进「销售出库单」这张表

日期：2026-10-03

用户：「同时销售退货单的是不是也可以加进来」。

## 实证(2026-08)
金蝶销售退货单 248 张：对外 124 张（RK 开头，深圳星期零，B2C 销售退货单）+ 内部 124 张（XSTHD 开头，孝感对深圳的内部镜像，客户=内部主体）。
迅鸽账单里 114 笔退货服务费（每笔 2 元，共 228）全部对得上 RK 单号。

## 改动
- `routers/logistics_review.py`
  - `_month_outstock` 加取 `SAL_RETURNSTOCK`（字段名和出库单不同：客户 FRetcustId、基本数量 FBaseunitQty、仓库 FStockId；取不到则降级成没有退货，不影响出库单）。
    退货单 `kind=ret`，销售额、数量记负数（冲减）。内部交易同一口径剔除。
  - `/outstock-freight`：行带 `kind`；退货单不算费比；「有运费/没有运费/只有装卸费/什么都没有」只对出库单统计和筛选；
    统计加 `n_out / n_ret / amount_ret / fee_ret`，销售额合计＝出库减退货。
- 前端：类型列退货单标「退货」、整行淡紫底；运费格退货单不标「没有运费」；第一张卡片显示「出库单 N ＋退货 M」及冲减销售额；页签说明带上退货单。
- 单据类型下拉自动多出「B2C销售退货单 / 标准销售退货单」，可单独筛退货。
