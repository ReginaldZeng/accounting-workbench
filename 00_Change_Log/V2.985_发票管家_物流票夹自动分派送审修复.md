# V2.985 发票管家：物流票夹自动分派与送审修复

日期：2026-10-16

物流接入先创建的票夹未分配审核人，钉钉扫描因票夹已存在而跳过，且物流来源不在自动送审范围，导致附件和发票齐全仍停留收票中。

- 已有的物流收票中未分派票夹继续跟踪审批节点；到达启用审批人后复用票夹并补分派。
- 打开已有未分派票夹时补分派，已分派票夹不更改归属。
- 物流来源纳入自动送审，未分派不送审，继续执行原完整性、重复票及金额检查；退回单不自动重送。
- 回归覆盖复用不重复建票夹、补分派、金额不齐保留、已分派不覆盖、退回不自动送审。

验证：3 项针对性测试通过；完整发票 API 60 项中 59 项通过。手机配对 test_09_pairing 的提示文案断言在未修改基线同样失败，与本次修改无关。
