# V2.904 导出复核表：合起来比的几张单，差异按合计的账单量算

- 日期：2026-10-11
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 物流账单复核台 › 导出复核表（「复核明细」页）

## 起因

用户看恒茂 8 月的导出：FBDR075386 账单量 6,642 箱、金蝶核对量合计 7,622、差异 −980，「量的复算」却写「一致」；
下面 FBDC075377 账单量 980、金蝶 7,622、差异 −6,642，也写「一致」。问：「这些为什么会判断一致」。

## 原因

这两张是同一笔调拨：FBDR075386 是调入单、FBDC075377 是它对应的调出单，金蝶里是同一批货 7,622 箱。
账单把这批货分开写在两个单号下（6,642 箱 ＋ 980 箱）。系统是把两张**合起来**比的：6,642 ＋ 980 ＝ 7,622，和金蝶一致——结论没错。
错在导出表：差异那一格只拿了这一张自己的账单量去减金蝶合计，所以显示 −980 / −6,642，和旁边的「一致」对不上。
「计费方式」那一列其实写了「和 FBDC075377 是同一笔调拨，合起来比」，但不显眼。

## 改法

合起来比的单，差异写成 `=(本单账单量 + 另一张的账单量) − 金蝶核对量合计`，两张的差异都是 0；
换算系数、量的复算也按合计算，都是公式，点进去能看到加的是哪一格。凑不出系统比的那个合计的，不写公式。

## 改动

- `backend/routers/logistics_review.py`：`_box_docs` 合并段带出 `grp_others`；导出的差异、换算系数、量的复算按合计写。只改后端。

- 全表扫了一遍「差异不是 0 却写一致」的：恒茂、极鲜达、链盟都没有了。
