# V2.435 · 核算表网页预览美化：数字格式化 + 搬样式（加粗/底色/对齐/列宽）

**日期**：2026-09-05　**分支**：main

Reginald：V2.434 的预览「有点难看」——原样值太素：长小数（0.386315789…）、税率没成 %、xlsx 的配色/加粗/列宽全丢。

## 改动（`_xlsx_to_html` 升级）

- **数字按单元格 number_format 格式化**：`0%` → 百分比（13%）；`#,##0.00` → 两位（10.34）；General 小数 → 最多 4 位去尾零（0.3863）；**整数不加千分位**（ERP 编码 300600092 不被断成 300,600,092）。
- **搬样式**：加粗（font.bold）、字色、纯色底色（fill solid，跳白）、水平对齐（数字默认右对齐），跨列的标题/长说明整段展开不截断。
- **列宽**：读 `column_dimensions` 宽度换算 px 出 `<colgroup>`。
- 外观：白卡片 + 圆角 + 细边框，接近真版排版。

隔离测试覆盖：小数收位 / 百分比 / 整数不加千分位 / 两位格式 / 加粗 / 底色 / 列宽 / 跨列展开——全过。后端 py_compile 过。
