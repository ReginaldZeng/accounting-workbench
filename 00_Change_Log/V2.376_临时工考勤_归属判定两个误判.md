# V2.376 · 临时工考勤 · 「归属不符」的两个误判，盲区从 15 归零

**日期**：2026-08-29　**分支**：main

Reginald 指着「另有 15 人的『归属与打卡不符』这一项没查」问是什么意思。
查下去发现**这 15 人根本不是查不到部门**——是我判错了。两个 bug 都是我自己的：

## ① 把正常部门名当成了「没有部门」

V2.373 我给 `agency_of_dept` 加了「末段要带『-』或以『人力』结尾」的条件，
想的是别把整条路径当成部门名。结果钉钉给的是**部门树叶子名**，本来就没有「-」：

```
「浮动组」    → 空   ❌ 该返回「浮动组」
「中段车间」  → 空   ❌ 该返回「中段车间」
「外围」      → 空   ❌
```

于是**该报的「归属不符」没报，还被算进「没查成」的人数**——15 人里有 12 个是这么来的。
去掉那个条件：末段非空就返回它。

## ② 重名合并的人，部门取错了账号

同一个人在钉钉有两个账号时（离职再入职），我死取 `账号[0]`——
而离职那个账号常常没部门，取到它就等于把部门丢了（陈双珍、李苏、马福 实测）。
改成**取第一个有部门的账号**。

## 结果（2026-06）

| | 人力导出打卡表 | 钉钉取数 |
|---|---|---|
| 同名风险 | 0 组 | 0 组 |
| 归属不符 | 16 人 | **16 人** |
| 归属无法核对 | 8 人 | **0 人**（原 15） |
| ⚠ 打卡撑不起上报 | 4 | 4 |
| ⚠ 报了工时没打卡 | 0 | 0 |

**两条路现在结论完全一致，而钉钉侧的盲区反而比人力导出还小**（0 vs 8）。

```

锦绣→浮动组 2 ／ 天幕→中段车间 2 ／ 锦绣→小料长期临时工 2 ／ 锦绣→外围 1     ← 调配名目，多半正常
```
