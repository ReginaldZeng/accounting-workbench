# V2.400 · 合同外调整：本期奖惩「已核对」确认（空期也能签）

**日期**：2026-08-29　**分支**：main

Reginald（⑦合同外调整页）：「这里是不是要做一个确定本期没有奖惩情况」。

## 加了什么

⑦合同外调整页底加一枚**period-级确认**：

- **本期有奖惩**（如 2026-07 一笔 ¥-5）：「确认本期奖惩已核对」——本期 N 笔逐笔看过、该附单据都附了，签个正向记录。
- **本期一笔都没有**：「确认本期无奖惩情况」——正向签一句「核过、确实没有」，
  而不是只剩工具那句被动的「没找到」。这正是 Reginald 要的。

跟逐笔「确认无误」是两回事，不冲突：逐笔管「某一笔像有问题但没事」，
这枚管「整期奖/罚/补贴我看过了」。

## 怎么记

存确认人 / 时间 / 指纹（笔数|净额|异常|存疑）/ 摘要。奖惩数据一变（重跑、换源），
指纹对不上，这枚确认**自动失效**、提示重新确认——跟⑧复核结论那枚签一个道理。
确认 / 撤销都写审计日志。空期的指纹是 `0|0|0|0`，签「本期无奖惩」。

新增 `GET/POST /api/tempatt/adjsign` 与 `POST /api/tempatt/adjsign/undo`，
与⑧复核结论的 signoff **各用各的 key，互不干扰**。七项接口测试全过、测试期清库无残留。
