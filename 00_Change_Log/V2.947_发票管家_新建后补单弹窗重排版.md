# V2.947 发票管家：新建后补单弹窗重排版

**起因**：用户 2026-10-13 发了线上「新建后补单（财务代填）」弹窗的截图，说「这一页也要重新设计好看点」。
原来的样子：找到付款单后是一张三栏小格子，申请人、公司主体这些被挤成两三个字一行，事由塞在右下角窄窄一条；
下面表单三栏排不齐，「预计到票金额」单独掉到第二行。

**改法**（只动页面排版，不动接口和数据）：

- 找到付款单后的信息卡，照 V2.916 改过的后补单详情那一套：
  上面一行**收款方**（大字）＋审批类型和编号，右边**付款金额**（大字）；下面两张小卡「付款单」（申请人、部门、公司主体、ERP 单号）
  和「收款方」（户名、开户行、银行账号）；**事由**单独一块、占满整行，很长的先收起、点了再展开。ERP 单号填的是「无」的显示成「—」。
- 表单改成整齐的两栏：发票种类｜税率，预计到票金额｜预计到票日期，财务接收人｜备注，资料占整行。
  发票种类三个选项铺满一栏。预计到票日期下面加四个快捷日期：7 天后、15 天后、本月底、下月底。
- 弹窗稍微加宽（820 → 880）。

**顺手修的**：V2.916 改详情时，详情里「备注」那一段的样式名和页面上的提示条重名了，结果后补池里所有黄条、绿条提示
（比如「这张付款单已经附了发票，确定还要登记后补吗？」）文字贴着左边、没有留白——用户截图里就是这样。把备注那段的样式改了名，提示条恢复正常。

**验证**：用假数据渲染看过改后的弹窗（上半、下半各一张）；前端回归 `tests/qa_inv_frontend.cjs` 没有新增失败。没验：线上真数据。

**文件**：`frontend/src/views/InvLater.jsx`、`frontend/src/views/inv-later.css`。
