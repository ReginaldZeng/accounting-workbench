# V2.377 · 临时工考勤 · 「归属不符」分两种讲，要紧的排前面

**日期**：2026-08-29　**分支**：main

Reginald 看着结算风险那一页说「没看懂什么意思」。

翻回截图一看，**这怪不得他**——16 条里每一条的说明**一模一样**：

```
对不上不等于错——打卡部门可能写「浮动组」这类调配名目，但长期不一致该问一句。
```

可这 16 条里混着两种性质完全不同的情况，一句话糊过去，等于让使用者自己去分辨。

## 现在分开讲

**⚠ 两边都是派遣方（9 条）——钱可能付错家，要紧**

```
毛志勇   结算算 华顺 的钱 / 考勤挂在 锦绣    工时 99.0
李胜平   结算算 天幕 的钱 / 考勤挂在 恒祺    工时 33.0
…
说明：两边指向的是**两家不同的派遣方**——华顺 和 锦绣 都是在用的派遣方。
      这个人的钱算在华顺头上，考勤却挂在锦绣，**可能付错了家**。建议找人力问清楚再放过。
```

**△ 打卡侧是车间/调配名目（7 条）——多半正常**

```
程爱莲   结算 锦绣 / 打卡「浮动组」        工时 225.0
鲁保军   结算 锦绣 / 打卡「外围」          工时 263.0
…
说明：「浮动组」不是派遣方，是车间或内部调配的名目。多半正常——
      确认确实是内部调配就点「确认无误」，以后不再报这一条。
```

判据很直白：**打卡那侧的名字在不在本期结算表用到的派遣方名单里**
（本期是 华顺/天幕/广才/恒祺/成达/鑫路达/锦绣）。在名单里＝两家派遣方对不上；不在＝车间名目。

顺带把主行文案从「结算 华顺 / 打卡 锦绣」改成「**结算算 华顺 的钱 / 考勤挂在 锦绣**」，
不认识这个工具的人也能一眼读懂，并把要紧的 9 条**排到前面**。

## 记一笔

同一个列表里放性质不同的东西、却共用一句说明，等于把分辨的活推给使用者。
