# V2.690 复核台重构为三步流：逐笔计提复核 → 逐单核量 → 确认登记；导出复核表

## 需求（用户梳理后定的骨架）
从总表(供应商×主体)出发、以计提为主线逐笔复核；每笔列 主体/费用类型/产品线/产品类型/部门/凭证号/计提金额/税率/账单金额/差异/备注（备注＝差异解释）；
复核要点按供应商放在逐笔页顶部（每家核法不同）；仓储费等无单据费用不逐单；确认后登记"已复核"（整月一家一次，锁当月）；输出复核表。

## 后端
- 新表：`logistics_review_sign`(登记：carrier/period/reviewer/signed_at/snap_json) / `logistics_review_line_note`(逐笔差异解释，line_key=凭证号+科目+维度) / `logistics_review_carrier_pts`(供应商复核要点)。走 store.TABLES → create_all 自动建。
- `_accr_entries`：金蝶费用借方逐分录（不聚合），维度加 部门(FFLEX5) 与 产品项目单列；**税率按凭证**＝同凭证 2221.01.07 ÷ 费用合计（实测五张都 9%），含税＝费用×(1+税率)，替代原全月毛率。只有 2221.01.06 的税额调整凭证不计入、另列 adj 提示。
- `_build_lines`：账单先按 主体×费用类型×产品线 配到笔(level=biz)，配不到退回按 主体×费用类型 挂组首笔(level=group，跨行合并)，账单有计提无单独成行，每组一行小计；账单侧优先汇总行。账单产品线 `_bill_biz`＝bizline 列→费用标注解析→研发费用TOB/TOC→同义归一(其他零售/山姆零售→零售)。
- `_fee_norm` 加"研发"→研发外购；规范类加研发外购。
- 端点：`GET /lines`(老 /accrual 同指) · `POST /line-note` · `POST /carrier-points` · `POST /sign` · `POST /unsign`；`_locked` 锁月：已登记月份 doc-note/doc-classify/line-note 返 409。总表回 `signed`。
- 导出 sheet1 改「复核表」：状态/复核人/时间 + 复核要点 + 逐笔 11 列 + 组小计 + 合计，横向一页可打印。原账单一格多单号按首单号匹配复核列。

## 前端
复核台详情改三步：① 逐笔计提复核（要点编辑 + 逐笔表 + 差异解释）② 逐单核价核量（原表，锁月时禁改）③ 确认与登记（汇总卡 + 登记/撤销 + 导出）。总表加"复核状态"列。

## 数据
极鲜达 140 行标注回填为原账单"类别"（原来是 sheet 名），src_sheet 记 sheet 名；6 行多单号行补进 raw_bills JSON。

## 遗留
_build_recon/_accr_lines 旧版保留作对照，稳定后删；解析器对一格多单号仍跳行。
