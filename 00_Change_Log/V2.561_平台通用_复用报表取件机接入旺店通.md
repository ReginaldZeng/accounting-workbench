# V2.561 平台通用：复用报表取件机接入旺店通

- 既有财务报表取件计划任务在完成原报表拉取后，顺带运行旺店通公盘扫描扩展，不新增计划任务、设备登记或 Python 环境。
- 沿用 `pull_reports.ini` 的服务器地址与 `pull_token`，新增库存管理、销售出库明细两个可选公盘目录；未配置时完全不影响原取件流程。
- 每分钟自动扫描，也响应工作台手工扫描请求；只读取稳定写入的最新 `.xlsx`，成功文件以签名记账防重复，不删除、不移动公盘原件。
- 旺店通扩展固定通过 HTTPS 访问 BP 工作台，失败只写独立日志，不会中断财务报表取件。
- 两份 PowerShell 脚本通过 Windows PowerShell 语法树解析，并保留 UTF-8 BOM。
