# V2.721 迅鸽退件表每张退货单挂「退货服务费」（单价取月结清单）

日期：2026-09-30

## 起因
V2.720 后退货服务费(228)只在汇总页，退件表 114 张 RK 退货单没挂钱；用户："挂"。

## 改动
- 解析器 spec.per_row_fees={分项名: 汇总页费用项}：单价=月结清单该项 金额÷数量，每行(一单)挂一份，记入 sub_fees 与 amount。
- 迅鸽 spec(DB+种子)：退件表 per_row_fees={退货服务费: 退货服务费}。
- 结果：starfield 111 张×2=222、kikiherb 3 张×2=6，与汇总页一致。
- 退件表主体改固定「深圳星期零」(原取「公司」列=星期零-Starfield，与汇总页对不上，可逐单算不进)；搬运费改固定「孝感星期九」+标注 成品仓储-电商(汇总页孝感「卸货」，计提记孝感仓储费)。
