# V2.800 付款做账：装订对照清单 + 凭证号贴条

日期：2026-10-05

用户：「如果我批量生成了，那就没人在付款单上写凭证号了，这样装订的同事是不是就不好区分了」→「你做来看看」。

批量做完后凭证号只在系统里，纸质付款单上没有。系统记着每张请款单对应的金蝶付款单号、凭证号、账簿，纸质单上印着钉钉审批编号，把这层对应打出来即可。

- `LogisticsVoucher.jsx`（纯前端，数据就是列表里的做账记录，不另取数）：
  - 列表上方新增「装订用」一栏：选凭证月份 →「打印装订对照清单」「打印凭证号贴条」。按当前筛选（状态/搜索）出。
  - **装订对照清单**：A4 竖版，按主体 × 凭证月份分页、按凭证号排序；列＝凭证号 / 付款日 / 供应商(编码) / 付款金额 / 钉钉审批编号 / 金蝶付款单号 / 发票张数 / 计提更正单 / 已装订(□)；表下合计、用法说明、装订人签字。
  - **凭证号贴条**：A4 一页 21 个（3×7，虚线裁切），每个＝大号凭证号、主体、凭证月份、供应商、金额、审批编号、付款单号；有更正单的标「附更正单」。剪下贴在纸质付款单右上角，不用手抄。
  - 主体更正在原主体账簿建的红冲凭证单列一条（红色），写明「无纸质付款单」、只附计提更正单 ①，不计入金额合计。
  - 金蝶里别人已经做过凭证的（不是本系统写的），凭证号取发票管家同步到的，也进清单，标「金蝶已有」。
  - 批量做完的结果条上加「打印本批装订清单」「凭证号贴条」。

验证：用线上真实列表数据本地渲染了两张样张（真实已做账 3 张；其余用「可做账」的单配示意凭证号看满页效果）。线上页面的按钮未在真机点过。

上线：纯前端，不用重启。
