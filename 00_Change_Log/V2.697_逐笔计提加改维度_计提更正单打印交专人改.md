# V2.697 逐笔计提加「改维度」，导出《计提更正单》打印交专人改

日期：2026-09-30

## 起因
极鲜达孝感星期九 记-557(装卸费 4,500 含税)/记-569(出库运费 43,600 含税) 金额和账单对平，但计提维度记错——用户定"应该是入库运费"。
用户口径：**我们不去金蝶改，只备注说明怎么改，打印出来，专人去改**。原页面只有差异≠0 的行能写备注，对平的行没处写。

## 改动
- 新表 `logistics_review_line_fix`(create_all 自动建)：carrier/period/line_key + 应改为 to_acct/to_fee/to_dept/to_biz + memo + snap_json(登记时原分录快照：主体/凭证号/科目+科目名/费用项目/部门/产品线/金额)。
  金蝶改好后原行键会变，更正单仍按快照打印；页面标「金蝶里原分录已变，可能已改好」。
- `POST /api/logistics-review/line-fix`：一次可登记多笔(line_keys)，五项全空=撤掉；已登记复核的月份锁定。只重挂更正，不作废逐笔缓存(不重读金蝶)。
- `_build_lines`：每笔带 `anc`(同一账单金额的锚点行键)、`fix`；结果带 `fixes`。计提取数加科目名。
- 前端逐笔表每笔计提「差异解释」格加「改维度」(淡显，悬停变亮)；点开在该账单金额合并格下方展开编辑框：
  费用项目/科目/部门/产品线(下拉可选也可手填，显示原值，空=不变)+说明；同一账单金额下几笔默认一起改；
  改成入库运费而原科目是 6601 时提示科目(孝感历来工厂/小料入库 5101、代工厂/零售/鲜食 6401)，点一下填上。
  已登记的行显示橙色「待更正 → …」，表下汇总「计提维度待更正 N 笔」。
- 导出：复核表 备注列加「【待更正】改为 …」(浅橙底)，表尾一行提示；新增第二页《计提更正单》(横向一页宽，原记账 vs 应改为两组表头，不变的灰字，底部登记人/更正人/日期/复核人签字)。
- 不影响对账：更正只是登记，逐笔配对、差异、可逐单都不变。
