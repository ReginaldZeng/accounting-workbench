# V2.848 付款做账：撤掉凭证号贴条；「扫码查凭证」开单独的只读权限给装订的同事

日期：2026-10-06

用户梳理纸质单的流转：钉钉审核 → 出纳付款 → 纸质付款单到实习生手里；付款凭证由工作台做、财务经理审核。凭证号和计提更正单怎么回到纸质单上？
用户定：「实习生我可以给账号，但是这个后面可以规划集成在另一个入口而不是混在这里面」「不需要贴条，实习生扫码知道是哪个凭证，标注一下就好」。

改动：
- 撤掉「凭证号贴条」（付款做账页装订那一条和批量做完后的链接，连同生成代码）。装订对照清单、打印本月计提更正单留着。
- 新权限点 `voucher_scan`「扫码查凭证（装订用·只读）」：默认不给，要在账号页勾。扫码的三个接口（扫码 / 拍照 / 钉钉扫一扫配置）原来挂在「上传物流计提表」这一项下，给了就等于能做账；现在有做账权限的照旧能用，只勾「扫码查凭证」的也能用，但进不了做账、上传。
- 实习生用法：账号只勾这一项，手机钉钉打开 `#/vscan`，扫纸质付款单右上角的二维码 → 显示主体、凭证号、制单人、审核人（没审核的写「还没审核」）、要不要附计提更正单 → 手写标到单子上。

没做的（用户说后面另开入口再规划）：单独的装订入口、贴没贴过的留痕、实习生自己打印计提更正单（现在仍由有做账权限的人在付款做账页打「本月计提更正单」交给他）。

验证：本地用只勾 `voucher_scan` 的账号测权限判断——扫码可用，上传 / 录入金蝶不可用；默认权限不带这一项。没有用真的实习生账号在线上试过。

上线：后端有改动，需重启。
