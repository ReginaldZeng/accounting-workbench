## ① 那个✔为什么那么大

不是我把它做大的，是一条选择器**误伤**：

```css
.tempatt .ta-filter select, .tempatt .ta-filter input { height:32px; min-width:150px; … }
```

`input` 没排除 `[type=checkbox]`，于是「只看异常」那个勾被撑成 **150×32 的蓝色大块**。
加上 `:not([type=checkbox])` 就好了。

顺手把它做成一枚**小胶囊**——勾上变主色描边，跟旁边的判定档按钮同一个视觉重量，
不再是一行说明文字后面挂个复选框。原来那串长说明（撑不起上报 / 报了工时没打卡 / …）
移到 `title` 里，悬停可见，不再占半行。

> 这类「按元素类型一刀切」的样式最容易误伤：`input` 底下还有 checkbox、radio、file，
> 它们本来就不该有输入框的尺寸。

## ② 筛选和判定档并到一行

原来筛选框一行、判定档按钮又一行，逐日明细光是表头就占掉两行。
给筛选组件加了个插槽，判定档按钮塞进同一行，中间用竖线隔开：

```
部门[全部]  归属[全部]  姓名[     ]  清空筛选  (只看异常) │ 全部1632 仅不一致4 ⚠撑不起4 ◇未计工时17 △仅1次卡17 ✓撑得住1594      筛出 N/1632 人日
```

放不下会自动折行。逐人核对那一页不传判定档，样子不变。
