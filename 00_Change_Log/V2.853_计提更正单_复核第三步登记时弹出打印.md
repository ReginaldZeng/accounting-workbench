# V2.853 计提更正单：复核台第③步登记时自动弹出预览（撤掉「保存到金蝶」后的自动弹）

日期：2026-10-06

V2.852 把「点击保存的时候弹出打印提醒」理解成了付款做账的「保存到金蝶」。用户纠正：「保存到金蝶？我指的是审批钉钉OA的时候噢，就是第三步那里的」——是复核台第③步「确认通过并登记已复核」：登记完就去钉钉批 OA，纸质付款单这时还在手里。

改动（纯前端）：
- 复核台第③步：点「确认通过并登记已复核」成功后（登记制那几家的登记也一样），这家这月的请款单里有要红冲更正 / 尾差 / 记错主体的，自动弹出计提更正单预览，点「确认打印」。提醒语：「已登记复核。××有 N 张请款单要附计提更正单：现在打出来，审批钉钉时订在纸质付款单后面。」没有要更正的不弹。
- 第③步「发票与暂估」卡片头上加「打印计提更正单（N 张请款单）」按钮：已经登记过、或想重打的随时能打。
- 付款做账：撤掉 V2.852 加的「保存到金蝶成功后自动弹更正单」（单张和批量）；手动打印的按钮都还在，预览窗照旧。
- 审批时还没有付款凭证，更正单上凭证号是一道横线，做完账由装订的同事在「凭证装订」扫码后手填（V2.851 已做）。

验证：编译通过；预览窗 V2.852 已在浏览器里渲染确认过。**第③步登记后自动弹这条路没有在线上真走过**（线上现在要更正的是迅鸽两张，迅鸽 8 月还没登记复核）。

上线：纯前端。
