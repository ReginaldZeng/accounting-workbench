# V2.643 单据运费·销售出库：迅鸽8月落库 + 明细表按单据分页/搜索

- Date: 2026-09-28 | Author: Claude Opus 4.8

## 背景
「单据运费·销售出库」tab 一直空——它要的是已解析进中间表的销售出库明细。迅鸽 8 月销售出库=每张 XQLCK 单挂快递费，共 5717 张单。

## 做了什么
- **迅鸽 8 月销售出库运费落中间表**：从已签核价核量结果《迅鸽_2026-08_核价核量结果.xlsx》按单据取「账单快递费＋加收」，聚合 5717 张 XQLCK 单，合计 **16256.05 元**（＝该月快递费计提额，分毫一致）。写为 bill_lines：grain=detail / review_mode=audit / fee=销售出库费用 / carrier=迅鸽 / subject=深圳星期零 / bizline=电商 / 一单一行。孝感星期九无快递，全归深圳星期零。
- **doc-freight 端点改为按单据分页**：销售出库单可达数千张，旧实现每次翻页把全部单据的物料明细都去金蝶拉一遍会超时。改为：总运费/单据数先从中间表算好（不碰金蝶），排序后**只取当前页那批单据去金蝶取物料**；返回 `pages` 总页数。单据号搜索先按单号过滤再分页，物料名/编码在本页已取物料内二次过滤。
- **前端**：明细表加搜单据号框＋上一页/下一页分页条（每页 80 张单）；表头统计改「N 张单据 · 运费合计」（行数按页动态）。

## 口径
- 销售出库 tab：每张 XQLCK 单的快递费按基本单位数量摊到该单物料（金蝶 SAL_OUTSTOCK 实时取物料/往来/销售额），单位运费=摊得运费/基本数量，费比=摊得运费/销售额。
- 快递费本是逐单一笔（一单一 XQLCK），摊到该单的 SKU；多 SKU 的单据会拆成多物料行、加回等于该单快递费。
