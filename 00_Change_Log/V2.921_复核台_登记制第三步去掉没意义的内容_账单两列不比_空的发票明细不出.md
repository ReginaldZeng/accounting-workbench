# V2.921 复核台：登记制第③步去掉没意义的内容——账单两列不比、空的发票明细不出

- 日期：2026-10-12
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 物流账单复核台 › 第③步 确认与登记（登记制承运商：禾享、路凯这类）

## 起因

用户打开禾享 2026-08 的第③步，截图说：「这个页面好乱的感觉」。

对着截图看，乱在这几处：

1. **下面那张大表里有一格红字「账单没有这一类 −1,322.00」**，合计行也是红的 −1,322.00。禾享是登记制，本来就没有账单，这个「差」不是问题，但红字看着像出错了。
2. **最下面一张空表「发票明细 0 张」**，只有表头和一句「票夹里还没有发票」。
3. **最上面那张卡里一句话指向不存在的东西**：「税按下面的税率挂暂估进项税」——费用凭证已经认定了，下面根本没有填税率的表。
4. 大表上方那段说明是写给有账单的承运商看的（「先看蓝底的账单两列…」），对登记制不适用。

## 改法

只动登记制的第③步和「没有发票」的情形，普通承运商的页面不变：

- 账单两列（账单金额、账单−计提）登记制一律显示「—」，鼠标停上去说明「登记制：这家没有可逐单核的账单，这两列不比」；合计行同样。
- 一张发票都没有时，「发票明细」那张空表不出；有发票了自然出现。
- 大表的小标题登记制改成「费用凭证对发票」，说明改成一句适用的话。
- 最上面那张卡：费用凭证已经有了的，「税按下面的税率…」那半句换成「在下面『发票与暂估』里确认发票后补」。

## 没动的

三张卡的先后顺序、每张卡的结构没动。这次只是把没意义的字和空表去掉；如果去掉之后还是觉得乱，下一步是把登记制的第③步重排成一张清单（费用凭证 → 和请款比 → 发票 / 后补 → 做账），那个要先出样机给用户看。

## 改动

- `frontend/src/views/LogisticsInvCompare.jsx`：新增 `reg` 属性；空的发票明细不渲染。
- `frontend/src/views/LogisticsReview.jsx`：登记制第③步传 `reg`；费用凭证卡那半句。
