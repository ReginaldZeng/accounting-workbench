# 发票管家：初审后钉钉评论票不再自动接入

本次替代 V2.948 的“初审后评论票自动接入”规则，也取消此前曾保留的财务手动查找例外。保留财务初审判断、初审前补票能力及历史票展示。

## 最终口径

- 审核前可在钉钉补发票或登记后补，二者之一合格才审核；表单附件、初审前已经存在的评论附件照常接入，普通初审前接入和票齐自动送审不变。
- 审核后不再对钉钉流程内新增内容审核：自动初次拉取、定时回扫和手动 `flow_recheck(manual=True)` 均不下载、不关联后补单、不送审。
- 审核后的后补票只能由申请人通过发票后补单上传，财务确认收到；原有上传、确认及审核通过后算已到等规则不变。
- 后补单详情不再显示「去钉钉找发票」，前端对应 state、处理函数、import 和 API 导出均已移除。
- 历史发票、`lateFlow` 标记及「初审后才到」等徽标不删除；自动和手动回扫也不会把遗留的未关联 `lateFlow` 票重新送审。

## 实现

1. `routers/invoice.py` 的自动初次拉取逐附件用 `_late_info` 判断，跳过初审后评论附件；末尾不再无条件 `link_late`。底层 `_pull_one` 不改，供初审前手动补票复用。
2. `flow_recheck` 在 `first_review.passed` 时不再区分自动或手动，均在读取附件清单前返回，提示“初审后流程新增内容不再接入，请通过发票后补单上传”。自动路径返回 `ok=True` 以正常结束本轮；手动路径返回 `ok=False`，兼容接口 `/api/inv/later/{lid}/flow-check` 因此返回 400。初审前手动补票保持原行为。
3. `routers/invoice_books.py` 建后补单后不再 `queue_recheck`，财务代填和申请人自助均不自动回扫；回扫队列和后台取队逻辑已移除。
4. `invoice_intake` 保留初审前回扫及票齐送审，不再自动关联初审后票。
5. 后补详情移除流程补票按钮及全部前端调用；设置页、源码头注、API/docstring 和测试统一为“审核后只能后补单上传、财务确认”的最终口径。
