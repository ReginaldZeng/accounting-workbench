**【物流计提】服务器部署首日(V2.217 包)实测问题闭环**。

**现象**:用户在服务器上传 7 月账单包,7 家中 6 家解析成功(206 票),唯独《7月链盟帐单.xls》读取失败:"Import xlrd failed…"——账单包里唯一的 .xls 旧格式文件。

**根因**:pandas 读 .xls 依赖 xlrd。`requirements.txt` 早已列有 `xlrd>=2.0`(物流对账线诚煜 .xls 时加入),但**部署包只覆盖代码、不执行 pip install**——服务器环境从未装过该组件。本机开发环境装过,故本机测试未暴露。

**处置**:
- 服务器:宝塔 → Python 项目 → 执行 `pip install "xlrd>=2.0"` → 重启项目 → 重传账单(已指导用户);
- 工具侧:`parse_bill_files` 读取失败提示检测 xlrd 关键词 → 人话化为"服务器缺 .xls 读取组件——请管理员在宝塔 Python 项目执行 pip install xlrd 并重启,再重传本文件(或把账单另存为 .xlsx 上传)"——同事自助可解,不再对着英文堆栈发懵。

**部署流程教训(记入下次打包说明)**:部署包覆盖后若 requirements.txt 有新增,需在宝塔跟一句 pip install -r requirements.txt——考虑后续在 pack_deploy 的更新步骤文案里固化这一步。
