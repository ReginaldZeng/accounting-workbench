# V2.647 修复复核台 /result 等三处 SQL .mappings() 错位（开始复核详情从未成功过）

- Date: 2026-09-28 | Author: Claude Opus 4.8

## 根因
`c.execute(select(...).where(...).mappings().all())` —— `.mappings().all()` 写进了 `c.execute(...)` 括号内、作用在 Select 对象上（应作用在执行结果 CursorResult 上），`AttributeError: 'Select' object has no attribute 'mappings'`。三处：
- `review_result`（复核台「开始复核」详情端点）→ 因此**任何承运商的开始复核详情从未成功返回过**（迅鸽价卡空一直没人真点，未暴露）。
- `review_doc_sales`（旧销售出库兼容端点，现前端已不用）。
- `review_register_kingdee_check`（其他单据「接金蝶查单号」）。

## 修复
把 `.mappings().all()` 移到 `c.execute(...)` 之外（多一个右括号）。三处均改。

后端 .py 改动 → 部署重启。
