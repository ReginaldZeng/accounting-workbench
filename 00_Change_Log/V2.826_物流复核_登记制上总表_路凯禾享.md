# V2.826 物流复核台：登记制上总表（路凯、禾享）

日期：2026-10-05

路凯是卡板租赁（请款单附件只有发票和对账单两份 PDF），禾享是国际快递寄样（附件是称重 / 计费 / 签收照片），都没有可逐单核价核量的账单。
用户同意这两家走登记制。原来「登记制」只有货拉拉、且只体现在单据运费页的手工登记，总表上还是「未配」「开始复核」。

- `routers/logistics_review.py`
  - `_register_carriers()`：取数说明里 `review_mode=register` 的承运商。
  - 总表：登记制的承运商状态显示「登记制·待登记」；没有账单时「付款(复核)」那一格用请款金额顶上，和计提比出差异。（有请款、没计提的仍显示「有请款·无计提」。）
  - 登记接口对登记制的承运商多记一项请款合计。
- `routers/logistics_payreq.py`：登记制的承运商请款单到了不去解析账单，账单状态记「登记制·不导账单」。
- `LogisticsReview.jsx`：登记制的行按钮是「登记（不逐单）」——弹出各主体 计提 / 请款 / 差，写一句备注即登记；计提和请款有差异时备注必填；登记后可「撤销登记」。

数据操作（上线后在服务器上做）：供应商档案给路凯补金蝶编码、新增禾享；禾享请款单的承运商简称改成「禾享」；存两家的登记制取数说明。

上线：后端有改动，需重启。
