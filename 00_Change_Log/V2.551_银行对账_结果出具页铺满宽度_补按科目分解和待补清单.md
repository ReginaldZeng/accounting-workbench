**【银行对账】结果出具(S4)页铺满宽度 + 右侧补实用内容**。
**起因**：V2.550 修好了 S4 的数据口径，但需求方看真机说"怎么还是这样、右边那么空"——页面 `ResultExport` 的内容框被 `maxWidth:940` 卡在左侧,宽屏右半边全白,和其它不设上限的页(FundDashboard/DataImport 都 `className="body"` 满宽)不一致。
**改法**（纯前端）：
- 去掉 `<div className="body" style={{maxWidth:940}}>` 的宽度上限,恢复满宽;
- 概览统计卡(在用/对平/待补/真实差异)满宽;
- 概览下新增左右两栏 `grid repeat(auto-fit,minmax(340px,1fr))`：左＝「按科目分解」表(遍历 groups：科目/在用/对平/待补/差异，待补＝银行侧缺·非全零，对平＝在用−待补−差异)；右＝「待补银行侧 N 户」清单(遍历银行侧缺户，列 账户名/主体/怎么补——`waitReason` 按科目+关键词判：银行存款→本月无流水待截图·结转；交易性金融资产→资管/理财走对账单；其它货币资金→天猫/抖音/京东/结算等关键词→电商结算走电商线，否则理财走对账单);
- 导出卡满宽收底。
**验证**：本地起 http 静态服务把同版式(真 8 月数据 35/17/18/0 + 18 户待补清单)渲染,量得 1680px 视口下 body 满宽、统计 4 块并排(每块 393px)、底部两栏并排(各 812px 侧靠)、右侧不再空。`npm run build` 通过。
**遗留**：待补 18 户里的"怎么补"是按科目/关键词粗判,个别户(如建行未进包 vs 无交易)口径可后续细化。
