# V2.682 费用类型：账单原名已是规范类就直接采信(老机制改到原 fee_item 的归类也生效)

## 背景
用户按建议在逐单表把丰源 FBDR(调拨) 改成「出库运费」、把某销售出库单主体从深圳星期九改成深圳星期零——这些改动(V2.680 UI)写到了原始 subject/fee_item 列。V2.681 改成「单号前缀优先」后，FBDR 前缀仍推成调拨，把用户的费用类型改动吞了(主体改动仍生效，结果不一致)。

## 修复
`_eff_fee` 优先级细化：① fee_ovr 覆盖列 → ② **账单原费用名 _fee_norm 后已是规范类(入库/出库/调拨/退货运费)就直接采信** → ③ 否则(顺丰=冷运运费 这类非规范名)按单号前缀 _fee_of 归口。
- 顺丰「冷运运费」非规范 → 前缀 XSCKD/QTCK → 出库运费(对上计提)。
- 丰源原名「采购入库运费/销售出库运费/调拨运费」本就规范 → 直接用；用户把 FBDR 改成「出库运费」也是规范 → 采信(调拨并入出库)。
两不误，且用户已做的归类改动无需重做。新 UI 改动仍走 fee_ovr 覆盖列(非破坏)。

## 效果(丰源，用户已把 FBDR→出库、918.93单主体→深圳星期零)
- 孝感星期九·入库 2288=2288 平；深圳星期零·出库 5036.39=5036.39 平 → 全组对平。

## 上线
仅后端一处函数 → 部署自动重启。
