# V2.981 账单复核导出：复核明细补上账单里没有单号的行，按主体加起来＝账单

- 日期：2026-10-14
- 作者：Claude Opus 5.5
- 模块：应付板块 › 物流对账 › 账单复核台 › 导出

## 起因

用户看极鲜达 8 月：复核台逐笔计提复核里深圳星期零账单金额是 75,093.68（和钉钉请款单一样），导出的复核明细里深圳星期零加起来却是 75,265。

差的 171.76 是山姆页一笔「托盘丢失扣款 −171.76」，账单上这一行没有单号。复核明细是一张单一行（按金蝶单号），没有单号的行不进逐单核对，原来也就不列，所以按主体一加就比账单多出这笔扣款。

不止极鲜达：易风达 8 月有 3 行（搬运费 300、两张仓储费 10,011 和 1,302），恒茂 8 月有 313 行（冷藏车按天收），复核明细里原来都没有。

## 改动

- `backend/routers/logistics_review.py`（导出，复核明细页）：账单上没有单号、金额不是 0 的行，排在复核明细最后，一行一条，底色浅灰：
  - 费用主体、费用类型和逐笔计提复核同一个口径（人工改过的按改过的）；
  - 单据号写「（账单上没有单号）」；
  - 各费用分项、账单计入金额、账单计费量照账单；
  - 备注写原账单上的说明、在原账单哪一页，并注明「不逐单核量价」。
- 金额是 0 的不列（迅鸽的钱记在费用项汇总行上，明细上没有单号的行都是 0，列出来只是一片空行）。
- 已经在逐单核对里的（有的承运商没有单号的行也按价核）不重复列。

## 验证

服务器上用新代码只读导出 8 月（写库拦住），复核明细按主体把账单计入金额加起来，和库里账单按主体比：

- 极鲜达：深圳星期零 75,093.68、深圳星期九 5,628.85、孝感星期九 99,860.00，全部对上；补进来 1 行＝托盘丢失扣款 −171.76。
- 易风达：深圳星期零 800.00、孝感星期九 87,168.00，对上；补进来 3 行。
- 恒茂：孝感星期九 78,733.53，对上；补进来 313 行。
- 迅鸽：深圳星期零 29,475.83、孝感星期九 1,548.00，对上；没有补行。
- **没验的**：上线后从页面上点导出、用 WPS 打开看一眼。
