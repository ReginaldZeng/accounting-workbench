# V2.451 · 脱敏版核算表给 BP：`/api/bomcost/sheet` + `/api/bomcost/export`；核算侧全量核算表只给内部账号；下载分版本

**日期**：2026-09-06　**业务方定**：「BP 侧想看核算表的就在 BP 侧看，除非是我和总监这种主管理员。下载的核算表也要分版本。」

## 口径

| 谁 | 在哪看 | 看到什么 | 下载 |
|---|---|---|---|
| 成本会计 / 财务BP（核算工作台账号） | 核算工作台 | **全量**（供应商、型号、规格、报价说明都在） | 全量重排版 / 原版附件（`/api/bom/export/*`，需 `bom:export`） |
| BP 工作台的人 | **BP 工作台**自己渲染 | **脱敏版**：物料行遮 型号 / 规格 / 供应商（默认，商品版口径），报价说明默认不遮；数值、五分项、勾稽、上游都给 | 脱敏版重排版 xlsx（文件名带「脱敏版」）/ 网页预览；**不给原版附件** |
| 主管理员（Owner / 总监） | 两边都行 | 全量 | 全量 |

## 核算侧改动

- **基础设置四个开关真正生效**：`_CFG_DEFAULT` 改为 遮型号/规格/供应商＝开、报价说明＝关；它们只管**给 BP 的脱敏版**，核算侧内部永远全量。`_masked_rec(e)` 服务端置空（前端藏没用）。
- 新增 `GET /api/bomcost/sheet?entryId=`：脱敏版核算表 JSON（头部信息、fee/srcFee/comp、物料行、勾稽 checks、并行 variants、`hiddenColumns` 告诉 BP 遮了哪几列、links）。
- 新增 `GET /api/bomcost/export?entryId=&preview=0|1`：脱敏版重排版 xlsx（活公式）/ 网页预览，同一 `build_pretty`，标题与文件名带「脱敏版（已遮 …）」。
- 两口鉴权同 `/api/bomcost/final`（内部令牌回环 / 门户登录），**只准已审核且有效的版本**（初审/作废/替换 → 403）。
- `_export_auth`：核算侧全量导出 `/api/bom/export/*` **对内部令牌 403**（提示走 bomcost/export）；登录门放行前缀收回到只有 `/api/bomcost/`。
- `links` 改口径：`sheetUrl / previewUrl / downloadUrl` 全指脱敏版；`adminDetailUrl / adminCompareUrl` 明标**仅主管理员**放；`originalUrl` 撤（原件含供应商无法脱敏）。
- 文档：《对接说明_BP只读标准成本台账》改成「BP 自己渲染脱敏版核算表」；回复文档 §10；确认书 v1.2 §2.6/§5.3。

## 验证

TestClient：sheet 遮三列（model/spec/brand 置空、priceNote 保留）、`hiddenColumns=[型号,规格,供应商]`；export xlsx 物料行型号/规格/供应商单元格为空、文件名含「脱敏版」；初审版 403；内部令牌打 `/api/bom/export/pretty` 403；门户用户仍走全量。

BP 侧的人不拿核算工作台账号；核算侧现有 `enter:bomstd + bom:view_sheet + bom:export` 即全量。主管理员 admin 自带。
