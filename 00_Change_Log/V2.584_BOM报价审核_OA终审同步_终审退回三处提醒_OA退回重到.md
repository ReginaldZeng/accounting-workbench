# V2.584 · BOM报价审核：OA 终审同步（在 OA 点同意/退回 → 工作台自动终审）+ 终审退回三处提醒 + OA 退回重到（丙案）

**日期**：2026-09-15　**业务方问**：「退回/审核通过我得在工作台操作？然后钉钉也要审核一次？——那能不能我在流程点了，工作台这边自动终审？」+「BP 在流程退回，成本会计怎么知道我说的是哪个产品？」

## 边界（不变）

吴总 2026-09-07 定「钉钉流程不动、不替人点」——本版**只读 OA**：你在 OA 财务经理节点点了什么，工作台跟着做；反过来永远不做（不替人在 OA 点同意/退回）。钉钉服务端也没有「回退到某节点」接口。

## 改

### 1. OA 终审同步 `_oa_final_sync_once`（与自动立项同一轮询线程）
- 台账里**已初审、待终审**的单 → `dingtalk_bom.final_node_state(单号, 节点)` 读财务经理节点（conf `final_node_ids`，默认 `908e_bfa0`）最近一次**已完成**任务：
  - **AGREE** → 该单**已初审且初审时间 ≤ OA 同意时间**的产品自动终审通过（`ack.via="OA同意"`、带 OA 任务号/时间留痕）；初审晚于同意时间的、尚未初审的**不动**，钉钉提醒 OA 审批人「请到工作台终审」（你同意的是当时那版）。
  - **REFUSE / REDIRECTED / 实例被拒绝终止** → 自动**退回**：备注里写了 CP 码就只退那几个产品（`_cp_in_text`），没写整单已初审的都退；原因＝OA 备注（无则「OA 退回（未写原因）」）。
  - 同一任务号只处理一次（`bom_oa_final_seen`）；审批人身份按钉钉 userid→姓名→工作台账号（主管理员自审照旧标「自审」）。
- conf.ini `[bom] oa_final_sync=1`（默认开，需钉钉已配、本地 SQLite 不触发）、`final_node_ids`；`GET /api/bom/oa-final-sync/status`、`POST …/run`（主管理员手动跑）。
- 实证：真钉钉 27725/20869 财务经理节点均读到 `COMPLETED·AGREE`（task 字段 taskid/task_result/finish_time；拒绝备注在 `operation_records` 的 `EXECUTE_TASK_*` 记录里）。

### 2. 终审退回三处提醒（工作台按钮与 OA 同步共用 `_final_review_apply`）
- 新列 `final_return` JSON `{by,at,note,via}`，退回时写、重新初审清空；`_entry_view.finalReturn`。
- **钉钉发初审人**（按姓名查钉钉花名册；查不到退到门户配的「BOM 落公盘送达」收件人）：「OA 单 X · 产品 CP 名称 · 终审退回（谁·何时·OA）：原因 → 去待办」。
- **待办**单行标「⟲ 终审退回 N」、处理页组头标「⟲ 终审退回 N」；**详情页顶部横幅**「终审退回（谁·何时·在 OA 退回）：原因——改完重走③④再审核通过」。

### 3. OA 退回重到（丙案）`_oa_rearrival`
- 自动立项轮询里，台账已有的单若成本核算节点上出现**更新的任务**（`taskCreateTime` 变新）→ 不再当「台账已有」跳过：
  - 全是草稿的组 → 自动「重连钉钉替换」（附件挑选改为**财务复核 › 商务输出 › 其它**，V2.547 口径；数字没变自会跳过）；
  - 含已初审/已审核的组 → **不自动重拉**，其中已初审产品按「终审退回」打回（原因＝财务经理节点最后备注，无则「OA 退回重到」），待办标「⟲ OA 退回重到」；成本会计到处理页点「重连钉钉替换」。
  - 首轮只记下当前任务时间不动作（上线不误判老单）；钉钉提醒节点在办人。`bom_oa_returned` 供待办显示。
- 重拉核心抽成 `_refetch_replace_core`（端点与自动路径共用）。

## 测（沙盒 + 真钉钉 27725 立项，OA 节点结果用桩）
T1 OA 同意→两条初审早于同意的自动已审核（ack.via=OA同意），成品初审晚于同意→不动+提醒，同任务不重复；T2 拒绝备注带 CP→只退半成品、final_return.via=OA、钉钉发初审人含产品+原因；T3 拒绝无备注→整单已初审都退；T4 工作台 `/final-review` 退回→finalReturn+钉钉，通过→清 finalReturn；T5 待办汇总 returned；T6 退回重到：含初审组 held+成品自动退回（原因带出）+钉钉，同 taskCreateTime 不重复，全草稿组真钉钉重拉替换成功。V2.540 手动指认回归 ALL PASS。

## 待验（真环境）
