# V2.275 电商对账 · 剔除留痕批量勾选登记

## 一句话
需求方定："需要做一个多选，因为万一是活动的话，流水会很多"——一场线下活动/一轮推广就是一串流水（5 月收钱码实证），逐笔点登记不现实。加勾选列+类头全选+批量条：一次给整批同一判定与说明。

## 改了什么
- routers：POST excl-notes-batch——items≤500 单事务写入；verdict 空=批量撤销；审计合记一条（"批量正常 N 笔 说明"）。
- EcomSettle.jsx：行首复选框（无流水号的行禁勾）；类头复选框=全选/清空本类；勾选后浮出批量条——已选 N 笔·合计金额 + 判定下拉（对上活动/推广 / 违规·要追 / 撤销登记）+ 整批同一句说明 + 批量登记/撤销 + 清除选择。单笔登记/改/撤保留不动。
- 权限同单笔：勾选与批量条仅 ec_settle_upload 可见。

## 验证（E2E，测试记录验后已批量撤销）
类头一勾=5 笔全选（合计 −7,100）→ 批量登记"正常·7月万相台推广充值·运营确认"→ 5 行绿✓徽章、库中 5 条 → 再全选+撤销登记 → 库清零。
