# V2.261 电商对账 · 账户流水灯语义修正

## 一句话
需求方指出 V2.260 的语义矛盾：「上传记录未查到」却亮绿灯。修正为——灯表达的是**这一步可信完成**：文件在且上传审计可查=绿灯；文件在但审计查不到=**黄灯**+琥珀字「来源未验证，请人工确认是谁放的」；没文件=灰灯。

## 改了什么
EcomSettle.jsx 步①灯逻辑：`on = 文件齐 && flow_pkg审计在`，`half = 有文件 && 无审计`；未验证文案转琥珀色。

## 验证
预览实测：测试环境（文件手工拷入、无审计）→ 黄灯 rgb(163,90,0) + 琥珀提示文案。
